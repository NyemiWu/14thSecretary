## 四组划分

秘语共 **14 条**，分属四个互不相交的组。每组对应四段式真名的一位，**组与位是一一对应的** —— `火` 不可能出现在第一位。

### 一 · 倾向（LNC）

| 秘语 | 名称 | 概念 |
|---|---|---|
| `L` | 秩序 | 即 LAW。该秘语表达概念为**对他者友善**。 |
| `N` | 中立 | 即 NEUTRAL。该秘语表达概念为**无视或忽视**。 |
| `C` | 混乱 | 即 CHAOS。该秘语表达概念为**对他者恶意**。 |

### 二 · 性（主动 / 受控）

| 秘语 | 名称 | 概念 |
|---|---|---|
| `一神` | 受控 | 即一神教倾向。该秘语表达概念为**无主动性，被他者控制或驱使**。 |
| `多神` | 主动 | 即多神论倾向。该秘语表达概念为**存在主动性，为了存活主动进行抉择**。 |

### 三 · 途（手段）

| 秘语 | 名称 | 概念 |
|---|---|---|
| `战` | 战士 | 即战士类型。该秘语表达概念为**高防御性能、物理战斗方式**等符合战士刻板印象的能力表现。 |
| `法` | 法师 | 即法师类型。该秘语表达概念为**操控能量、高智能**等符合法师刻板印象的能力表现。 |
| `牧` | 牧师 | 即牧师类型。该秘语表达概念为**治愈、圣化**等符合牧师刻板印象的能力表现。 |

### 四 · 显（表现属性）

| 秘语 | 名称 | 概念 |
|---|---|---|
| `火` | 焰 | 该秘语表达概念为以**火焰、热能、辐射**等方式体现力量。 |
| `水` | 寂 | 该秘语表达概念为以类似**冰或死寂**的方式体现力量。 |
| `电` | 雷 | 该秘语表达概念为以类似**雷电**的方式体现力量。 |
| `气` | 冲 | 该秘语表达概念为以**冲击、塑形**等方式体现力量。 |
| `祝` | 圣 | 该秘语表达概念为以**神圣化、正能量**方式体现力量。 |
| `咒` | 秽 | 该秘语表达概念为以**怨咒、劣化等负能量**方式体现力量。 |

## 组合空间

```text
3（倾向）× 2（性）× 3（途）× 6（显） = 108
```

三位数不到的排列组合，撑起了一整套定位体系。再叠加一个真名（赐名），才是完整的四段式真名。

!!! quote "设计原案 · 应用规则"
    匹配秘语时，如果秘语正确（是四个秘语之一）会增加**测名进度**；
    只有全部秘语匹配并顺序正确，才会将测名进度推进至 **100%**。
