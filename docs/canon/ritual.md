# 赐名流程

!!! quote "设计原案"
    观察对象 → 匹配秘语 → 揭秘获得四段式真名 → 锚定具体赐名

<div class="ritual-flow">

<div class="ritual-step">
<span class="ritual-no">01</span>
<b>观察对象</b>
<p>在对象身上读取线索。它的行为、它对刺激的反应、它经过之后留下的痕迹 —— 全都指向某几段秘语。</p>
</div>

<div class="ritual-step">
<span class="ritual-no">02</span>
<b>匹配秘语</b>
<p>把观察结果落成四段秘语。哪一段错了，对象就会抗拒一次；对的段落则被锚定下来，不再更改。</p>
</div>

<div class="ritual-step">
<span class="ritual-no">03</span>
<b>揭秘获得四段式真名</b>
<p>四段秘语全部匹配并顺序正确 → 测名进度推进至 100%，四句短句随之展开。</p>
</div>

<div class="ritual-step">
<span class="ritual-no">04</span>
<b>锚定具体赐名</b>
<p>四句里各有一个候选词，其中只有一个是真名。锚对了，赐名成立；锚错了，它会把自己重新裹起来。</p>
</div>

</div>

---

## 进度与代价

| 事件 | 结果 |
|---|---|
| 一段秘语正确 | 该段锁死，测名进度 **+25%** |
| 一段秘语错误 | 对象抗拒，**阶级 +1**，多暴露一条线索 |
| 四段全部正确 | 进度 **100%**，进入揭秘 |
| 锚对真名 | **赐名成立** |
| 锚错真名 | 同样计入阶级 |
| 阶级到达上限后再次失误 | 对象**脱锚逃逸**，本次失败 |

!!! warning "100% 这个门槛"
    四段秘语**部分正确不算通过**。进度条涨到 75% 也依然是未完成状态 ——
    必须四段全中，才谈得上揭秘。

## 万能秘语 · 無相

参考《Warframe》赤毒玄骸体系里的 **Oull**：可以填进任意一段，不判错，
但**也不锁位、不涨进度**。

所以它永远推不到 100%。它只是续命的探测符，用一次少一次。
