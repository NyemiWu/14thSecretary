# 002 · 静水之下

<div class="entry-head">
  <div class="entry-seal">C 一神 法 水</div>
  <div class="entry-name">沉钟</div>
</div>

## 观察记录

一团比水更深的轮廓，边缘始终在溶解，看不出边界在哪里。

!!! abstract "形态摘要"
    - 行为无动机，只为兴味
    - 自身不驱动，由更深处的东西牵引
    - 不接触、不用爪，靠延缓一切起作用
    - 经过处声音先死
    - 不进食、不休息，像在等一个不会来的指令

## 四段秘语

| 段 | 秘语 | 判定依据 |
|---|---|---|
| 一 · 倾向 | `C` 混乱 | 推船离岸只为看船沉，无理由、对活物恶意 |
| 二 · 性 | `一神` 受控 | 自己不想动，是更深处的"手"在动 |
| 三 · 途 | `法` 法师 | 不用爪牙，靠操控水与温度 |
| 四 · 显 | `水` 寂 | 经过处声音先死，命中的活物血液在体内冻住 |

## 四段式真名

1. 它做的事没有理由。它把船推向下游，只为了等一次落潮，好看着船自己沉下去。
2. 它不为自己而动。更深的地方有东西牵着线，它只是那根牵线尽头的手。
3. 它不用爪。它只是让水慢下来，让温度慢下来，让一切都遵守它的慢律。
4. 它经过的地方，声音先死。人们后来把那片死寂叫作 **沉钟**。

!!! success "锚定结果"
    **赐名：沉钟**

    干扰候选：`落潮` · `牵线` · `慢律`

## 测名线索池

1. 它做事没有理由。它把船推离岸边，只为了看着船自己沉下去。
2. 它自己并不想动。更深的地方有东西牵着线，动的是那只手。
3. 它不用爪牙。它只是让水慢下来，让温度慢下来，让一切都慢下来。
4. 它经过的地方，声音先死。连雨落进那片水面都不出声。
5. 它做这些没有目的，只有兴味。
6. 它不进食，也不休息。它仿佛在等一个永远不会来的指令。
