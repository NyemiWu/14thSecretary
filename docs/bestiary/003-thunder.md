# 003 · 第八次雷暴

<div class="entry-head">

## 观察记录

一个过高的、被反复击穿的人形轮廓，正面的皮肉几乎没有一处是完整的。

!!! abstract "形态摘要"
    - 对观察者无恨无爱，视同石头
    - 无人召唤，时辰自选
    - 不闪避，以身体迎刃
    - 抬手时云先亮，铁器自行发烫
    - 不追击，让开路即离开

## 四段秘语

| 段 | 秘语 | 判定依据 |
|---|---|---|
| 一 · 倾向 | `N` 中立 | 对谁都没有态度，只是照旧往前走 |
| 二 · 性 | `多神` 主动 | 时辰由它自己挑 |
| 三 · 途 | `战` 战士 | 不闪避，以身体为盾 |
| 四 · 显 | `电` 雷 | 抬手时云先亮，铁器自行发烫 |

## 四段式真名

1. 它不恨你，也不爱你。你和一块石头没有分别，它照旧往前走。
2. 没有人召它来。这个时辰，是它自己挑的。
3. 它不躲。它迎着刃走，把身体当盾，把每一道伤都记成旧账。
4. 它抬手时云先亮，铁器就自己烫了起来 —— 人们管它叫 **空膛**，扣下去时里面什么都没有。

!!! success "锚定结果"
    **赐名：空膛**

    干扰候选：`照旧` · `时辰` · `旧账`

## 测名线索池

1. 它不恨你，也不爱你。你站在它面前，和一块石头站在它面前没有分别。
2. 没有人召它来。这个时辰，是它自己挑的。
3. 它不躲。它迎着刃走，把身体当盾，把每一道伤都记下。
4. 它抬手时云先亮。那道白光走过的地方，铁器会自己烫起来。
5. 它不追击。你让开路，它就走，连头也不回。
6. 它身上几十道旧伤，全部开在正面。
