# 004 · 巡礼者的残响

<div class="entry-head">
  <div class="entry-seal">L 一神 战 祝</div>
  <div class="entry-name">遗祝</div>
</div>

## 观察记录

一具始终朝着一个方向跪行的躯壳，掌心有磨不掉的温白纹路。

!!! abstract "形态摘要"
    - 跪下替他人按住伤口，不惜撑裂自身
    - 不做自主决定，在等一个更高的声音
    - 从不转身，所有伤都在正面
    - 掌心浮现温白纹路，被照过的东西安静下来
    - 躯壳本身无名，身上刻满别人的名字

## 四段秘语

| 段 | 秘语 | 判定依据 |
|---|---|---|
| 一 · 倾向 | `L` 秩序 | 跪下来替人按住伤口，不阻拦任何人离开 |
| 二 · 性 | `一神` 受控 | 不做自己的决定，等候更高的声音 |
| 三 · 途 | `战` 战士 | 从不转身，每一道伤都开在正面 |
| 四 · 显 | `祝` 圣 | 掌心浮出温白纹路，被照过的东西安静下来 |

!!! note "`牧` 与 `祝` 的区分"
    这里用的是 `祝` 而不是 `牧`。
    `牧` 是**治愈与圣化作为手段**；`祝` 是**神圣化作为力量的表现形态**。
    它的温白纹路是**外显**的，所以落在第四段。

## 四段式真名

1. 它跪下来替你按住伤口，自己的裂壳一层层剥落，它没有停。
2. 它不做自己的决定。它一直在等候一个更高的声音，哪怕那声音从没来过。
3. 它身上没有一块完整的皮，可每一道伤都开在正面。
4. 它没有名字。人们后来替它唱了一段悼词，那段词叫 **遗祝**。

!!! success "锚定结果"
    **赐名：遗祝**

    干扰候选：`裂壳` · `等候` · `正面`

## 测名线索池

1. 它会跪下来替你按住伤口，哪怕那样会撑裂它自己已经开裂的壳。
2. 它不做自己的决定。它在等一个更高的声音，哪怕那声音一直没有来。
3. 它身上没有一块完整的皮，可每一道伤都开在正面 —— 它从不转身。
4. 它抬手时掌心浮出一圈温白的纹路；被那纹路照过的东西会安静下来。
5. 它不阻拦任何人离开。你走，它只是站着看。
6. 它的躯壳没有名字，它把别人的名字刻在自己身上，一层盖着一层。
