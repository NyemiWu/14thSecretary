# 西伯利亚穹顶城：二十八号穹顶城

“飞跃”计划（Скачок Проект）：西伯利亚穹顶城的一次突破穹顶、延伸活动范围的尝试。试图用装甲与混凝土洪流于意识污染角力，硬生生抢下额外的穹顶城面积。利用极大功率的发动机，推动该造成模块化部分的混凝土穹顶向外扩张，同步填补缝隙，扩大穹顶包围范围，并利用强大的装甲力量摧毁沿途的一切意识造物。

计划失败了。

仅仅只需一次失误，一辆异化的重型装甲平台就足以摧毁其所在的作战编组，更何况由内而外的侵蚀往往无可预见，而爆发之时已然排山倒海。西伯利亚穹顶城引以为傲的装甲洪流尽数被毁，而残存的钢铁巨兽们也只能用其轰然倒下的庞大身躯堵住混凝土穹顶的缺口。全民皆兵的号召之下，得以苟活的只剩下后方的妇孺老弱，从此西伯利亚穹顶城一蹶不振，直到新的信仰似乎带来新的——

但那个来自至高联合的传道者始终身着黑袍，面目不清。
