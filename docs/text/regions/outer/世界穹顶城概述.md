# 十四号城

特点：

1.  政治不稳定，权力不集中，高科技企业垄断政治与民生

2.  文化多元，市民文化活动与意识形态丰富

3.  地方经济两极分化，资源分配不均，北方片区与中心矛盾紧张

4.  意识污染事件频发，意识生物活动频率高

5.  内陆地区，附属有发达的自贸港，最适合作为交通贸易枢纽

6.  发展潜力极大，充满机遇与挑战

7.  军事武装力量分散，无城市官方编制，主要军事力量来自高科技企业和地方残余戍卫军

城际关系：

正在与十三号城的新上台政权建交，计划促进两地文化与经济交流

与S城建立有稳定的贸易关系，S城缓解了十四号城粮食作物短缺的问题，而十四号城则承诺向十三号城输送仿生人技术和科学顾问。但对于S城牵头的“亚欧穹顶城际联盟”的主张，十四号城没有作出明确回应，似乎是对权力分配有不同的意见，遣送走了S城派来的政治指导专家团队。

**十三号城**

位置：位于十四号城西北方向约一千六百公里（尺度可按比例缩小）

1.  宗教治城，宗教中心集权

2.  领土面积小，人口少

3.  意识污染严重，宗教与意识生物共存

4.  生活水平低，居民普遍接受宗教主义教育的灌输，故认知水平落后，科学技术由宗教中心完全管控

5.  内部矛盾激烈，有反抗军存在，处于政变动荡中

    城际关系：

    基本与世隔绝，直到新政权上台才开始对外交流，目前正与十四号城建交。

**S城**

位置：位于十四号城东北方向约一千公里（尺度可按比例缩小）

特点：

1.  领土面积大，临海

2.  政治水平发达，政治意识强，有高度秩序化的中央政府和社会制度

3.  农业、渔业发达，可保证市民衣食无忧且有大量余裕

4.  重工和建造业发达，有各种堪比奇观的重型机械载具，得益于军用智械技术，有充备的中央军事力量

5.  对于意识污染灾害的治理相对保守和回避，也因此仿生人技术相对落后，对意识作战的认识还停留在火力打击，依赖其他穹顶城的技术支援

    城际关系：

    计划设立亚欧穹顶城际联盟，以S城为政治中心。

    计划拉拢十四号城加入联盟，实则是让十四号城成为S城政治附属城市。

**J城**

位置：位于十四号城东南方向约六百公里（尺度可按比例缩小）

特点：

1.  人口密度和资源开发已经逼近极限

2.  领土面积相对小

3.  主战派居多，潜伏的内在矛盾容易导致内战爆发

4.  科技水平极其发达，仿生人储备极其夸张，能有效对抗意识污染灾害威胁

    J城通过将意识生物“囚禁”在仿生人里来治理意识灾害，由此方法培养出了数以千人计的仿生人军团。如今J城周边意识生物已基本消除，而这支超级武装力量放在城市里是一个极大的隐患，直接销毁又会导致意识生物失容引发更大的灾害，于是J城计划通过激进地向外寻找其他穹顶城，扩大领地，发动外战来消耗多余的武装力量和人口，也借竞争关系进一步刺激自身发展。

    内部爆发过一起大规模“仿生军队哗变”事件，事后有一大批武装仿生人叛逃到城外建立了一座大型据点，J城官方对外城宣称该支武装力量已经脱离J城、完全失控，疑似目前该军正策划对其他穹顶城的军事袭击。

    城际关系：

    计划以开采空舰坠址这一事件为牵头，与十四号城争夺城外资源分配权，

    拒绝加入城际联盟，但没有打算与S城竞争（因为打不过）

    觊觎N城的待开发资源，极端主战派提出殖民N城

**N城**

位置：十四号城南方约四千公里（尺度可按比例缩小）

特点：

1.  人类、动物与意识污染形成了某种奇特的共生关系

2.  面积大，人口少，自然生态资源丰富，植被茂盛，有较多物种，气候湿润温暖

3.  没有明确的穹顶边界，也几乎不发展工业，很难说这座城市还能不能算作人类文明的范畴内

4.  有外交意向，但鉴于“人与意识污染共生”这一现象太过独特，加上距离太远且隔海，从未受到其他穹顶城的接见

5.  流行自然崇拜，当地人会供奉一种独特的称为灵木的树，而这种树实质上可以看作是N城的天然穹顶系统，它的特性维持了人类个体意识不被污染所扭曲
