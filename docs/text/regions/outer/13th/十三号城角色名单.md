# 十三号城角色名单

阵营身份设定

六大阿梅沙圣灵及其教派、神职者，每位圣灵的机构都有社会功能。水/植物之神的机构对应的是医院，土对应的是农田、耕种者，其成员大多选自农民阶级，金属对应的是教廷，与建筑、矿物、王国秩序、政府、学校有关，动物对应的是牲畜、牧场，

神使（雅扎塔Yazata）：仿生人

琳，赐名【天敌-阿修罗】

芊

科恩

随行测名师A，专业素养过硬且充满好奇心，对印欧语系、琐罗亚斯德教、印度神话颇有了解，对文化习俗的话题与向导塔洛玛蒂相谈甚欢。

**伽玉玛特**，波斯语Gayōmart的音译。琐罗亚斯德教神话中的“原人”或“最初的人”。世界观里神胚破茧后的原初巨人。

**米芮**，被选为神胚的女孩，米尔达的孪生姐姐。拥有控制神使的能力，本质是可以控制意识生物。

**米尔达**Milda，十三岁少年，后更名米塔耶克Mitayek。十三号城【神胚】米芮的孪生弟弟。米塔耶克，三战-戍卫军团时期范瓦德开拓联盟军的创始人。

**伊玛·努尔**，女性，三战时期被米塔耶克收留的孤儿，十三号城建城时期范瓦德开拓联盟的核心人物，拥有戍卫军团少将军衔，并领导了十三号城的开拓与建设，功绩可堪十三号城建城之母，在政变中被暗杀。右翼以她的名字建立了努尔教，以努尔神权之名义统治十三号城。

**塞潘达尔马兹**，阿梅沙圣灵之土地女神，象征“虔诚”之善。手持玫瑰的女主人，意识生物，形象为蝎子。玫瑰修道院是侍奉土地女神塞潘达尔马兹的神职机构。

**阿娜希塔**Anahita，掌管水、生育、智慧与战争的女神。主角团遇到的，自称是阿娜希塔的女人。

**神使**

**妲耶娜**Daena，良知女神，启悟天使，宗教本身的化身，肩生双翼的女神，灵魂的指引者与审判者。Daena在人的死后命运中扮演着至关重要的角色。

迎接亡灵：人死后第三天，Daena会前来迎接灵魂。

引至审判桥：她将灵魂带至钦瓦特桥（Chinvat Bridge，即“审判之桥”），接受最终的审判。有趣的是，经典记载她前往时会有两只犬随行。

道德审判官：在桥上，Daena的形象（美貌或丑陋）就是最直接的判决。如果Daena和灵魂（Urvan）对死者感到满意，灵魂便能过桥进入天堂；反之，则会被拒之门外。

奇美拉灵缇犬

**斯劳沙**Sraosha，聆听与启示之神，男，仿生人，双目失明，奇美拉为公鸡。圣人般的救世主情结，潜意识渴望修复他人的创伤来实现自我价值。这种情结发展成一种“伪善”。（类似崩铁的星期日）

**忧**Vayu，风与空间之神，女，仿生人

**艾什玛**Aeshma，女，身患圣状，具有攻击性和自残倾向（名字对应愤怒与暴力的恶魔，与斯劳沙对位）。她是玫瑰修道院的修女之一，长期被打压，最终在投射性认同下变成了“坏孩子”。在塔洛玛蒂的开导后，却阴差阳错导致了修道院圣火失火，烧伤并逃离修道院。在这最低谷的时候结识了神使斯劳沙。艾什玛的重度创伤、渴望救赎，与斯劳沙的救助情结相遇，一人一仿生人坠入爱河，也走向坠入深渊的边缘。最终立场不同的二人彻底决裂，在伐什卡日的革命中迎来结局。主题：救赎。

**塔洛玛蒂**Taroumati，女，十三号城的神职人员。背教者，策反者，善诱人心，是传说中的女魔，六恶神的盟友。原本是侍奉六大阿梅沙圣灵之一（土地女神【塞潘达尔马兹】）的修女（火侍），17岁那年在火灾中重度烧伤导致残疾，离开修道院并改造成半机械人，如今是龙蟒巨妖【阿日达哈克】的信徒与召唤者。作为向导为前往十三号城的琳一行人引路，自称是侍奉努尔神权的传教修女。
