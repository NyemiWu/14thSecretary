# 十三号城的圣状

圣状是一种流行于十三号城的意识污染症候，类似中世纪的黑死病，圣状无法治愈，患者精神会持续恶化、受到严重污染，十三号城的所有圣状患者都被认为是神选的先民，允许送上天堂，而这个方法便是祭火。圣状患者会经过特殊处理，在清醒的情况下投入圣火。圣火是一种有跨视距纠缠效应的等离子媒介，所有圣火无论地点距离都享有彼此的意识共振链接，形成一张巨大的意识信息网络。网络的中央服务器便是十三号城的核心：意识熔炉。

至高联合宣称圣状是十三号城市民的民族优越象征。当然他们知道圣状其实是意识熔炉过载的信号，患者唯一的结局就是意识崩解、回归混沌海洋，这种不可控的意识污染让他们不得不加速筹备更新日的到来，以到达海面上的那个彼岸。

（实际上，圣状的真相依然有待进一步挖掘。）

圣状的另一种可能是，被压抑在意识海中的“恶”，正以愈发强烈的动机通过集体潜意识回归，这些恶会直接在十三号城的意识个体上形成具象化的污染，譬如长出精灵耳、兽角等。十三号城的至高联合政权却宣传“精灵耳和兽角是尊贵的象征”来掩盖事实，多么讽刺。

圣状（创伤）的意义在于让人的本质更接近意识生物我，让意识生物通过集体创伤获得养分
