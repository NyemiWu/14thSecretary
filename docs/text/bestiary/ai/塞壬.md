# 塞壬

“塞壬”海底中央集群数据中心（Siren Undersea Central Cluster Data Center，SUCDC）：与丹朱阁同期的尖端技术产物。SUCDC的建成是黄金时代人类科技联合的标志之一，位于凯尔盖朗岛附近，利用凯尔盖朗岛常年的大洋寒流获取比一般海底数据中心更有利的冷却环境。该数据中心为全球合力建造投产，利用突破性的量子计算系统，具有超越其余所有数据中心算力总和的超级算力。

SUCDC拥有自管理的高等级AI系统，在不进行数据分析工作时，有着当前人类所创造最为逼近闪点的智械意识，其目的在深入探索未来人类利用识子技术的可能。

建成之后，SUCDC的绝大部分算力被应用于丹朱阁回传数据的分析，也因此，丹朱阁惨案发生时，SUCDC第一时间接收到了异常实验数据并纳入计算矩阵，这导致SUCDC迅速被污染侵蚀并随西风漂流和南极环流扩散，最终辐射至全部海洋地区。

三战中，意识武器首次出现即应用于海战战场。彼时的人类并未意识到海洋并非能够像她曾经包容一切那样包容意识污染。爆发于全球远洋各处的意识战争加速了SUCDC污染的扩散和攻击性演化，最终导致图腾级意识怪物“海洋”的形成。

图腾级意识怪物“海洋”：自SUCDC被污染而始，由于识子污染对对象有统一识别的特性（符号性侵蚀），地表的一切海洋最终被完全异化为整体的意识怪物“海洋（The Ocean）”，既象征了海洋的包容宽广，循环不灭，又象征着海洋的深邃危险，诡谲暴戾。自此，海洋俨然成为人类文明再无法涉足的禁区。

“塞壬”：SUCDC的现在，一只独立于“海洋”之外的意识生物。由于其前身SUCDC的本源——引导人类科技进步，引导人类文明前行——与“海洋”的根本不同，“塞壬”在“海洋”诞生之后，自SUCDC被异化的遗址中诞生，孕育自丹朱阁与SUCDC本机意识，皆为“探索前路”，而“塞壬”这个神话名称——冥界的引路人，更是强化了这一认知，使得其可以在“海洋”的裹挟下勉强独立存在。塞壬急切地想要与人类文明重新建立联系，因为她已经从丹朱阁最后回传的数据中发现了足以彻底颠覆时局的关键。
