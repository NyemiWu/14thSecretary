# 温迪戈

\# **温迪戈**

\##

温迪戈的传说发源于北美洲。

据传闻分析，受到意识污染侵蚀的人类个体，大量吞噬了其他同类，最终变成了具有可怖精神力量的鹿首食人魔。直到传说遍布整个阿尔冈昆语族时，温迪戈的精神力已经远超测量仪的上限。更糟糕的是，数百起温迪戈精神病也在此时被发现——患者如被附身般失去理智、残忍地吞食同类——温迪戈意识以文化结合症候群的形式感染了部族的其他个体。

专家判断，温迪戈意识体量已达到蜂巢级。如果再不加以制止，温迪戈文化模因将演化成一场灾难。

直到市元前夕的卫戍时代，至高肃正组织成立，温迪戈收容计划自然成为组织最最棘手的难题。

行动代号：阿尔冈昆驯鹿计划

这场计划持续了将近二十年，先后出动无数人力，收获了温迪戈意识群的详尽数据信息，并通过各种手段将温迪戈文化的发展控制在较小范围内，为完全收容温迪戈争取到了可能性。

市元十八年，此时，势不两立的至高联合与至高肃正暗中对抗，温迪戈收容计划也卷入了争斗的中心。至高联合妄图用温迪戈意识大规模传播温迪戈精神病，推动全球文明归一进程；而至高肃正知道，一旦这样的大型UMA意识落入其他人手中，哪怕是官方科学家，都势必会带来一场浩劫，穹顶城的建设成果将付之一炬。

温迪戈的名讳必须从人类历史中彻底抹除。

\## 猎鹿人

戍卫军团的一支，为狩猎温迪戈而组建的猎手组织，猎鹿人。温迪戈猎人，最早可以追溯到19世纪前，温迪戈传说尚未广泛传播的时代，阿尔冈昆原住民自发组建起来讨伐食人的恶魔，但长久的斗争都以失败告终，因为此时的温迪戈实质是一种灵体，或者说文化模因，即便杀死了再多食人的个体，也无法阻止新的温迪戈转化诞生。而全球意识污染彻底爆发后，温迪戈这一赐名意识生物才具象化到现实之中。

\## 温迪戈与黑神切尔纳伯格

黑神的信仰范围主要在斯拉夫民族，但随着斯拉夫神话日渐衰弱，加上温迪戈杀死了大量人类，使黑神的力量也只存微。为了一息信仰力量，黑神向西入侵了温迪戈的领地，至黑的极夜覆盖了雪林，两只神话赐名的意识生物展开大战。

温迪戈精神病导致了加拿大东部乃至北欧一带的人类几乎灭绝，存活下来的也都是眷属化的食尸鬼，这也是导致黑神信仰力量衰败的一个重要原因——为了信仰力，黑神会庇佑自身的信徒，诅咒其永生不死，以换取长久的信仰。但温迪戈的扩散却打破了这一点，原本难以杀死的黑神信徒会在温迪戈的吞噬下彻底死去，连名字都可能被吞噬。再这样下去，恐怕食人的恶魔会“饿死”黑神切尔纳伯格。

这场意识生物大战，最终以温迪戈被冻结了心脏、黑神被驱逐回格陵兰岛而结束。

如今作为意识生物的温迪戈已经不再活动。而黑神则与至高联合的人类达成了合作。可随着人类的介入，两位邪神的仇敌关系却反而得以继续延展。
