# 意识生物概述

意识灾害伴生生物（简称意识怪物/**意识生物**）：最基础的意识生物是由自然生物（也包含一些无机物）受到意识污染影响而变异来，随着污染程度加剧，其原生自然特征也会愈发扭曲，最终变成有赐名的、难以名状的高等生物。现存最高为图腾级，预测最高为启示录级。

也有一部分意识生物是由各类超自然意志现象产物得来，而不是以自然生物为基础。但绝大部分意识生物最终都会寄宿到载体上。

具有碳基生命性质，可以被火器压制，会不断重生，解构任何存有“意识”的素质，即一切文明造物，然后变成新的怪物。在物质身体毁坏后，意识会游离并寻找其他宿主，只有从意识之海中杀死它，并彻底焚毁脑、神经等意识器官，才可能完全消灭。而同时，意识怪物的进攻手段可能并不会看上去那么“激进”，它们会有像野兽或是怪兽一样的撕咬，横冲直撞和肆意破坏，但大多数是“无声的吞噬”和“侵蚀”甚至“同化”，不带有半点“敌意”地席卷大陆。在戍卫军团时期结束后，随着科技进步，人们发现不需要用火焚化意识生物的躯体也可以将其杀死。

纯粹的意识能量现象通常不被视作意识生物。 没有寄宿载体的游离意识（幽灵、意识风暴、暝啸等）不能完全算作生物。

意识生物催生于强大的执念，这种执念本质同样是“对于某种符号规则的坚定认知”，所以在意识污染的影响下，这种执念成就了现实——形式则是意识生物。而其中一些强大的意识生物，将会发育至“**赐名级**”，链接一个可以被认知的特定符号，并享有该符号所牵连的规则律。比如神话传说中的怪物名。或是某种物件。围绕这些赐名，有专门的职业负责研究它们，比如测名师，或是祓除名讳的肃正者、颂读者。总的来说，杀死一般的意识生物需要同时斩杀其物质躯体和意识体，但即使这样做，赐名级别的意识生物依然会以同样的名字重新降临在世界上任意一个地方，所以需要至高肃正这样的组织用逆模因手段专门祓除其名字，让赐名从人类文化里彻底抹去，才能避免赐名再临。

**图鉴**

**矮支原体：**被发现的第一类具有物理实体的意识生物。细胞结构难以辨认，行为模式呈现出动物、植物、真菌、原生生物、真细菌的特点，生理依赖能量源不明。宏观形态特征多样，无显著可归纳特征。多存于各类人造物表面、结构内部，当矮支原体以此种模式存在时，呈现出与其攀附的人造物同样或类似的物理外表特征和部分物理属性，遭破坏后变化为无色半透明粘液。少量存在于野外，此种模式下存在的矮支原体会模仿当地生态链底层种群的行为，物理外观和特征，应激后变化为无色半透明粘液。矮支原体人工培育困难，因此其他特征尚不明确。目前暂未取得矮支原体对人类有危害性的直接案例，但仍需警惕其潜在风险。

**亚支原体：**在矮支原体种群中少量发现的意识生物聚落。与矮支原体特征类似，缺少明显细胞结构，呈现出多界生物的混合特征。与矮支原体不同点在于，亚支原体在非拟态状态下也具有一定的生物刺激反应。在拟态状态下，拟态非生物物质时，具有更高的物理特性模仿水平；拟态当地生物种群时，倾向于拟态低级捕食者种群，但生活习惯异常。例如：拟态为蜗牛的亚支原体却具有蚂蚁聚落的行为特征，且会出现捕食行为。亚支原体在拟态变化时，应激反应会导致其变化为无色半透明粘液，与矮支原体不同点在于，亚支原体聚落形成的粘液有明显的趋光性或避光性运动特征，在光刺激合适的条件下，会倾向于向拟态过的种群(或人造物)移动，并尝试重新拟态。目前暂未取得亚支原体对人类有危害性的直接证据，但其行为特征相较于矮支原体，更应注意其潜在风险。

**赐名意识生物**

**温迪戈**

北美洲阿尔冈昆传说中食人的恶魔，拥有强大精神力量，永远无法满足于吞噬同类的欲望。大规模传播温迪戈精神病。如今是仿生人琳的奇美拉意识嵌合体，象征吞噬同类的动物性本能，使得琳极其擅长杀死、模仿和吞噬其他仿生人。

**黑神-切尔纳伯格**

图腾级赐名意识生物。极寒、极星与黑夜之神。意识污染现象-北极癔症的根源。导致西伯利亚穹顶城濒临覆灭。其行迹被发现于北极圈的格陵兰岛至俄罗斯西北一带，但是从未探测到其本体的确凿存在。北极癔症的规模正在往北欧乃至俄罗斯持续扩张，根据患者的口述，他们会在发病时看到“魔鬼”“邪神”的身影，以及高悬在黑夜里的极星。

一份关键研究推测，黑神曾入侵加拿大北部，疑似与另一图腾级意识生物温迪戈争斗领地，这一事件导致同时期的北美洲出现温迪戈精神病和北极癔症并发症候群患者，并为温迪戈的消匿提供了解释。有关二者接触的调查直到穹顶城时代仍在继续。

黑神切尔纳伯格与白神贝洛伯格是对立关系，斯拉夫神话的善恶二元与波斯神话有相似之处，同属于东印欧神话体系。

《黑神颂》：含北极癔症在内的黑神症候患者所颂唱的意义不明的词句

黑神向西扩张时遭遇了温迪戈并爆发信仰战争。结果是黑神冻结了温迪戈的心脏，但自身也被温迪戈所创。黑神的信仰力量是日渐薄弱的，而彼时的温迪戈作为以精神力量见长的意识生物，已经通过文化结合症候-温迪戈精神病吞噬了加拿大东部的大部分人类意识，造成了可怖的食尸奇观。

黑神会通过剥夺信徒的“死亡”来获得恒久的信仰，信徒会被转化为求生不得求死不能的永生形态。而温迪戈强大的赐死性与之形成了激烈的对抗，因此二者虽同是传说中的邪神，但彼此却是竞争性、排异性极高的宿敌。

**帕祖祖**

帕祖祖（Pazuzu）是源于苏美尔神话，常见于美索不达米亚与亚述的病魔，配偶为同属病魔的拉玛什图。其形象具有犬脸、额上长角、凸出的眼睛、鳞片状皮肤、四根鸟翼、老鹰脚爪与狮首特征，部分造型包含蝎尾 \[2\]。该角色在影视作品《康斯坦丁》中登场，《鬼泣3》的贝奥武夫角色造型参考其特征，《康斯坦丁》剧情通过召唤帕祖祖对抗拉玛什图。

帕祖祖作为东南风风暴神，其携带的波斯湾热风被视为高烧病因。苏美人通过咒语和驱魔仪式防范帕祖祖，但也利用其威慑力驱逐弱小病魔，并在儿童房摆放雕像以保护家庭免受侵扰 \[2\]。卢浮宫藏像未显蝎尾，展现其形象多样性。

**桥姬**

半张脸美丽，半张脸丑陋。其规则律为：跨过桥的人/物将会落水。桥和水并不一定是具象的桥和水。可能是天桥，甚至彩虹桥。解法为拆桥

桥姬（はしひめ）是日本传说中栖息于桥畔的女性水鬼或水神，兼具厉鬼与守护神双重属性 \[1\] \[4\]。其形象源于痴情女子投水化鬼的传说，核心版本为宇治川女神因恋人离别或被夺所爱投河，死后化为厉鬼加害过桥者，常见行为包括夜诱男子溺亡、因嫉妒拖拽美貌女子入水 \[1-3\] \[6\]。

不同文献记载其形态与起源存在差异：江户时代则与私娼形象关联 \[2-3\]。鸟山石燕《画图百鬼夜行》描绘其暴雨夜现身，发燃嫉火半隐水中，桥桩象征其桥梁之神属性 \[1\]。

桥姬传说反映日本传统婚恋观与女性命运，其执念与怨恨成为文学经典母题，并衍生婚礼改道避邪等民俗禁忌 \[3-4\]。该形象亦被解读为对人性悲剧的隐喻，体现古代社会对女性悲剧的认知
