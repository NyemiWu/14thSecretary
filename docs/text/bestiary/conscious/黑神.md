# 黑神

\# 黑神-切尔纳伯格

图腾级赐名意识生物。极寒、极星与黑夜之神。意识污染现象-北极癔症的根源。导致西伯利亚穹顶城濒临覆灭。其行迹被发现于北极圈的格陵兰岛至俄罗斯西北一带，但是从未探测到其本体的确凿存在。北极癔症的规模正在往北欧乃至俄罗斯持续扩张，根据患者的口述，他们会在发病时看到“魔鬼”“邪神”的身影，以及高悬在黑夜里的极星。

一份关键研究推测，黑神曾入侵加拿大北部，疑似与另一图腾级意识生物温迪戈争斗领地，这一事件导致同时期的北美洲出现温迪戈精神病和北极癔症并发症候群患者，并为温迪戈的消匿提供了解释。有关二者接触的调查直到穹顶城时代仍在继续。

\## 北极癔症

主要表现为病人突然尖叫，撕扯衣服，脱掉衣服，模仿某种动物或鸟叫，在雪地里打滚，乱跑。发作后一如常人，可有遗忘。主要分布于北极圈内爱斯基摩人与北西伯利亚族群中，通常是妇女，急性起病，持续时间一般为1-2小时。有时患者会用陌生语言歌唱、合唱，或是表现出类似拉塔病的模仿他人动作语言的行为。

关于北极癔症的病因有多种学说，如纬度、气温、极夜、极光、北极星或是邪灵影响。

\## Ever dying,never die.

黑神切尔纳伯格与白神贝洛伯格是对立关系，斯拉夫神话的善恶二元与波斯神话有相似之处，同属于东印欧神话体系。

《黑神颂》,含北极癔症在内的黑神症候患者所颂唱的意义不明的词句

黑神向西扩张时遭遇了温迪戈并爆发信仰战争。结果是黑神冻结了温迪戈的心脏，但自身也被温迪戈所创。黑神的信仰力量是日渐薄弱的，而彼时的温迪戈作为以精神力量见长的意识生物，已经通过文化结合症候-温迪戈精神病吞噬了加拿大东部的大部分人类意识，造成了可怖的食尸奇观。

黑神会通过剥夺信徒的“死亡”来获得恒久的信仰，信徒会被转化为求生不得求死不能的永生形态。而温迪戈强大的赐死性与之形成了激烈的对抗，因此二者虽同是传说中的邪神，但彼此却是竞争性、排异性极高的宿敌。
