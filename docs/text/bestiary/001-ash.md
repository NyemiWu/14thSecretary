# 001 · 灰烬中的某物

<div class="entry-head">
  <div class="entry-seal">L 多神 牧 火</div>
  <div class="entry-name">守烬</div>
</div>

## 观察记录

一具半塌的躯壳，表面覆着冷却的壳，壳缝里有暗红的光一直闷着。

!!! abstract "形态摘要"
    - 不主动攻击，受击后退让
    - 壳下持续闷烧，从不熄灭
    - 无召唤来源，自主选择出现的时辰
    - 触碰可封闭伤口、接续骨骼
    - 经过处木质炭化、石质开裂；遇水剧烈收缩

## 四段秘语

| 段 | 秘语 | 判定依据 |
|---|---|---|
| 一 · 倾向 | `L` 秩序 | 对靠近的活物没有敌意，被砸只是退开半步 |
| 二 · 性 | `多神` 主动 | 无人召唤，出现的时辰由它自己挑选 |
| 三 · 途 | `牧` 牧师 | 触碰令伤口闭合、断骨接续 |
| 四 · 显 | `火` 焰 | 经过处炭化开裂，遇水剧烈收缩 |

## 四段式真名

1. 它没有扑过来。它站在灰幕后面，只是把那团火压低了半寸，像是怕烫到你。
2. 它本可以熄掉 —— 熄灭对它而言不过一次呼吸。但它选了不息，继续烧着。
3. 伤口上覆了一层薄薄的焦痕，血止住了，痛也跟着止住了。
4. 它把手心拢起来。那不是取暖的姿势，那是在 **守烬**，守着一点不肯熄的东西。

!!! success "锚定结果"
    **赐名：守烬**

    干扰候选：`灰幕` · `不息` · `焦痕`
    真名出现在**第四句** —— 只有那一句在"宣告"它是什么。

## 测名线索池

对象每抗拒一次，多暴露一条。共 6 条，按阶级依次释放。

1. 它对靠近的活物没有敌意。有人用铁棍砸它，它只是退开半步，等那人走远。
2. 它的壳是凉的，可壳缝里一直有暗红的光在闷着，从没有熄过。
3. 没有人召唤它。它出现的时辰，是它自己挑的。
4. 它把手按在伤口上，血止住了，断掉的骨头在里面接了回去。
5. 它经过的木头会炭化，石头会开裂；可它一碰到水就剧烈收缩，像是被烫到。
6. 它从不猎食。它只是等 —— 等有人受伤，然后走过去。
