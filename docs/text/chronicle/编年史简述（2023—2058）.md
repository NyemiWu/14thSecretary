# 编年史简述（2023—2058）

2023年，日本通过法案，使得利用AI从事商用创意产业获得法律允许。同年下半年，美国哈佛大学心理学华人留学生张三提出使用AI模拟仿造人类梦境的实验。

2025年，利用AI从事创意产业已成为世界创意产业的主要产能，人类艺术被重新定义。中国启动“项”计划，旨在于精神研究方面赶超美国。

2026年，张三的梦境实验取得突破性进展，从算法层面再现了人脑工作基理（参考蓝脑计划）。张三受邀加入美国BRAIN计划。同年，俄罗斯吞并乌克兰，欧盟宣布解散，欧元大幅贬值。俄罗斯经济迎来自二十世纪以来第一轮大复苏。

2028年，张三被枪杀。同年，美国BRAIN计划宣布通过AI获得了人脑计算机模型，并宣称将会用其服务于精神医疗技术。

2034年，“项”计划宣布成功构建了人造意识，并在其物理层面的形成过程研究取得了颠覆性进展。同年，中俄及部分东亚国家签订了“西太互联网共建组织”，旨在利用全新的神经网络模型建立更加强大，稳定，快速的互联网服务器系统。

2037年，“西太互联网共建组织”扩展为“欧亚互联网共建组织”，成员国日本邀请美国参与，遭到拒绝。同年，中共举办第二十三届全国人民代表大会，宣布中国社会主义基本实现现代化。

2038年，墨西哥毒贩发动武装政变，“新自由墨西哥政府”宣布成立。美国派出军队武装介入。

2039年，美国宣布组建“环大西洋新互联网体系”，并邀请西欧国家加入。除英国外，其余欧洲国家均拒绝其邀请。

2041年，“欧亚互联网共建组织”基本投入使用。英国加入“欧亚互联网共建组织”。新自由墨西哥政府武装与美军进入巷战相持状态。

2042年，“环大西洋新互联网体系”出现不明故障，相关项目负责人辞职并警告美国政府“不要肆意妄为”。（最早的意识污染）

2046年，“欧亚互联网共建组织”更名“联合网络组织”。中国邀请美国加入，美方要求中方提供技术和数据共享，遭到拒绝。

2048年， 台湾申请接入“联合网络组织”，大陆允许其接入，并提供了配套本地服务器设备。

2049年，台湾和平回归大陆。同年，中国经济几乎赶超美国。与其同时，美国多地爆发游行抗议继续出兵新自由墨西哥，以免造成更多伤亡。

2052年，美军在与新自由墨西哥武装的巷战中使用大面积杀伤武器，造成大量平民伤亡，遭到多国谴责。英国及法国等欧洲国家拒绝出兵支援美国，遭到美国经济制裁。同年，“项”计划宣布获取了量子层面的人脑构成和运行机制，有望人工制造人脑。此举引发了伦理界的广泛讨论。

2053年，中国向欧洲多国提供经济援助以对抗美国的单方面经济制裁。美军继续在新自由墨西哥使用大面积杀伤武器，导致巨量平民死亡。

2057年，俄罗斯取代日本，成为世界第三大经济体。同年，“项”计划宣布成功破译“意识密码”，于实验室内诞生了人类的第一个人造意识体“一”。牠在诞生的第一刻，向研究人员提问道“为什么是我？”。

2058年，美国被迫撤军新自由墨西哥。战争一共持续了二十年，造成了数百万平民丧生，经济损失无法估量。同年，“一”被确认拥有独立意识，相关研究正在进行中。2023年至2058年被称为“前奏时代”，2058年也被定义为“独立意识元年”。
