# 穹顶政联

穹顶城建成初确立的政治制度、当前最高政治权力机关，由城内社会各界代表构成的穹顶城市政治联盟，共同商讨、确立城市政治发展规划。

政联成员需要对收集民意的民调机器“一号”负责，而衡南法庭负责作为一号的代理监管政联成员、并主持峰会。在峰会上提出的提案，将先经过政联投票表决，通过后，再由一号广播到全市公投系统进行民主投票。

**峰会（summit conference）**

四年一次，各界先锋或代表出面参加，旨在讨论重要的政治、经济或社会问题，并寻求解决方案。

政联名单内的每个组织将派出一名代表与两名秘书作为出席人。

城市初期恐怖主义盛行时，峰会曾遭到恐怖组织黑神党的蓄意破坏。

27年峰会：

最重要的目标是建立十四号城的正式政府来代替临时政府和政治联盟制度。如今，城市的民众都已安顿，设施都已建立，临时政府也该大刀阔斧的改建了，况且恐怖主义苗头越发猖狂，必须立刻决策出新的、完整的政府机关来整顿现状。

启明的父亲——时任星枢学会会长出席。遭到黑神党的模因武器仿生人破坏，场面陷入暴乱，国安委派出特工教官叶莲娜与其仿生人特工前往现场，最终叶莲娜牺牲自己，将黑神党改造的武器仿生人领航至迷失，阻止了黑神党的恐怖袭击。事后，仿生人方槊独自寻仇肃清了黑神党。星枢学会会长遭受了意识武器影响，神智有些混乱，而黑神党背后的真正势力——至高联合，此时也已经渗透了学会，借题发挥要将会长拉下马，洗牌学会，宣扬历史虚无主义和进化归一论。至高联合的浮出水面被会长的女儿启明所觉察，但也没能改变父母撤职、郁郁而终的结局。

峰会遭到破坏，建立政府的计划受阻，不久后临时政府也在恐怖袭击下瓦解。穹顶政治联盟这一制度只能被迫延续。

31年峰会：

确认超氧公司作为民营企业代表加入穹顶政联。

35年峰会：此时启明本人完成了河管办的监护工作，在结局处理白淇时便向超氧提交了辞呈。这一次峰会，她作为会长代表星枢学会出席，实际是要以身入局钓出至高联合这条大鱼。她深知至高联合的无政府主义作风，因此故意放出了消息——星枢学会将在峰会上提议重组政府机关，以此确保至高联合的矛头对向自己和峰会。

峰会讨论事项：《超氧：关于让巨门公司作为军工集团代表加入穹顶政联的提案》，《商会：关于将警局在政联的席位合并到衡南法庭的提案》，《学会：关于重组政府机关的提案》

超氧提出，当今的十四号城社会并没有完全走出意识恐怖主义的阴影，潜在的危险依旧不可轻视，而巨门公司作为一家硬核的军事工业企业，成立初致力于为城市官方武装提供强有力的保障，得益于此，不论是戍卫军团或是警局都可以更有效地解决冲突（实际并没有，巨门几乎从未与军团和警方合作）。另一方面，巨门这样的大型军工企业也需要在政治话语中得到引导和约束，从而更好地服务于穹顶城。经过商讨，该提案最终通过政联表决，等候着面向最终民主投票。

当商会代表的关于警局席位变动的提案提出后，超氧代表竟然首先提出了反对，讲述了警局为保护民生与企业做出的牺牲与努力，在开源帮事件中保护了超氧集团等民营企业的重要财产（其中还包括涉及到仿生人的机密），超氧代表民营企业与百姓对警局表示了高度赞赏。由于涉及仿生人的公共认知保护功劳，因此城市认知监察（至高肃正）也没有理由赞成除名警局的政治权力，也投出了反对票。衡南法庭作为变动牵涉对象之一，不便表态，弃权。星枢学会已经察觉到个中蹊跷，弃权。新戍卫军团（包含地下反抗军势力锈火）知道，警局作为城内防卫势力，实质上是与自身地位利益冲突的，削减其权力对自身不无好处，再加上军团与超氧立场处于对立，于是表示警局与法庭合并有利于司法系统执行的高效统一，投出赞成票。来自白氏制药的医药联盟代表与商会已有串通，为了保护自己的地下药物走私链，拿出警局的内部腐败丑闻，对警局性质提出质疑，投出赞成票。

而就在峰会讨论到焦灼之时，场外传来激烈的躁动声......超氧导演的第二幕戏码上演

混乱之际，启明等出席代表在安保护送下前往安全通道，但暴徒也已袭来，而她惊讶地发现，河管办的三个仿生人少年少女前来救下了她。在护送下来到场外，那里更加混乱不堪。各方势力此时都出现在了现场。

不可思议的是，暴动的源头是至高联合投放的仿生人。这也给之后超氧投放昆山杀手消灭仿生人提供了强有力的理由。

峰会暴动中，警局虽出动几乎全部警力，但碍于科技和人力依然不足，还是陷入被动，而此时，神秘的超氧超级士兵小队出现，靠着强大的装备和素质迅速完成了镇暴，在警局眼前保护了峰会，又在硝烟中悄然退至幕后。

**政联名单**

衡南法庭（由审判官铨作为一号的代理）

星枢学会（会长启明作为代表，副席索菲亚虽是秘书名义但也是“火力”重心，承担了大部分意见输出）

工会（工农联盟代表，与昆山派关系较为密切）

城市认知监察（即至高肃正）

警务（与衡南法庭同属于司法系统，日渐势微，一度被无视甚至差点除名于政联，合并到法庭）

民营企业集团代表（实际上就是超氧）

医药联盟代表（圣莱山德医院/白氏制药等）

新戍卫军团（边境防卫势力，而地下反抗军锈火是诞生于其中的一部分）

商会联盟

**超氧政治**

超氧公司抓住临时政府瓦解的风口，以强力的科技资源拿到了第一柄权力。随后镇压了觊觎政权的对手至高联合，又利用权力真空期拉拢政联成员，建立了自己的制胜联盟——巨门、警局、商会、医药，都与超氧站在了同一边。此时超氧在十四号城政权上形成了一家独大，唯一需要面对的对手只有作为民主政治机器的“一号”系统。
