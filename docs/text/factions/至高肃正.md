# 至高肃正

\# 至高肃正

组织：城市认知监察-【至高肃正】。抹消记忆，肃正认知，祓除传闻。

\## 组织信息

意识生物会通过信仰（本质是认知链）获得力量，坊间传闻的夸大更是会赋予意识生物难以对抗的生命力，还会使它向群体认知中夸大的形象转化。因此，城市认知监察委员会成立。

戍卫时代结束后，残余戍卫军团及世界军事力量的集合体，其存在目的在于继续清除可能威胁穹顶城根本安全的意识污染源和意识怪物。“塔罗牌系统”归为志高肃正管理，密级极高。志高肃正还拥有“全视之眼”系统，用于密切监控全球范围内的意识灾害波动，同时向志高肃正本部与“塔罗牌系统”提供预警数据。

行动旨在：

1、检测意识生物和传闻的出现，通过记忆删除、伪造事实等各种手段消除民间传闻，并杀死或收容意识生物（生物遗骸和意识碎片会被严加保管，严禁出售、转移给其他个人和组织）；

2、向民众隐瞒仿生人、危险意识生物等可能引起认知危机的存在。

3、回收因各种原因失容的意识生物，包括被加工成的奇美拉素材、以及以此制成的仿生人。

该组织的存在比仿生人还要神秘，他们的影子或许能追溯到世界大战时期，仅有少数能触碰到穹顶机密的人物才知晓 有这样一个可怕的组织在城市暗面践行他们的真理。

组织效力于整座穹顶城市，因此绝对中立、独立，有自己的管辖与法规。

组织内秩序森严，成员仅有人类和智械，等级越是核心的肃正者，越是自幼便会被专门培养，严格规范其认知，训练其能力。 训练有素的肃正者们经过了各种改造，能在武装智械的协同下打败意识生物或仿生人，

“找到你了，食人魔。”——肃正者见到琳时说的第一句话。

\## 现世之碑

来自至高天外的，铭刻现世业的高耸石碑。

至高肃正组织的行动核心，实质上是意识锚点上建立的超级算体，通过复杂原理计算、观测城市内的意识状态，监控认知，将重要数据具象化成碑铭。

至高肃正通过宗教仪式将全体成员的信仰绑定于现世之碑，以使石碑源源不断地获得意识能量，也使得肃正者们保持信息同步。组织的建立者撰写了一整套自洽的教义和宗教传说，也是旨在确保信仰的高度统一。

这种必要的政教同源结构使得至高肃正蒙上神秘的宗教色彩。

\## 哀恸面具

至高肃正研制的，用于有效镇压意识污染的个人防护用具。可以在短时间内让使用者不受意识污染的影响，但在使用后会导致使用者意识被抽离至面具内，物理躯体表现为变成植物人，甚至直接死亡。

配发至每个至高肃正的编内人员，作为最后的抵抗手段，宁死，也不向意识妥协。

仿生人使用哀恸面具会导致面具容器超载。短时间内仿生人会拥有自体领航能力，但会最终导致意识与物理的链接完全无效化，死亡，甚至变成意识怪物。

至高肃正后来开发了提取哀恸面具内残存意识的技术，可以利用被人类使用过的哀恸面具提取人类意识，并以此为意识基准生产仿生人。

\## 温迪戈收容

温迪戈的传说发源于北美洲。

据传闻分析，受到意识污染侵蚀的人类个体，大量吞噬了其他同类，最终变成了具有可怖精神力量的鹿首食人魔。直到传说遍布整个阿尔冈昆语族时，温迪戈的精神力已经远超测量仪的上限。更糟糕的是，数十起温迪戈精神病也在此时被发现——患者如被附身般失去理智、残忍地吞食同类——温迪戈意识以文化结合症候群的形式感染了部族的其他个体。

专家判断，温迪戈意识体量已达到蜂巢级。如果再不加以制止，温迪戈文化模因将演化成一场灾难。

直到市元前夕的卫戍时代，至高肃正组织成立，温迪戈收容计划自然成为组织最最棘手的难题。

行动代号：阿尔冈昆驯鹿计划

这场计划持续了将近二十年，先后出动无数人力，收获了温迪戈意识群的详尽数据信息，并通过各种手段将温迪戈文化的发展控制在较小范围内，为完全收容温迪戈争取到了可能性。

市元十八年，此时，势不两立的至高联合与至高肃正暗中对抗，温迪戈收容计划也卷入了争斗的中心。至高联合妄图用温迪戈意识大规模传播温迪戈精神病，推动全球文明归一进程；而至高肃正知道，一旦这样的大型UMA意识落入其他人手中，哪怕是官方科学家，都势必会带来一场浩劫，穹顶城的建设成果将付之一炬。

温迪戈的名讳必须从人类历史中彻底抹除。

\## 肃正者（Enforcer）

至高肃正的基层执行者，身披黑袍，仅用独臂。现世碑的碎片插入胸膛，再由意识传导链链接到唯一能使用的手上，使碑之意志凌驾心灵，在意识海中领航，肃正者即是执行肃正意志之手。
