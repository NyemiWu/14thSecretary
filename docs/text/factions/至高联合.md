# 至高联合

Ultra Union。本部在十三号城的宗教组织。恐怖主义，超人类主义，相信意识污染是生物进化的必要伟大进程。其扶持的数个恐怖组织多次袭击十四号城。

十三号城的建成晚于十四号城

至高联合的人实际上很精明，宗教是用来统治十三号城、给穹顶（女神模因）收集信仰的工具，他们研究自然意志和意识污染并寻找客观规律，所以某种意义上至高联合相信的是自然科学。但是他们对自然意志的片面结论有很大局限性，也因此说是邪教组织并不为过。

他们不知道，自然没有意志，只是直白地回应人的欲望。

早在意识灾害刚刚降临时就已经存在。对意识天灾的狂热崇拜者，认为文明应该接受意识污染，污染才是“净化”和“进化”，是万物的最终归宿与最终形态。其势力范围遍布全球，实质上或许才是人类文明需要面对的最大威胁。

起源

范瓦德（Vanward,先锋）十三号开拓联盟军，领导人努尔（Noor，女）

卫戍时代，范瓦德开拓军完成筑城的伟业，在权力分配时，备受军民们尊重的开拓者、筑城者努尔却决定放弃似乎理所当然的执政权，（相当于解散开拓联盟）想过上普通生活。为了开拓联盟顺利执掌城市政权、享受胜利果实，联盟内右派发起政变，想要胁迫努尔上位执政。然而在政变混乱之中 努尔遭到暗杀。

努尔的死没有浇灭右派的疯狂，反而将局势推向万劫不复。狂热的他们不仅扭曲了努尔死亡一事，还给第一批市民钉入思想钢印，使他们相信着、歌颂着“筑城女神努尔”的存在。

经历一系列内部清洗后，范瓦德开拓联盟最终发展成了至高联合，其领导人正是发动政变的同僚。他本来由衷希望努尔执政，由衷希望十三号城的市民世代感激她的贡献，永远铭记开拓联盟这一伟大共同体——直到努尔被暗杀那日，他对人性彻底失望，他只看到一群生啖饮圣女之血肉的秃鹫。

也因此，至高联合真正信仰的是自然意志，或者说意识污染的宏大生物进化进程，秉持超人类主义的优越，鄙视传统模式的人类文明。

城市建成前的夕阳下，四十一岁的努尔对同僚敞开心扉，她说，自己最大的梦想是想养个孩子，当个普通的母亲。

联盟四分五裂的那天，她倒在血泊中，亲眼看着自己的“孩子”们相互厮杀。

如今，她年轻时的样貌永远留在了祭场中央的筑城女神雕像上。

她值得永远为市民铭记，但绝不是以这种方式。

筑城纪念日，十三号城的第一批市民手捧鲜花，夹道欢迎努尔和开拓联盟向市中心的行队。然而，他们等来的军车上不是筑城者的英姿，而是一台黑压压的模因炸弹。

仿生技术哲学

能生产、使用和维护仿生人的主要势力有三个：超氧、仿研所（前安委会）与至高联合。三大势力分别有三种核心理念：社会化，军事化，宗教化。

超氧制造仿生人的最高图景是最专业、功能最强大、最具服从性的绝对武器，有森严的等级与精密的编制，可以完美应对最剧烈的冲突与最严重的灾害，也因此超氧希望让自己的仿生人产品以高调、强大的姿态面向世人，不过碍于城市认知管理协议暂时无法实现。

仿研所的注重点更倾向于仿生人的功能，让仿生人随时以自然的姿态快速响应需要他们出手的事态，仿研所的构想中仿生人散布在社会的方方面面，既是解决问题的秘密专家、也是社会生产的一份子。

至高联合研发的仿生人是作为宗教工具、或是对政治兵器而诞生的，于前者，仿生人本身将会是公布于众的宗教象征，以超人类或是神明的身份推动至高联合统治民众、达成全人类意识污染化的最终目的；于后者，让仿生人的意识交互有效颠覆敌人或异己，是他们从三战延续至今的仿生技术哲学。

三种不同的理念也导向三种不同的仿生人迭代目标，以及仿生人的三种姿态，而这三种蓝图之间也会彼此影响，让仿生人具备复杂的多面属性。

三战前，导致三战彻底完全爆发的恐怖组织并非至高联合，而是至高联合的名义前身“进化联盟”。

气态浮力生命科技有限责任公司

Gaseous Floatation Life Technology Co., Ltd.

（GFLT）

gaseous floatation（气体浮选）是工业运用中常见的一种固体颗粒筛选方法，又称为泡沫浮选，利用液体中不同固体颗粒对液体内气泡表面的亲和力差异实现固体分离。GFLT选择此作为其公司名称，暗含了该公司“试图筛选文明”的精英主义取向。

中文翻译弱化了该公司的实际目的——利用其独有的“意识海气泡”技术筛选意识体，并借由此技术，按照它的逻辑来“净化文明”。

GFLT是最早将意识海及识子应用技术接入产品的生命科技公司，其早期拳头产品即以初代SACA装甲为代表的一系列广泛应用识子技术的军工产品。这使得GFLT在三战期间迅速敛财发展，甚至从一个商业实体陡然跃升为政治实体，成为新体系下的“新贵族”。而随着三战结束，人类文明凝聚起来并将意识污染视为最终的敌人与唯一的斗争对象，GFLT的各类核心技术被现有的人类政体迅速挖掘出来并“充公”，使得GFLT的商业大厦顷刻之间化为齑粉，其地位由于其本体的被瓜分而一落千丈。

GFLT的残余势力为了对此复仇，带着GFLT剩余的大量技术、设备乃至于正在研发中的各项危险技术加入了恐怖组织“进化联盟”，并将其更名为“至高联合”——此时的GFTL对人类文明的“净化”欲望，已经成为了它眼中的悲悯——“与污染同化，拥抱意识才是文明的最终模样”。

GFTL对识子技术的激进应用使得该公司早在三战之前便已实现“意识统一化”，即该公司内的个体将无意识地趋同于GFTL的“集体意识”，而GFTL则已经具有类似于蜂群意识的存在形式，并由其内部全部力量构成最“具有实体感”的经济和政治实体。

最终GFTL残余势力并入进化联盟并发展为至高联合后，GFTL本身已然成为“意识污染”的代理人，将其集体意识作为思想钢印，以更强硬的形式彻底控制其下所有有生力量，并再无“个体”的区分，只剩下“我者”与“他者”——前者均是我，后者均是“我将给予怜悯的蒙顿之物，而我将布下主（意识污染）的慈悲”
