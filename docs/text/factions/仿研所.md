# 仿研所

穹顶仿生科技研究所：简称仿研所，与蓝山事务所联系密切，提供全城唯一的仿生人医疗救助服务，并向蓝山事务所收取各类情报作为报酬。仿研所原为设计制造仿生人，为戍卫军团提供不断升级、不断优化的仿生人部队的科研机构，在穹顶城合围后，仿研所原有职能因仿生人武装禁令而废止，转为主要研究仿生人与意识污染的深层联系，以及提供仿生人医疗服务等工作。在此中，仿研所掌握了几乎全城所有仿生人相关的部署情报、资源情报、力量情报，同时作为多次替蓝山事务所执行隐秘任务的手套机构，实际上保存了为数不少的武装力量，具有推翻超氧统治的潜力。

主角团所在，从事意识科学研究与仿生人制造的研究所。仿研所是一个包含附属学院和武装力量的综合机构，有预防、清剿、讨伐意识生物及伴生灾害的职责，拥有对意识作战的丰富经验，人才众多。同时也是某些意识生物的收容所。

仿研所是一个理想主义色彩较为浓厚的组织。

仿研所分七大分所，履行不同的职责，研究范围也不同。人员编制相对灵活，流动性强，联系密切。

**仿研壹所**：总部，研究中心，理论科学，意识学，仿生人设计、制造。是奇美拉意识嵌合手术的发源，且与星枢学会共同研发了如今的意识空间技术。

**仿研贰所**：清剿，讨伐，武装作战。含若干作战型仿生人及领航员，昆山，琳&芊所在。

仿研叁所：装备，战备，机械，后勤，产品、武器设计制造。有训练场、靶场和武馆，还有存放智械的格纳库。天琴，时雨蝉所在。

**仿研肆所**：信息处理，数据，统计，分析，预警，运维，社会工程。是信息技术部门，肆所的人员通常足不出户。所长：珂博奥。

**仿研伍所**：行政，信息收集，调查，教育，招聘。**仿研所附属学院**是由仿研所和星枢学会联合创办的，其成立也是为了纪念双方多次合作，而伍所本部就位于学院中，也可以说这所附属学院就是伍所。学生家长投资的建设费也是仿研所的一个重要经费来源。

**仿研陆所**：意识生物处理，善后清理，意识素材运输，意识污染管控，消防部门，清道夫。“意识灾害发生时，要第一个到达现场，也要最后一个离开现场”。疏散人群，配合工作，打扫现场，在社会眼中是一群穿荧光防护服的消防员。陆所人员通常没有固定居所，而是在城市各地的机动载具据点中待命、巡逻。

**仿研柒所**：生物，医疗，生命科学。意识生物拉斐尔的收容所。是从仿研所原医疗部独立出去的新机构，其工作性质导致该所的大部分工作是高度保密的，连仿研所其他领导人也无从得知。风蕊所在。

合作流：仿研所各所的合作是紧密且复杂的。壹所制造仿生人，伍所培养领航员，二者搭档。意识污染发生时，首先由肆所发出警情，陆所消防人员会直接抵达现场，帮助双子这样的专业斥候前往实地勘察，收集信息，传回肆所进一步分析评估，如果灾害较小则由双子直接解决，灾害较大则加以控制，等待贰所的武装人员抵达。贰所完成清剿，陆所会在污染指数安全后清理现场，并将意识生物或碎片带回仿研所处理。贰所的武装人员则接受柒所的治疗，叁所人员会根据战况调配战备资源，补给作战人员。

人员情况：

双子想待哪儿就待哪儿。每个分所都有给她俩放书包的专用小柜子。

昆山既是仿研所的领导人物，也是仿研所的收容对象。

琳和女二属于贰所叁所来回跑。叁所的武术陪练时雨蝉非常不待见她俩。

女二、闫洇浮和风蕊是附属学院同班毕业的，其教授是现在的柒所所长。

女二两次来到伍所的招生招聘办公室，都是在最落魄的时候。

风蕊毕业后前往圣莱山德医院作为护士实习，然后仿研柒所成立，亟需人手，于是风蕊经由莱山德院长亲自推荐，回到仿研所担任疗养师。虽然属于柒所，但风蕊通常会待在贰所直接帮助琳这些一线作战人员。

伍所，有权力决定仿研所午饭吃什么。

肆所，实际上是围绕珂博奥建立的。

陆所，经常会和警局打交道。二者在现场分工默契。

星枢学会的部分成员是仿研所附属学院校友，某人更是学院的名誉校长（其实就是挂名校长）。

柒所遭遇过超氧武装人员袭击，领队者是闫洇浮与仿生人提尔锋。他们为拉斐尔而来。

六号、米娅等人的合同上既写明了合作内容，也规定了他们这类危险人士需要接受仿研所监管，尽管他们不隶属于仿研所。
