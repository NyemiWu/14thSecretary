# 圣莱山德医院  
St. Lysander's Hospital。教会式的意识诊疗医院。院长莱山德，专注于意识病诊治，然而他每次行善后，面貌都会如被诅咒般越发狰狞可怖，如今他在医院最深处的院长办公室里，只有护士长和几位顶级医生、药师得以见到他那恶魔般的模样和圣人般的心肠。
当然，有护士意外目击到过莱山德院长的样子，在恐惧、流言蜚语、捕风捉影等加工后悄然传开，“恶魔院长”俨然成为十四号城都市传说中赫赫有名的一个。
此事在十四号城网传的“十四号城冰山图”中亦有记载。  
##   
疗养师正是圣莱山德医院的实习护士，本就有些胆怯的她，有几日竟然被恶魔院长的传闻吓唬得不敢睡觉。而双子则对这种网络上大噪的传闻充满了兴趣，打算以探险的名义与伙伴前去一探究竟。  
## 硫磺疗法  
一种有争议的意识病治疗方案。  
## 临终关怀  
莱山德院长医术真正的核心价值，所谓医者仁心。
