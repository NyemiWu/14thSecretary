# 十四号城联合科学院

十四号城联合科学院(简称学院)：诞生于穹顶城之前，戍卫军团时代的顶级学府，主要研究意识污染相关理论。后因资源匮乏，学院合并，形成了现在十四号城联合科学院的庞大学术体系，并诞生了“常”作为十四号穹顶城的核心AI系统、“全视之眼”全维监测系统等尖端科技。但在穹顶城合围时间前后，其核心领导团体遭到至高联合渗透，学院被分为以启明教授为首的学院派和以安德鲁斯为首的联合派，后者不惜以流血冲突争夺学院主导权和科研资源，导致前者不得不从联合学院中分裂出去，单独形成了“启明学院”，并寻求和获得了超氧的资助。后者将原联合学院研究重心转向意识污染更深层次的探索，试图找到“彻底归化人类”的方案。在其意图暴露后，志高肃正武装介入冲突并派遣塔罗牌“女教皇”，成功剿灭至高联合渗透力量，启明趁机重新统一学院组织，调停派系斗争，并统一更名为启明科学院，但整个学院因此元气大伤，只能继续在超氧资助下维持运转，逐渐沦为超氧操控下的研究性机构。
