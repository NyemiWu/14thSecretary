# 商会

超氧的创立和辉煌，离不开商会的帮扶。超氧的创始人，赵某，借助商会的宗族势力，打拼数载，挣得创业的原始资本，又不顾宗族反对地，背井离乡，成立了一家新兴材料公司——超氧的前身。

在商会的大人物们借恐怖主义瓦解城市和平之势大发战争财的时候，是超氧的创始人抓住了风口，凭借过硬的技术实力解决问题、证明了自身潜力。

而后，顺利上位的超氧将商会一脚踢开，任那帮老资历对“赵家人”恨得牙痒。而在超氧看来，商会的没落正是源于其宗族老人们短视、守成、迂腐的官僚主义糟粕，终日沉迷于如何在权势的棋局中胜子，毫无实业精神可言。这样的格局持续到现在。

而商会的年轻一派也意识到了，父辈对科技的偏见和低估酿下了不可挽回的损失。于是那尘封的、围绕虹金改造人体的计划被再度重启。
