# 四段式真名

一组用于**精准定位对象**的"真名"。

## 定义

由「**四个秘语 + 真名**」组成：

| 段 | 内容 | 取自 | 说明 |
|---|---|---|---|
| 一 | LNC 倾向 | `L` / `N` / `C` | 对他者的基本态度 |
| 二 | 主动还是受控 | `一神` / `多神` | 是否具备自主意志 |
| 三 | 偏向于哪种手段 | `战` / `法` / `牧` | 能力表现的类别 |
| 四 | 表现属性 | `火` / `水` / `电` / `气` / `祝` / `咒` | 力量的外在形态 |
| 五 | **真名（赐名）** | — | 唯一，在短句中揭示 |

前三段是**范畴**，第四段是**形态**，第五段才是它的名字。

## 书写样例

!!! example "以「守烬」为例"
    **四段秘语**：`L` · `多神` · `牧` · `火`
    **真名**：守烬

    1. 它没有扑过来。它站在灰幕后面，只是把那团火压低了半寸，像是怕烫到你。
    2. 它本可以熄掉 —— 熄灭对它而言不过一次呼吸。但它选了不息，继续烧着。
    3. 伤口上覆了一层薄薄的焦痕，血止住了，痛也跟着止住了。
    4. 它把手心拢起来。那不是取暖的姿势，那是在**守烬**，守着一点不肯熄的东西。

    四句各承一段秘语，第四句揭示了真名。

## 写作规范

!!! abstract "硬性要求"
    四段式真名在书写时，需要有**四段包含秘语要素的短句**，
    并在**其中一句**揭示真名（赐名）。

拆开看是三条约束：

1. **四句**：不多不少，每句承一段秘语。
2. **可辨**：每句都要让读者能反推出它对应哪一段秘语。不能是"四句随便写写，意思沾边"。
3. **一明一暗**：只有一句把真名说出来。其余三句里可以放**形似名字的干扰词**，但都不是真名。

!!! danger "最容易写坏的地方"
    别把真名放在第一句。玩家的阅读顺序是从上往下的，
    真名先出现，后面三句就失去了悬置感，
    「锚定赐名」这一步也就没有意义了。

## 与秘语的关系

四段秘语是**检索键**，真名是**答案**。

- 秘语错了 → 测名进度不涨，对象会抗拒。
- 秘语全对但锚错真名 → 名字不成立，它脱锚离去。
