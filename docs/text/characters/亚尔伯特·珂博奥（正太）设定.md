# 亚尔伯特·珂博奥（正太）设定

亚尔伯特·珂博奥（Albert Corbeau），代称正太，男，仿生人，顶级黑客，被双子昵称“珂宝”“珂博”，理智而精通技术，在带学生与拍档的任务后，他受任务对象模因武器启发，打造了一种认知骇入武器，代号“冈格尼尔”——奥丁之矛。

正太的设定，他的参考原型是北欧神话奥丁，对应的，他有“福金”和“雾尼”两架浮游无人机，二者组合在一起是代步载具，类似浮空转轴滑板，这里参考艾克和绿魔，战斗中，两架无人机只有一架起飞，另一架会被正太握在手中防身。

福金是远程骇入型，可以一步步攻破范围内数字型敌人的防火墙，使其瘫痪易伤，也能发射各种弹头造成杀伤，当它被持握在手时，远程伤害更高，作用类似手枪和黑客密钥 雾尼是近战格斗型，可以撞击、突刺敌人，也可以造成范围时停场格挡攻击，被持握在手时，近战伤害更高，作用类似刀剑，生成护盾可以直接保护正太。

以上延伸出两种战斗风格，一是放飞福金，手持雾尼，浮游枪辅助+近战主力，先瘫痪敌人再近战处刑，这样可以最大化伤害，也可以利用时停护盾保护正太，时候对付数字型敌人，缺点是手短容易被动， 二是放飞雾尼，手持福金，这样可以远距离放风筝，用雾尼击退敌人，再用时停场加以控制，再用福金安全射杀或是骇入，缺点是不再有护盾贴身保护正太，一旦被群怪包围就会自身难保。

被动技举例：被雾尼时停的怪物，受到福金远程攻击伤害提升，被福金黑瘫痪的敌人，受到雾尼近战攻击伤害大幅提升

精神的长者，现实的稚童。
