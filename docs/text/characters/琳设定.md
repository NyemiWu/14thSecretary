# 琳设定

琳Lynn，ESFP，女，仿生人，外表是17岁少女，武器是单手刀。性格率真活泼开朗，总是用生动的表现和热情感染他人，希望获得搭档领航员（穆颖芊）的认可，为此会在一些小事上装出笨拙和不成熟，又在重要的战斗中拼上性命去争取表现。她的自我意识刚诞生不久，因此心智是从几岁的小孩开始快速发育的，心智发育速度约是正常人的二十倍。

奇美拉：鹿，**温迪戈。**意识交互：离神断魄（使对象的精神与躯体短暂分离，从而暂时晕厥），精灵（消耗大量意识能量，短时间内超频暴走，强化自身感知能力），吞噬者（来自温迪戈意识的恐怖能力，吞噬其他意识体并获得其一部分的意识能力）。琳的本质是大型反人类文明组织至高联合创造的、用于吞噬穹顶意识的容器。

诞生于穹顶城合围前的最后一名仿生人，吸纳了大量极为先进的仿生人技术及意识污染对抗技术，被植入名为“奇美拉嵌合体”的复杂意识器官，使得她可以在战斗和通常活动中不断进化和学习，同时具备吸收意识污染并由其所用的能力。诞生后，受到至高联合追杀而失控暴走，后由仿研所将其重置并收容，目前以普通仿生人的身份工作于仿研所一般武装小组。

Lynn的个人形象：一名看上去十七八岁，阳光开朗，性格活泼，身形窈窕优雅的少女。她偶尔会给人一种“单纯得有点笨手笨脚”的感觉，同时好奇心、同理心很强。金瞳，发梢带有渐变的青绿色。战斗时眼睛和发梢会有微弱发光。常用武器为一把生产于戍卫军团时期的小型军用横刀，轻便，锋利，后经仿研所改良，安装识子引擎后具有投入意识海作战，斩断识子漩涡的能力。Lynn后期逐渐变得成熟、稳重，独当一面。她的成长将贯穿整个世界观主线故事的始末。

琳-内摄

琳的学习能力：琳会无意识地继承杀死（吞噬）的对象的某些特质，这是一种内摄

她重创方槊后，她也习得了认知迷彩与潜行技巧，隐喻上是因为她吞噬了方槊的一部分。而方槊也因此在这一战后被削弱。

限制：躯体过载。琳可以通过这种办法习得几乎所有意识交互，但是同时掌握、使用太多会导致躯体过载。

琳是至高联合创造的，“吞噬穹顶的容器”。因此，绝对不能让琳接触到穹顶。伏笔：琳总觉得穹顶塔像个大桃子。

随着吞噬穹顶智能一号，温迪戈的骨面开始破裂，取而代之的是，只属于神的无瑕面容。

远方荒蛮的高崖上，塔洛玛蒂注视着闪烁着的十四号城穹顶，“十四号城的巨人，已经苏醒了。”

参考自绝命毒师

“他的气质来自那些他杀掉的人”

摄入（英语：Introjection）：或称内向投射，与投射作用相反。指广泛地、毫无选择地吸收外界的事物，而将它们变成自己人格的一部分。由于摄入作用，有时候人们爱和恨的对象被象征地变成了自我的组成部分。如当人们失去他们所喜爱的人时，常会模仿他们所失去人的特点，使这些人的举动或喜好在自己身上出现，以慰藉内心因丧失所爱而产生的痛苦。相反，对外界社会和他人的不满，在极端情况下变成恨自己因而自杀。内投射也可能是自罪感的表现，他们常常模仿死者的一些性格特点来减轻对死者的内疚感。内投射或仿同的对象，常是所爱，所恨和所怕的人，尤其是父母。

一学生对勤奋用功的女同学产生情感却未能表达，暗地里开始比她更用功。

看到人类残害动物，发现自己身为人类真是可耻而对自己感到憎恨，甚至有自残、自杀的行为。

雏鸟情结

琳对女二是有雏鸟情结的

琳会在小事上故意装作笨拙以获取女二的关注甚至嫌弃，而在重要的事情上又会不要命地去挣表现、渴望夸赞

在十三号城，女二一直寻找着治愈琳的方法。但同时，琳在暗中寻求一个完美的、无声的自杀，将自己从认知域中抹去，让女二带着虚假的记忆回到十四号城度过余生。

战胜二号后，琳“找回”了一部分自己曾经的人生记忆，这些记忆的涌入让她看起来就像变了个人。女二和她的关系也因此变得微妙，那些充满尊重的话语让她们像是陌生的同龄少女，这样的疏离感使女二的心隐隐作痛。但她依然全力寻找解救琳的办法。琳诞生出越发不可遏制的自毁倾向。琳甚至在某天装出一场失忆，想要让女二失望、绝望，最终抛下自己，但她低估了女二的决心，也低估了女二的脾气。
