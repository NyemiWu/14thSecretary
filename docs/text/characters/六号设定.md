# 六号设定

六号：生产于戍卫军团时期的武装智械个体单位，在戍卫军团时期属于一般作战单位，但在穹顶城时期，其仍保有的军规级武装力量使其成为战略级威慑力量。目前在仿研所的指挥下从事一般事务性工作，偶尔处理一些棘手的幕后“清扫”工作。是目前二号不敢直接与仿研所产生正面冲突的明面上的直接原因。

六号（暂议）新增设定：六号本为前塔罗牌“战车”。早在戍卫军团时期，塔罗牌“教皇”“太阳”“皇帝”“魔术师”等已被派遣至地表。但因早期塔罗牌未更新自毁协议补丁，导致完成任务后长期空闲的这四张塔罗牌异化为极为强大的意识怪物个体。特派遣塔罗牌“战车”以处理这些异化塔罗牌威胁，同时向塔罗牌轨道平台更新了自毁协议。在“战车”部署至地表后，对其进行了更为夸张的武装升级，使其特定参数高于其需要消灭的异化塔罗牌，并拥有更高的模块化改装能力以针对性对抗其余异化塔罗牌。

“战车”在剿灭已知的四张异化塔罗牌后，卸除武装模块，被安排以工程智械的身份参与十四号城的修建。目的是暗中持续保持地表活动，以确保再次出现异化塔罗牌时能够第一时间前往处理。但因自毁协议补丁更新，后续并未再次出现塔罗牌异化的事件。穹顶城合围时期，因戍卫军团力量受到意识污染大幅冲击，“战车”改编至戍卫军团某一作战小队以战术智械身份参与前线作战，为防止其身份暴露，“战车”在改编至作战小队时更名为“六号”，并封存塔罗牌相关数据，其反塔罗牌模块武装系统一并封存。

穹顶城合围后期，六号所在的作战小队全队牺牲，六号在战斗中同样大幅受损，丧失作战能力。在关键时刻被老爷子（目前是仿研所首席研究员，兼任戍卫军团观通部队某属高级工程师，保存着六号的塔罗牌相关数据和模块化反塔罗牌武装系统，同时也是塔罗牌系统的早期开发团队一员）救走并带离前线。此次作战中，六号的数据处理系统严重受损并遭到部分重置，导致其无法再兼容塔罗牌系统，但仍然保留了模块化武装系统和

改装能力。

合围后，老爷子加入仿研所工作，志高肃正向老爷子抛出橄榄枝，遭老爷子拒绝，但承认帮助志高肃正保管“战车”塔罗牌系统和相匹配的模块化武装系统，承认将在必要时将六号重启为“战车”。老爷子的目的在于以六号为武装基础，保证仿研所在十四号城目前不稳定的局面下拥有足够的武装力量以保证安全独立。此时六号在修复过程中重新安装了最低限度的“反塔罗牌武装模块”，其余模块由老爷子暗中继续保存于仿研所，并把安装和启动密钥封存于“将棋”中。后老爷子遭到超氧昆山级杀害，临死前将“将棋”的秘密告知并托付给双子，六号得以在之后通过“将棋”再次恢复到全盛状态。
