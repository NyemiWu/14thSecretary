# 风蕊设定

**风蕊**，ISFJ，性格善良温柔细腻，非常擅长照顾和治疗，从仿研所特种学校毕业后，前往莱山德医院实习，期间经历了“恶魔院长”怪谈这个事件。后来在院长推荐下，回到仿研所新成立分所【仿研柒所】担任**疗养师**，主要任务之一是监护意识生物拉斐尔。拉斐尔事件后，更多以主角团的一员的身份，支持琳和芊一行人的各种活动。

风蕊、芊、音符，三人是仿研所附属特种学校的同班同学，关系上风蕊和芊更亲近一些。

芊从城外超氧绑架中逃回来，此时自己家已经被超氧包围了，所以翻到了风蕊家（风蕊一个人在家）避难，风蕊给芊做了简单的包扎和意识治疗。

琳刚刚成为芊的搭档时，有一段时间，芊把仿生人琳扔给风蕊照顾。风蕊在这期间与琳互相认识。

在“恶魔院长”怪谈中，与双子的校园探险小队相遇。

拉斐尔事件中，与曾经的同学闫洇浮对峙，阻止了超氧打探拉斐尔的秘密。对于被剥削的意识生物拉斐尔，她充满同情。在芊与闫洇浮的矛盾中，也担任了调解作用。
