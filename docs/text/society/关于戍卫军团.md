# 卫戍时代：戍卫军团

穹顶城建设时期的外围防御武装力量，是上世代人类所有的武装力量的集合，衍生出相当一部分穹顶城在穹顶建设时期就已经因为无法抗衡期间各种意识怪物的袭击和意识污染而夭折。而且关于这一支（多支）武装力量的存续和力量流散都可以衍生和解释很多城内武装力量的来源。

随着在建穹顶城数量的减少，这支武装力量却没有因此而减少工作量，反而因为人员损失远大于穹顶城（被毁灭而）减少的速度，使得其保护能力越来越捉襟见肘，但好在最后还是保住了几座穹顶城完成了建设和穹顶合围。（或许后续一些人留存还会变成流贼土匪）。他们的全军覆没，也象征着人类旧文明的结束，守护了新阶段的开始，剩余的伤兵（没有意识污染的，有意识污染的伤兵就地处决）也有一部分回到了幸存的穹顶城，没人再能给他们颁发军功章，但他们知道他们如何保护了这一切，又牺牲了多少来保护者一切，而他们对过去缄口不言，因为他们知道，他们保护的新文明正在萌芽，他要褪去旧时代的糟粕。一部分意识伤员被送到城外的意识研究所治疗观察，意在治疗的时候隔离意识污染对城内的影响。

“当我不清楚我是否还在，请不要将我归于故乡。”

人员损失，经济损失，社会动荡，十四号城时期刚开始便陷入了经济大萧条，动荡乱局成为滋养超氧的土壤。

抵御对象：意识灾害伴生生物（包含聚合怪物、被感染的动物和人类等），武装土匪流寇。

意识灾害伴生生物（简称意识怪物）：具有碳基生命性质，可以被火器压制，会不断重生，解构任何存有“意识”的素质，即一切文明造物，然后变成新的怪物。在物质身体毁坏后，意识会游离并寻找其他宿主，只有从意识之海中杀死它，并彻底焚毁脑、神经等意识器官，才可能完全消灭。而同时，意识怪物的进攻手段可能并不会看上去那么“激进”，它们会有像野兽或是怪兽一样的撕咬，横冲直撞和肆意破坏，但大多数是“无声的吞噬”和“侵蚀”甚至“同化”，不带有半点“敌意”地席卷大陆。

最早的编制，每一个卫戍部队负责四个穹顶城，第十四号城由第四卫戍部队负责保护，每一支卫戍部队下辖七支不同分工的武装，分为阵地，机动，强袭，遥测，支援，通讯，后勤。

- **阵地**，负责近卫和阵地作战，持有固定的重火力据点，负责固定把守重点地理位置。

- **机动**，负责服从灵活调配，在不同据点或者前进基地之间灵活运作提供支援。

- **强袭**，负责贯彻“最好的防守就是进攻”。在必须的情况下打击意识扎堆的重点地区，提前消灭或者削弱意识怪物的冲击。由于要负责真正意义上的短兵相接，斩杀意识海中的意识怪物，需要广泛使用仿生人，由此诞生了领航员体系雏形。

- **遥测**，负责提供战术信息测量和敌对力量的定位。意识怪物进击是“无声的吞噬”，遥测所起到的作用甚至比其他部门更大，因为只有他们有主体能力来确认意识怪物的“位置”，无论是空间上的，还是意识海里的。广泛使用仿生人。

- **通讯**，负责保障各部门之间协调信息交流，并抵抗意识污染对信息的冲击。通讯的任务同样繁重，因为他们是要直面“无法被量化”的侵蚀来保障信息流通。同样广泛使用仿生人。

- **支援**，负责提供一切前线必须的武器装备支援，上送弹药，人员补给前送，撤离等等。

- **后勤**，负责后勤。

  后来因为兵力锐减，卫戍部队转为一个卫戍部队负责一个穹顶城，甚至一个卫戍部队只能提供一部分职能来支援保护穹顶城。再到穹顶城合围关键期，“穹顶意志”的激活吸引了前所未有的大量意识灾害向城市中心汇聚，卫戍部队只剩下了能够勉强支撑阵地作战的力量，甚至于只剩下屈指可数仍在作战的小队。到穹顶城合围关键期，也就是最后几周，卫戍部队的伤亡率已经来到了难以置信的百分之九十以上，而穹顶城的存活率也没超过百分之十。而在合围后，卫戍部队的伤亡率来到了百分之百。因为为了保证所剩无几的穹顶城合围顺利，成功，且没有后顾之忧。仍然具有完全作战能力的卫戍部队最后力量都选择了驻守城外关键据点，挡住了最后的意识冲击。

  关于前线部队的一些细节，更多的使用机械计算机取代电子计算机，以尽可能减少意识污染。面对意识怪物，先采用火力压制，高效率击杀。同时，卫戍军团强袭部队大量使用**冷兵器**，以确保可以斩杀意识怪物。为了防止借尸再生，需要以高温彻底焚烧躯体，破坏意识器官。

  列阵，斩杀，断魄，焚毁

  关键元素：纯机械设备，火器，冷兵器，火焰，汽油，各种载具

  关于意识污染与EMP：EMP电磁脉冲本质是电磁波以脉冲频率发出，可见光脉冲干扰人体视觉神经的过程也与之类似（可见光波频率远高于EMP），因此意识污染的一个表现可能是EMP和某些频率的可见光脉冲同时发生，造成电路毁坏的同时也触发人体光敏性癫痫。抗EMP干扰的元件有电子管等，可能是戍卫军团的代表元素之一。
