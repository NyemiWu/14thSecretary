# 地下城

<https://www.bilibili.com/video/BV1jsMczeETE/?spm_id_from=333.788.top_right_bar_window_history.content.click>

之所以有地下城，是因为新城市是在旧建筑群的坟墓上重建的。新的建筑群地面海拔会叠高，形成台地，把一些残留的旧建筑压在厚实的地下废墟中。

比如，一些海拔低、建筑高的地域，为了重建要把高楼推了，推成个差不多的废墟再填土压实，新海拔会高出个十米左右，但由于这时的土壤不再适合作高楼地基，新的建筑群会以矮建筑和设施为主。

那么这个地方就很适合作贫民窟。往下挖十米能挖出旧建筑的街道和房间，这还只是一个小规模的地下建筑群，集污处到出城口的地下通道可能就有这么一段埋在地下的旧街道，不是防空洞和地铁空间，而是曾经的地上，这种感觉很荒诞又很合理

集污处一带就是以老建筑群为主的生活、作业群落。
