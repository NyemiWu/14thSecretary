# 津渡区

**地点：**

十四号城内

**背景介绍：**

十四号城内，长江区域的渡口，靠近政治经济中心，受到政府重点扶持，教育，科研是津渡区的重点，由于靠近长江，还有着一定的交通优势。

**地形：**

占地面积：20平方千米

类型：河谷平坝

特殊地貌：地势偏平缓，依靠一江一河，交通网路四通八达 ，倒塌大楼残骸于自然融合，形成大面积坡地。

河流：长江（深水），黑水（深水）

滩涂：缚舟滩（浅水）

挽子坡主体：倒坍建筑与自然融合形成的巨大山坡，表面留有文明遗迹，坡体内部中空，有人工避难所

**地区资源：**

**意识污染：高**

**发展程度：低**

**资源量级：低**

1.  地理交通资源（高）

2.  可利用文明残留资源（中）

3.  可利用自然资源（低）

4.  可利用意识资源（中）
