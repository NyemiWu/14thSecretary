# 穹顶城城市区域总划分：（待补充

**片区规划：**

**穹顶城下辖**

穹顶城下辖有**边界区**，**边界警戒区**，**郊区**，**自贸港**四个卫星辐射城区。

穹顶防御系统和穹顶本身位于**边界区**，该区域附属一系列穹顶支持设备和机构，受穹顶城本城政府直接管理，负责穹顶的维护保养、穹顶城出的出入把关、穹顶城的封闭系统。

**边界警戒区**位于边界区外围，但并不完全包围边界区，主要集中于穹顶城出入闸口以及要害部位，例如穹顶支持设备、发生设备和能源交换及管理设备等。负责武装保卫穹顶的安全和穹顶城内外的政治联系，是穹顶城政府对外交流的触手和施加对外力量的抓手，虽然受本城政府直接管理，但是在穹顶本身出现危机安全状况时，以穹顶的安全为最高优先级。

**郊区**为边界区外，边界警戒区之间的弱管理区，主要存在为各类交通线路，也不乏有各类非法地方势力存在于夹缝之中。普遍长期人员活动较少，部分重点交通节点设有边界警戒区的哨卡和补给点，以保证郊区对外联络的通畅和对外交通基本职能能够基本保证稳定、安全运行，是穹顶城政府对外感知的最外层表皮。

**自贸港**位于边界警戒区更外围，基本独立于穹顶城政府独立运作，但是其基本商法和物资流转受本城法律及纳税限制。相当一部分自贸港保有独立的武装力量以保证其安全稳定。但由于几乎完全暴露于意识污染中，各自贸港仍然需要穹顶城提供武装支援以对抗意识入侵，也成为了自贸港受穹顶城管理和管控的一大限制。同时较大的自贸港设有意识科技相关的实验室和前线医院，穹顶城内的意识污染源将会视情况运送至这两类机构处理。
