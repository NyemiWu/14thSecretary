# 关于北岸（Arapluce）

北岸基本被两股势力瓜分

一半是十四号城本身的公权力，警署

一半是前戍卫军团的残部

后者利用戍卫时代的残余关系暗中获取倾斜资源

前者代表十四号城本身的资源分配链和秩序

两者是有冲突有矛盾的，但是明面上不能直接斗争，于是分别支持自己的代理人势力

警署暗中支持鸦巢，戍卫军团残部暗中支持野犬巷

这也使得前者(鸦巢)的处事风格偏向于铁腕手段和“规则”，后者更倾向于“自由”和帮派化的行为

两者之间摩擦不断，虽都被定义为帮派冲突，但实质上是警察局和戍卫军团残部的代理人战争

之后，在超氧的暗箱操作下，野犬巷(也可能只是超氧自己的人)引发了氧塔事件，引发了巨大的对于公权力的公信力危机

警署的力量受到大副削弱，并向主城方向倾斜，北岸区力量平衡被打破

同时，超氧宣布“无偿提供氧塔的替代系统”，进一步削弱了公权力力量

补充一点，超氧在此之前曾主动，半公开的向鸦巢“伸出橄榄枝”，提供所谓“武装安保支援”

对鸦巢拒绝超氧“武装安保支援”一事的鸦巢内部派系对此本就颇有微词，氧塔事件后，这一派系话语权进一步加大

加之警察局力量削弱，野犬巷趁此机会在与鸦巢的争夺中占据上风，几乎直逼鸦巢咽喉

鸦巢最终主动向超氧寻求“援助”，导致鸦巢被超氧架空，武装力量换血，警察局彻底失去对北岸的掌控

随后，超氧以帮派斗争的名义对野犬巷发起袭击，取得压倒性胜利，威胁到戍卫军团残部的直接利益

超氧对戍卫军团残部提出的维持现状的条件是，放弃对野犬巷的支援并交出长岛狛鸣

因为长岛狛鸣作为失去引航员的仿生人没有变异，且具有几乎完备的战斗能力，这一点上对超氧而言有相当高的研究价值

为了继续获取倾斜资源，更为了自保的戍卫军团残部就此放弃对野犬巷的所有援助，甚至站到野犬巷的对立面

野犬本人本就对戍卫军团残部的一贯作风不满，在长岛狛鸣的影响下，也为自己委曲求全的行为有所动摇

知道野犬巷已经保不住，于是委托南山事务所保护并带离长岛狛鸣，防止她被超氧当做研究物而落得难以想象的下场，但在与南山事务所谈好条件后返程途中造鸦巢(被超氧控制)伏击身亡

野狗(奥博连斯基)对南山事务所提供的报酬是关于长岛狛鸣本人的长期意识监测数据，以及她是个体仿生人的事实(她是仿生人这个事目前只有野狗本人和超氧(可能只有二号)清楚)

由于野狗身亡，长岛狛鸣接替野狗位置，直接参与进鸦巢和野犬巷的帮派斗争，于是南山事务所无法直接出面找到和带离长岛狛鸣，遂委托巨门安保进行具体执行

并派遣一名南山事务所成员(随便一个谁都行吧)在场

而南山事务所在行动开始前，事务所按期举办例行慈善晚宴，遭黑神党恐怖袭击

被派遣的南山事务所成员被拖住，巨门安保力量小组依照合约自主前往寻找长岛狛鸣

巨门安保本身不知道南山事务所寻找长岛狛鸣的目的，且依照保密协议不能透露雇主信息

加之巨门安保使用的武装装备等与超氧颇为相似(均是军规的制式武装)，遭到了长岛狛鸣的抵抗

长岛狛鸣以为是超氧最终试图剿灭野犬巷，单方面撕毁暂时的“停战协议”(野狗遭袭身亡后，相当一部分野犬巷成员欲投降超氧，而长岛狛鸣出于对这些成员的情感并未阻止，只是希望每个人都能选择自己想选择的活下去或者斗争下去的道路。超氧据此划定投降事件和暂时休战期，向野犬巷施压并接收人员)

长岛狛鸣判断失误引起野犬巷全体奋起抵抗，导致巨门安保小队暂时无法顺利完成任务，鸦巢趁虚而入，试图借此将整个野犬巷一网打尽

长岛狛鸣最终无法承受身边野犬巷成员战死的压力，彻底异化并引发局部意识灾害，而此时，南山事务所的委派成员刚刚到达北岸事发地点，被困其中，同时巨门因为安保协议，拒绝对此事进行更多投入(南山事务所开出的价码不符合巨门预期，巨门只认钱)，南山事务所向仿研所求助，仿研所指派六号协助南山事务所对被困人员进行救援

更早的时间，南山事务所这边发生了其他事情

因为北岸方面的冲突，南山事务所获得了大量用于信托抵押的情报信息，均透露超氧幕后操盘的事实，同时也因此具有透露超氧行为的风险

超氧无法容忍不可控因素存在，在与南山事务所谈条件的同时，预谋对南山事务所进行彻底清洗，策划了慈善晚宴中恐怖袭击一事

南山事务所推断出超氧操控黑神党进行恐怖袭击的可能性，及时撤离原驻地并向仿研所寻求庇护。平时，南山事务所常常因需要救助仿生人而向仿研所提供情报，同时将此作为从被救助方获取情报的报酬

因此，南山事务所存在模式上与仿研所关系密切，更是以长岛狛鸣的仿生人本质和意识波动监测数据为代价，向仿研所换取庇护援助

仿研所从而掌握了北岸冲突全貌，并认为长岛狛鸣的不可控因素是极为危险的存在，也解释其为何选择六号这种超规格武装单位协助南山事务所救援被困人员

因为南山事务所的性质，其保密工作相当完善，超氧对事务所本部进行暗杀渗透时，其早已人去楼空，但因为南山事务所对超氧的心存幻想，只在晚宴恐怖袭击后才彻底认清其面目，导致人员撤离过于匆忙，资料证据销毁不充分

超氧从事务所归档目录信息中了解到大量仿生人实际名录，为后续昆山杀手计划埋下伏笔，同时也知晓仿研所目前正在为事务所提供庇护

于是趁六号前出北岸时，对仿研所进行了暗杀行动，尽管双子尽力抵抗，老爷子仍身负重伤不治身亡。

之前，仿研所这边因为同为公权力(公权力一侧)的机构，仿研所和警察局一般站在同一条战线上

氧塔事件后，警察局力量式微，不得不向仿研所求援，尤其是在扶持鸦巢继续对抗野犬巷这一方面上

而超氧推动氧塔事件一事并未露出马脚，警察局将重心错误的放在了对黑神党势力残余的搜索和清缴

进而导致仿研所同样判断失误，不认为超氧对此事有何干涉，但不否认此事的确为超氧带来了很大的公信力收益

警察局不得已的情况下，委托仿研所以特殊维安力量的身份介入北岸对抗野犬巷，但同时仿研所并不清楚警察局和鸦巢的关系

面对突然介入的第三方力量，鸦巢秉承敌人的敌人就是朋友的原则，试图拉拢仿研所，但仿研所正义凛然地同样将鸦巢视为不稳定因素而拒绝其靠拢，导致两者战场割裂，情报不共享

于是超氧架空鸦巢时，仿研所继续错误地认为超氧并非一切的幕后推手，而只当超氧是在尝试瓜分北岸的蛋糕

尔后慈善晚宴恐怖袭击事件(暂定为黑色星期日事件)发生后，仿研所因此联合警察局抽调大量人手试图彻底肃清黑神党，而非继续深究，暴露超氧的野心

这均为超氧后面“突然暴起伤人”，成功实施暗杀计划和昆山杀手计划买下了伏笔

但一直处于对抗野犬巷前线的Lynn和女二，包括其他在场的主角团成员(没确定那些人，但总之凯瑟琳和六号应该不在场)都通过战场的蛛丝马迹对超氧的真正意图有所察觉，进而有所防备，使得超氧暗杀计划并没有完全达到目的，即包括Lynn的关键数据在内的信息并未被窃取

随着长岛狛鸣的完全异化，北岸原有平衡被完全洗牌，野犬巷不复存在，被架空的鸦巢被迫将残余的全部力量用于控制长岛狛鸣导致的污染源不扩散，原有的戍卫军团残部被超氧以各类“非法”借口，冠以公权力的口号清缴

从此北岸也彻底落到超氧掌控之中，超氧对十四号城仅剩的不可控力量仅剩仿研所，部分警察局势力(女警为代表的一派)，南山事务所，巨门安保

随后便肆无忌惮地发动昆山杀手计划，大批仿生人被杀，仿研所几乎被摧毁，主角团的工作被迫转入地下

因为对六号力量的忌惮和隐蔽工作的需要，超氧姑且无法彻底剿灭仿研所残余力量并洗牌，这也给了主角团喘息之机。南山事务所为寻求自身生存，几乎违背原则地与仿研所情报共享，仿研所由此通过超氧的行动与赵氏三兄弟行为模式的对比，推测出超氧有着第三方控制力量，即二号的存在

而超氧这边，通过控制鸦巢而对长岛狛鸣进行的大量研究数据发现，其意识层面存在几乎力量对等的战斗痕迹，对比参与北岸斗争的大量势力实际力量情况，推测出Lynn的存在，但无法确定其属于哪个势力，目前情况如何

故超氧目前不敢对残余的任何势力直接展开冲突，超氧与“正派势力”形成了微妙的平衡，并且双方已经明牌对抗

备注：

1.氧塔事件：十四号穹顶城中央制氧塔爆炸事件，明显是人为袭击，但始作俑者暂且不明

2.巨门安保：通过各种途径保留了戍卫军团时代遗留的各类军规级武装而成立的武装安保公司

3.“双子”：仿研所所属的两名特殊仿生人，通过特化的意识技术，能够达到“互为引航员”的目的，从而更灵活的实施战术行动，代价是持续作战能力较差

4.昆山杀手：超氧为肃清所有不在其管理下的仿生人发动的针对仿生人的屠杀计划，利用超氧自研的“昆山”级自主仿生人进行。该类仿生人功能更偏向于智械，几乎没有自主意识和判断能力，仅为完成任务而活动

5.黑神党：至高联合暗中扶持的恐怖主义团体

6.“主角团”：指该世界观中的主角团，以Lynn及其领航员为核心角色，包括其余仿研所的角色

7.“女警”：警署的一名女警，名为凯瑟琳，主角团的一员，后期会补足关于她的其他设定
