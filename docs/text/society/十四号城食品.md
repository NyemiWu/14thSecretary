# 十四号城食品

**食品综述，十四号城的食品可粗略分为以下几种体系，以下命名仅方便制作人沟通了解，不具有确定性**

**传统餐饮体系：**

兴盛时期：长期

从当今社会继承过去的食品，从烹调技巧到口味，应用场景，基本不会有太大变化，就是大家理解的传统餐品，但由于社会生产力和消费观的变动，大部分传统餐食的价格惊人，香辛料更是一度成为奢侈品

**太空餐饮体系：**

兴盛时期：市元前10年——至今

从戍卫兵团时期的战时物资餐点演变而来极具太空风格的餐食体系，味道普遍极为普通，一言难尽，仅作生命维持，多以膏状，条状，砖状，罐头（这个算友善的类型）形式出现。

**建城餐饮体系：**

兴盛时期：市元前10——市元后10年

建城经济困难时期的特别餐饮体系，除去政府公发的太空餐，大部分民众发动自己的智慧基于传统餐饮创造的拮据餐，（对标美国大萧条餐饮文化，例如水馅饼），特点为材料廉价，随意，但味道普遍不差，多为百姓自发的随性创作

**希望餐饮体系：**

兴盛时期：市元后10年——市元后25年

顺应建城复苏后，经济假性回暖，劳动需求大，社会发展快，节奏快。人们尚且充满希望，该类餐食的特点是满足快速发展，快节奏需求，但相较于神人太空餐更加具有让人消费的欲望和个性化

（典型现实逻辑案例，韩国黄金年代的冰美式文化）

**流行餐饮体系：**

兴盛时期：市元后25年——至今

流行文化杂糅下的融合餐饮体系，没有明确的派系，没有明确的路子，但是非常突出享乐主义和消费主义，注重外观和噱头（经济越是困局，但没跌破临界，越是容易产生消费主义），同比可参考日本泡沫经济下的饮食文化，但成因不同，甜食，奢华，精巧，价值会成为更多商品的标签

**餐品罗列：**

**YAHOMIA肝渍膏**

**派系**：太空餐饮体系

**生产商**：YAHOMIA

**规格：25**g塑胶管膏状包装/300g罐头包装

**描述**：曾经的军用口粮，YAHOMIA看家产品，便宜实惠，由小动物肝脏，肉糜和淀粉制成的咸味餐膏。味道很咸，重口，带腥味，淀粉味偏重。旨在补充蛋白质和维生素，矿物质，但由于味道过于离奇，一般不会有人将其当餐食使用，但是非常流行作为一种调味料，用水稀释有点酷似肉味鱼露的味道。

**受众**：究极经典款，老一辈的回忆，建城的艰难岁月，重口爱好者，穷人。（到底是谁在谣传这东西有独特香味）

**爱好者集邮：**

亚尔伯特·珂博奥：很有情调的小食

凯瑟琳：作为食物来说有些恶心，当盐就好多了

沈嘒宵（启明）：说实话我只是有时候不知道吃啥

多萝西：其实相比起碳砖这个还算可以

校礼官：我不予置评

**YAHOMIA蔓味时蔬**

**派系**：太空餐饮体系

**生产商**：YAHOMIA

**规格：150**g塑胶包装/25g塑胶包装/300g长筒包装

**描述**：曾经的军用口粮，廉价到难以置信，总的来说就是脱水蔬菜，由人工培植的纤维素块茎制成脱水制成。味道新奇，相较于传统脱水蔬菜口味更加合适丰富，有种栗子香气，并不怎么像是脱水蔬菜的感觉，更加蓬松。

**受众：**年轻人，即食主义者，穷人

**爱好者集邮：**

亚尔伯特·珂博奥：这个其实没什么特别的味道，但是吃起来很方便，动脑人群很适合。

清桡：菜干拌酸奶其实很不错，因为它也不是很菜干就是了。你知道吗，其实我不喜欢蔬菜，但我感觉这个不大一样，就像是更健康的薯片。脆脆的，香香的，我总觉得有种栗子香味，但大家都不这么想，真的是有栗子香味

UU：夫人很讨厌这个菜干，我真不知道她是讨厌YAHOMIA还是单纯讨厌菜干，不过因为也是她讨厌，所以我喜欢咯。

咪宝：它够便宜，刚好我够穷，喏，这不就巧了嘛

**惠成牛肉罐头：**

**派系**：太空餐饮体系

**生产商：**惠成/藜得利

**规格：500**g罐头包装

**描述**：早期由牛腩肉，土豆，白蚕豆制成，用料扎实，味道让人记忆深刻。传统意义上的好吃，但是由于食材供应，价格从市元前10年的30元到市元40年昂贵的65元，材料也变成了牛腩/鸭肉混合肉，土豆和黑豆，木薯，生产商也从最早的藜得利变成了惠成

**受众：**绝大部分罐头爱好者和藜得利牛腩罐头的粉丝

**爱好者集邮：**

牙：完美

穆颖芊：想起来以前还不叫这个名字，味道好像也变了些

坎特尔：所有粮里面我最喜欢的就是这个，我一般会再自己再熏一次，拿细碳燎一边，味道就正宗了

叶莲娜·亚历山德罗芙娜·普希金娜：浓厚，温暖，咸韵，总是绕上心头。

**木薯杂豆饭**

**派系**：建城餐饮体系

**生产商：**无

**规格：**300g（蚕豆/鹰嘴豆/黑豆/大豆...）+300g木薯/土豆+100g大米+5-10g油（动物油最佳）+100g蔬菜（纤维素块茎/真正蔬菜/菌类）

**描述：**廉价的精米饭替代品，建城时代的艰难选择，老一辈的回忆，理论味道比一般杂粮饭更好，但实际由于食材大多品类收集不全，成品会类似充满杂质的木薯团，口味和卖相都很朴素，果腹之选

**受众：**老一辈的回忆，穷人和健康饮食爱好者

**爱好者集邮：**

牙：我倒是喜欢这饭，白是白的，杂是杂的。

穆颖芊：有事的时候，就想

沈嘒宵（启明）：算是儿时的回忆了，不算可口，但有别有风味

埃贡：比春风质朴，比夏风柔嫩，比秋风温尔，比冬风长情
