# 奥博连斯基

斯维亚托斯拉夫·格列布·奥博连斯基，（Святослав·Глеб·Оболенский）

，俄罗斯人，前俄国黑手党成员，某组织下帮派头目。因管理用人不善，手下为钱财而走私贩卖未成年人口触犯组织纪律受罚，其手下作为导致数个家庭家破人亡。他本人却被怀有妇人之仁的被害者庇护，进而更真切地目睹其所作所为带来的苦难，但——

“你的双手沾满鲜血，而我不希望我的手如此”庇护他的雅罗斯拉娃修女小姐如是说：“我或许不会宽恕你的罪孽，但上帝会。”

她送给野狗一个十字架吊坠，银制，镌刻着细密的花纹。

“愿你的忏悔能让上帝宽恕你的罪。”

于是野狗虔诚的向上帝下跪，那是他第一次为自己流泪。

而在组织最终找上门后，他深知继续躲藏只会再一次牵连无辜的人，于是他光明正大的走出教堂门口，走向那几辆早就停在哪里的黑色高级轿车。

但意识灾害往往突如其来，毫无征兆。野狗发现那几辆车似乎透出某种喧哗，但明明看上去是死寂一般的沉默。这让他感到恐惧，但他仍然决定向前走去。

他把佩枪扔在地上，然后举起双手，沉默地靠近那几辆车。随着反光玻璃上他的影子愈发清晰，他心中莫名的恐惧却越来越强烈。

他能分辨出来，那不是对死亡的恐惧，也不是对未知的恐惧，而是一种更纯粹的，纯粹到让他无法理解的发怵，几乎让他想要嘶吼出来，却又明白现在的他不可能还有力气发出任何声音。

他透过反光玻璃看见教堂。华丽的，破烂的教堂。他突然想起了什么，转身向教堂冲去。

那是他第一次这么慌乱，但这慌乱却不是因为他心里那无根的恐惧，而是突然明白过来——当然，他也不知道自己为什么会明白，之后也不会——可他却绝望的发现短短几十秒内自己走出的距离却如何也冲刺不到重点。

梦，一定是梦吧！

他苦笑着，但没有放缓脚步。教堂门几乎近在咫尺，但每一步跨出却毫无作用。他低头看着被甩向身后的地面，惊恐地发现坚固的土地正在扭曲，而他甚至已经看不清自己的影子。

“我操，别，等等，不要！！”

他嘶吼出声来。

但他看见教堂好像活了过来，不，不是活了过来，而是变成了某种“存在”，而他无法形容，他只能说那像是某种活物。教堂开始扭曲，却仍然坚固无比；教堂变成了某种雾气，却又仍然实实在在的屹立在那里；他听见教堂在说些什么，但他耳畔明明没有任何声音。

“罗斯拉娃！！罗斯拉娃小姐！！”

他目眦欲裂。

但这雾气逐渐席卷过来，他感受到一种奇异的包裹感，像是罗斯拉娃在月光下流着泪抱住正在忏悔的他；他感受到千万的亡灵在他耳边轻语，像是罗斯拉娃小姐在忏悔室为他而向上帝祷告；他感受到恐惧和安心感扭曲在一起，像是罗斯拉娃小姐与所有被他害死的人拧成了一股粗大的麻绳，讲他悬挂在万尺高的绞刑架上。

“可能上帝会宽恕你。”

他清晰地听到这么一句话，随后他什么都听不到了。
