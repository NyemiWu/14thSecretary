# 好，那么来一段野狗派他的手下“獒犬”对鸦巢的小头目“秃鹫”实施的复仇行动：

地下车库的枪声骤然停歇，只剩下警报器刺耳的尖鸣。秃鹫深吸一口气，按下麦克风按钮，他那经过扩音器放大的、带着刻意轻松和恶毒嘲讽的声音，瞬间充斥了整个一楼大厅和向上的主楼梯间：

“嘿！‘獒犬’！车库的‘欢迎仪式’还满意吗？我听说你很喜欢拆东西？那些装甲车可是我花大价钱改装的玩具啊！” 他故意停顿了一下，听着耳机里传来沉重、稳定、毫不迟疑的脚步声正踏上楼梯，“啧啧啧，何必呢？像条真正的野狗一样在垃圾堆里刨食不好吗？非要闯进狮子的领地？”

脚步声没有停顿，没有加速，也没有回应。只有规律的、如同重锤敲击地面的“咚…咚…咚…”声，穿透层层墙壁，清晰地传到顶层。每一步，都让办公室里的空气更凝重一分。

一楼大厅监控屏幕瞬间被霰弹枪喷射的火焰和飞溅的碎片充满。两名躲在巨型大理石柱后的枪手连惨叫都没发出，就被轰得倒飞出去，柱子表面留下巨大的蛛网裂痕和喷射状的血污。獒犬的身影在硝烟中显现，毫不停留，走向通往二楼的楼梯。

秃鹫脸上的笑容僵了一下，他迅速切换频道，声音提高了八度，试图用更尖锐的羞辱掩盖不安：“二楼的朋友们！好好‘招待’我们的客人！让他见识见识什么叫真正的火力！别让他脏兮兮的靴子踩脏了我的波斯地毯！” 他身后的护卫下意识地咽了口唾沫。

二楼的抵抗更加疯狂。自动武器的火舌在走廊交叉闪烁，手雷爆炸的火光映亮了监控屏幕。然而，那沉重的脚步声几乎没有受到阻碍。霰弹枪的轰鸣如同死神的丧钟，每一次响起都伴随着监控画面的一角变黑或是一蓬血雾炸开。消防斧劈砍金属门框、撕裂人体、砸碎防弹玻璃隔断的刺耳噪音，透过麦克风清晰地传回办公室，伴随着骨头碎裂的闷响和濒死的呜咽。

“废物！一群废物！拦住他！用火箭筒！用…用什么都行！”秃鹫对着麦克风咆哮，之前的嘲讽荡然无存，只剩下气急败坏和一丝不易察觉的恐惧。他眼睁睁看着代表獒犬位置的红点在楼层平面图上，以一条笔直、冷酷的直线，无视所有迂回和障碍，坚定地向上移动。每一次枪响，每一次斧劈，都像是直接砍在他的神经上。

脚步声抵达了顶层走廊。这里布置了秃鹫最后的、也是最精锐的防线——六名全副武装、训练有素的雇佣兵，依托着临时堆砌的沙袋掩体和交叉火力点。

秃鹫像是抓住了最后一根稻草，声音带着歇斯底里的尖笑从走廊广播传出：“哈哈哈！獒犬！游戏结束了！看看你面前！这才是真正的钢铁丛林！你以为你是什么？一头蛮牛？在我精心打造的堡垒面前，你……”

他话音未落。

“轰！！！”

一声远超之前所有霰弹枪响的剧烈爆炸震撼了整个楼层！监控屏幕剧烈晃动，走廊的画面瞬间被浓烟和火光吞噬。獒犬竟然直接用霰弹枪轰爆了走廊尽头的一个消防喷淋系统主阀门，高压水柱混杂着灭火泡沫如同瀑布般倾泻而下，瞬间让整个走廊陷入一片白茫茫的混乱水雾。

雇佣兵们精心布置的防线和视线被彻底打乱。

紧接着，是地狱般的景象在监控中闪现：一个在掩体后慌乱擦拭护目镜的雇佣兵，被消防斧从侧面劈开了脖颈。另一个试图瞄准水雾中身影的枪手，被霰弹枪近距离轰飞，撞碎了旁边的防弹玻璃。

沉重的脚步声踏着积水，如同催命的鼓点，在混乱的惨叫和零星绝望的枪声中，稳定地、不可阻挡地逼近办公室那扇厚重的复合装甲门。

“咚…咚…咚…”

脚步声停在了门外。

办公室内死寂一片。秃鹫瘫坐在椅子上，面无血色，浑身筛糠般抖动着，连敲击扶手的力气都没有了。他身后的两名护卫，枪口剧烈颤抖地对准门口，汗水浸透了他们的战术背心。

扬声器里传来秃鹫自己粗重、恐惧的喘息声——门外的麦克风还在工作。

然后，是金属摩擦的刺耳噪音。獒犬似乎把霰弹枪挂在了身上（监控已失效，只能听到声音）。接着，是沉重的、有节奏的撞击声。

哐！哐！哐！

不是枪！是那柄消防斧！獒犬在用消防斧的钝头，如同攻城锤一般，沉重地、一下又一下地砸在复合装甲门中央！巨大的力量让整扇门连同门框都在剧烈震动！每一次撞击，门板上精心设计的防弹层就向内凹陷、扭曲一分，发出令人牙酸的金属呻吟！门框周围的混凝土墙面开始出现放射状的裂纹，粉尘簌簌落下！

“拦住他！开枪！打门！打死他！”秃鹫对着两名护卫失声尖叫。

护卫对着门板疯狂扫射！冲锋枪子弹在装甲门内部发出密集的闷响，留下无数凸起的弹痕，却根本无法穿透！反而跳弹在办公室内乱飞，打碎了昂贵的花瓶和壁画！

\*\*哐！！！\*\*

随着一声震耳欲聋的巨响和金属撕裂的哀鸣，复合装甲门中央被硬生生砸开一个扭曲的、边缘狰狞的破洞！一只沾满血污、青筋暴起的大手猛地伸了进来，抓住了破洞边缘！

“不！不——！”秃鹫绝望地嘶吼。

大手猛地向外一撕！伴随着刺耳的金属扭曲声，厚重的装甲门板像纸片一样被撕开一个更大的豁口！獒犬那如同魔神般的身影，带着一身硝烟、水汽和浓重的血腥味，弯着腰，从破洞中硬挤了进来！

办公室内灯光似乎都因他的存在而黯淡了。

两名护卫肝胆俱裂，几乎同时调转枪口指向獒犬！

“砰！砰！”

两声极其干脆利落、震耳欲聋的枪响，几乎重叠在一起！不是霰弹枪，也不是冲锋枪，是獒犬不知何时拔出的腰间配枪——一把老旧的、但保养得锃亮的\*\*.45口径M1911手枪\*\*。枪口爆发出巨大的火光。

两名护卫的眉心几乎同时炸开血洞，身体猛地向后栽倒，手中的冲锋枪无力地滑落在地。

办公室内瞬间只剩下硝烟味和秃鹫粗重、恐惧到极致的喘息。

獒犬看都没看倒下的护卫。他那双如同深渊般的眼睛，穿透弥漫的硝烟和尘埃，精准地、牢牢地锁定了瘫坐在巨大办公桌后，抖如糠筛的秃鹫。

他迈开沉重的步伐，军靴踏过昂贵的地毯，留下深色的湿痕和血印，一步一步，缓慢而坚定地走向办公桌。每一步，都像踩在秃鹫的心脏上。

秃鹫想尖叫，想求饶，想按下桌底的警报，但他全身的肌肉都僵硬了，喉咙里只能发出“嗬嗬”的、如同破风箱般的抽气声。他眼中只剩下那不断逼近的、如同死神化身的身影。

獒犬走到办公桌前，庞大的身躯投下的阴影完全笼罩了秃鹫。他没有说话，没有怒吼，没有任何多余的表情。只是平静地抬起了握着M1911的右手，枪口稳稳地指向秃鹫因恐惧而扭曲的脸。

秃鹫的瞳孔瞬间放大到极致，里面充满了绝望的乞求。

獒犬的手指，坚定而缓慢地扣下了扳机。

\*\*砰！\*\*

枪声在密闭的奢华办公室里显得格外巨大、空洞、且具有终结意味。

秃鹫的头猛地向后一仰，后脑勺重重地撞在真皮椅背的高处，留下一个喷溅状的、暗红的污迹。他眼中的光芒瞬间熄灭，只剩下死鱼般的灰白。身体软软地瘫在椅子里，额头上一个黑洞洞的枪口正缓缓渗出粘稠的血液。

獒犬垂下持枪的手臂，枪口还飘散着最后一缕青烟。他看都没再看那具尸体一眼，仿佛只是碾死了一只聒噪的虫子。他转身，迈着和来时一样沉重、稳定、沾满血污的步伐，踏过碎裂的门板，穿过弥漫着硝烟、血腥和死亡气息的走廊，消失在楼梯口的阴影中。

只留下办公室内刺鼻的血腥味、袅袅的硝烟、倒毙的尸体，以及那具瘫在豪华座椅上、额头开洞、脸上凝固着极致恐惧的“秃鹫”。

大楼的警报，还在徒劳地尖啸着。
