# 野狗-鸦巢的对峙

这之后，野狗进入了十四号穹顶城生活，并建立了名为“野犬巷”的帮派。与其对峙的，是十四号穹顶城本地的帮派“鸦巢”。

下面是这之后的一段场景：

"他们叫你野狗？"绸缎袖扣在煤油灯下泛着冷光，西装革履的男人用丝帕擦拭转轮手枪，"这绰号倒是贴切。"

弹巢转动声碾碎室内的寂静，一枚.45口径子弹被装进了弹巢。男人突然翻转手腕，银白色柯尔特蟒蛇在桌面划出刺耳声响，堪堪停在野狗指节发白的拳头前。

"五次。"镀金打火机窜起的火苗照亮男人刻意维持的冷笑，香烟在阴影中明灭，"在我抽完这支烟前..."他故意停顿，看着青烟掠过对方脸上那道从眉骨撕裂到嘴角的旧疤，"要么你就可以走，要么...给你的狗头开个天窗。"

野狗指腹摩挲着枪管淬火纹，钨钢的寒意渗入掌纹。他突然咧开嘴，露出他锋利得似有寒光的犬齿："我运气一向不错。"扳机第一次撞击空膛的脆响让水晶烟灰缸微微震颤，"六分之一的概率..."第二次空膛，他枪口纹丝不动对准太阳穴，"...连续五次的生存率是..."第三次击锤落下时，吊灯钨丝突然爆出火花。

房间内突然一片黑暗，只看得见那先生嘴里不安闪烁着的烟。他的香烟灰烬簌簌落在真皮椅扶手上。

＂真巧啊，不是吗，尊贵的...＂野狗把身体向前倾，正好让男人看见黑暗里他那冷峻的脸＂尊贵的，先生?＂

男人的嘴唇抽动了几下，但终究是没发出声音。但第四次空膛的声音传来，正好合上了旁边座钟突然的报时声。

野狗突然站起来，一只手撑着桌子身体前倾。他死死瞪着男人，两眼像是已经击发的枪口一样，似乎能映出硝烟。男人无名指上带着徽标的戒指不安地叩响了红木桌面，侍卫们枪套的搭扣声此起彼伏，像一群躁动的蟋蟀。

野狗的嘴角勾起一抹难以察觉的弧度。

第五次击锤抬起的瞬间，野狗突然调转枪口。冰冷的枪管贴上男人冷汗浸透的额角，侍卫们拔枪的声音淹没在突如其来的破门声里。

"现在轮到您复习数学了。"他握着男人的手扣动扳机，弹巢转动的机械声精密如刽子手的绞盘。

还是空膛声。

＂我运气确实不错，先生＂野狗的牙缝里挤出一丝冷笑。

男人想要甩开自己的脑袋，但是野狗已经把他的头死死按到了桌子上。

第六次击发，黄铜子弹终于带着体温跳进击发位，男人听见了自己动脉爆裂的轰鸣。

野狗抽走他齿间将熄的香烟，看着血浆从脑袋里涌出来，然后把烟头按灭在那枚带着徽标的戒指上，随后头也不回地走了出去。

＂不错啊，来得比我想象中及时。＂野狗接过手下递过来的大衣＂那么，我们来猜猜，＂

＂鸦巢的这群蠢货，知不知道我他妈特别记仇。＂
