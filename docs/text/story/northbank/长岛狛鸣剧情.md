# “我见到你的月亮...”长岛狛鸣摩挲着手里的十字架“那是月亮吗?”

“那是绞刑架。”野狗——不，现在他不是野狗了。他只是那个奥博连斯基，那个被名为雅罗斯拉娃的修女救下来的黑手党成员——他低声说着，又像是在梦呓“我们都会死去，我的朋友，”

奥博连斯基平静地看着长岛狛鸣，眼前的少女并没有被他脸上那狰狞的巨大伤口吓住，反而以同样平静的目光看着那张憔悴、衰老，却依旧令人不寒而栗的脸孔。

“像条野狗一样死去，但尽管如此...”

他突然大声咳嗽起来，本就不怎么干净的床单上又新增几块血迹。

“我不会像条野狗一样死掉，”长岛狛鸣捏紧了手中的十字架，“我不会像你一样，碌碌无为，苟且偷生。他妈的，你本来有那么多机会...”

奥博连斯基突然笑起来，混合着他的咳嗽声，像一只低声嘶吼的垂死野兽，露出残破却寒光凛然的獠牙——

“那咋了，我乐意，呵呵呵呵......”他眼里突然射出诡异的光“我们都是野狗，我们生来就是那样，我们就是那样生活的...呵呵呵呵...你想要改变吗...呵呵...”

他猛地坐起来，几乎个和长岛狛鸣脸贴脸——

“现在你才是野狗了，你才是野狗”他一字一顿“我只是奥博连斯基，我早就他妈的死了——跟那个愚蠢的教堂一起变成一摊狗屎的烂泥。”

长岛狛鸣强压住内心突然升起的一阵恐惧，这居然是她从未感受过的情绪。她想，自己在被鸦巢追杀时就该有一样的情绪才对，但她怎么回忆都想不起来。只记得那时，是眼前这头垂死的怪物，以难以理解的精确手法——当然谈不上优雅——带她杀出包围圈，从此将她一步步拉扯到如今。

“你至始至终都在骗我，到现在也是”她站起来“我绝不会成为你，绝对不会。”

野狗无力地向后倒去，脸上却仍然挂着诡异的笑容。

“我会保护好野犬巷，我会...我会夺回整个北岸，他妈的，我就是要救下所有人”她几乎瞪着野狗的眼睛，恶狠狠的说。

“不可能，呵呵...”奥博连斯基缓缓闭上了眼睛“呵呵...但愿吧...”

奥博连斯基的眼睛再也没睁开了。

“北岸”是十四号穹顶城的一个片区，也是十四号穹顶城帮派活动最为猖獗的地区。野犬巷作为北岸区的一个帮派，被继承了部分戍卫军团武装力量的帮派“鸦巢”压制。“鸦巢”企图完全控制北岸，并压榨当地民众，以此壮大，反扑其他区，将触手伸向整个十四号穹顶城。

长岛狛鸣是奥博连斯基救下来的一名仿生人。关于这个世界观中的仿生人设定暂时不谈。奥博连斯基将相较于普通人类，具备更强意识污染适应性的长岛狛鸣当做自己的接班人培养，但因为理念不和，两者常常出现分歧，但又因为目的一致，往往又能最终解决矛盾。

野狗死于意识污染病症恶化，死前将雅罗斯拉娃送给他的十字架转交给长岛狛鸣作为继续领导帮派的信物。长岛狛鸣自此成为新的“野狗”，尽管她并不喜欢这个称呼。她希望野犬巷的“野犬”们，更应该像是骄傲的狼，去撕咬出自己的自由。

“北岸”是十四号穹顶城的一个片区，也是十四号穹顶城帮派活动最为猖獗的地区。野犬巷作为北岸区的一个帮派，被继承了部分戍卫军团武装力量的帮派“鸦巢”压制。“鸦巢”企图完全控制北岸，并压榨当地民众，以此壮大，反扑其他区，将触手伸向整个十四号穹顶城。

野狗死于鸦巢袭击导致其意识污染病症恶化。他死前将雅罗斯拉娃送给他的十字架转交给长岛狛鸣作为继续领导帮派的信物。长岛狛鸣自此成为新的“野狗”，尽管她并不喜欢这个称呼。她希望野犬巷的“野犬”们，更应该像是骄傲的狼，去撕咬出自己的自由。

房间弥漫着血、劣质酒精和衰老躯体特有的酸腐气。奥博连斯基靠在污渍斑斑的枕头上，胸腔里拉风箱般的呼吸声是唯一的背景音。他瘦得脱相，那道劈开脸颊的旧疤愈发狰狞，唯有一双眼睛，仍像淬过毒的刀锋，冰冷，映不出丝毫对死亡的恐惧。

长岛狛鸣摩挲着手中那枚银十字架，指尖感受着其上的细密纹路——那是雅罗斯拉娃修女的遗物，如今却成了她手里的冰冷信物。

“我见过你的月亮…”她轻声说，更像是在质问自己。

奥博连斯基喉咙里滚出一声破碎的轻笑：“…那是绞刑架，狼崽子。我们…都会吊死在那儿。”他咳着，暗红的血点溅上床单，像枯萎的花。“像野狗一样…嘿…但好歹…”

“我不会！”长岛的声音陡然尖锐，她捏紧了十字架，金属边缘几乎嵌进掌心，“我不会像你一样烂死在这儿！你本可以…”

“我乐意。”老野狗猛地截断她，眼中爆发出一种近乎癫狂的、看透一切的嘲弄，“我们生来就是野狗…活着是…死也是…你想变个花样？嗯？”他猝然前倾，腐朽的气息扑面而来，枯槁的手抓住她的手腕，力量大得惊人：“现在！你才是了！野狗！老子…早他妈和那破教堂一起烂透了！我是奥博连斯基！只是奥博连斯基！”

长岛猛地抽回手，心脏在胸腔里狂跳。这不是对死亡的恐惧。是对这份沉重、污秽、却又将她从鸦巢枪口下拖出来的这份遗产的本能战栗。她厌恶他的认命，却又无法否认是他教会她在这地狱里撕咬生存。

她站起身，背脊挺得笔直，强迫自己压下喉咙的哽咽和指尖的颤抖。

“你骗了我，”她的声音冷了下去，带着一种几乎不容置疑的决断，“从开始就在骗。我绝不会变成你这样。”

奥博连斯基瘫回枕头，剧烈的咳嗽撕扯着他，但那抹诡异的、了然的笑容始终挂在嘴角。

“我会守住野犬巷。”长岛盯着他逐渐涣散的眼睛，一字一句，如同宣誓，“我会拿下整个北岸。鸦巢会被连根拔起。我会救下能救的每一个人。”

老野狗发出一声极轻的、仿佛来自肺腑深处的气音：“…傻话…”他眼皮缓缓垂下，最后一丝光晕消失前，含糊地嘟囔：“…随你吧…”

呼吸声停了。

房间陷入死寂。

长岛狛鸣僵硬地站在原地，许久未动。窗外，对岸的霓虹灯光透过肮脏的玻璃，在她年轻的、强装镇定的脸上投下变幻的光影。她缓缓抬起手，将那枚还残留着对方体温和血迹的十字架，紧紧攥在掌心，直至棱角刺痛皮肉。

她最终没有再看那具迅速冰冷的躯体一眼，转身走向门口。脚步沉稳，背脊如钢。

“召集所有人。”她拉开门，对守在外面的手下说道，声音没有一丝波澜，却带着一种前所未有的、冷硬的权威。

“北岸该换主人了。”
