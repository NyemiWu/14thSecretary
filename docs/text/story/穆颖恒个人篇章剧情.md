# 穆颖恒之章

人物：

穆颖恒

薇薇特

米娅

许翡叶，Rafael Xu

主角穆颖恒，学生时期，为人正直阳光，人缘极好，成绩优异，然而父母的压力却使他喘不过气。以他为组长的学生团队，是他的避风港。他和伙伴倾诉过这些压力，最难受的一次，他说自己打算离家出走，辍学去往另一个片区去打工、生活，他的伙伴们意见纷纷，但也还是尊重他的选择。彼时，这个团队的研究成果正进展到最关键也最难的一环。

小组里有另一个男生，同样成绩优异，但是沉默寡言，不会与同伴主动来往，他自恃清高的态度会时不时挑起团队矛盾，这时，作为组长的穆颖恒总是第一个出面调解。

也是这个时期，穆颖恒在一次偶然中邂逅了青涩的女仆薇薇特，少女被对方的阳光和温暖深深吸引。

那天，穆家夫妇又一次将压力倾泻到长子穆颖恒身上，他本想和从前一样继续忍耐，直到母亲提到了薇薇特——母亲从几个同学口中得知了这个名字，得知了穆颖恒时不时与她见面。当初是穆颖恒执意放弃了考取编制的路，转而去读他更热爱的学科研究生，如今又疑似不顾学业染上“早恋”，这无疑激怒了极度严苛的母亲。

这一次，他没有再忍耐了，他第一次正面跟父母爆发冲突。

躲在黑暗的房间里，捂着耳朵的妹妹穆颖芊，最后只听到一声摔门的闷响，随即是母亲一人的辱骂，然后寂静。

他决定出走了。他早已经做好了计划，取走了寄存在学校的行囊。但当他走到桥边时，他看向学校的教学楼，属于他的团队的教室依然亮着灯，他志同道合的伙伴们依然在学术的一线发出微光。他又想起了那个青涩的少女，倘若这一别，恐怕就再无缘见她了——至少，也要好好道别。

然而命运之轮于此时开始转动。

一个关于仿研所的叛徒，至高联合，至高肃正，以及意识生物拉斐尔的故事即将拉开帷幕。

XX：穆颖恒的组员之一，后进入仿研所工作，是有天才头脑的研究者，但是性格孤傲不合群，总是不屑于与愚人为伍。他独占了团队的研究成果，作为他投靠至高联合的投名状，并陷害穆颖恒、将其注射了感染剂并推入河中（但穆颖恒后被白淇救上岸）。他是达尔文主义者，坚信至高联合宣传的新进化，更坚信自己就是那个至高进化者，于是与意识生物拉斐尔融合。

拉斐尔：意识生物，治愈天使，能力是每次死亡后会进化并复苏。能够扼杀意识生物复活特性的温迪戈是拉斐尔的天敌。
