# 河管办

河岸管理办公室，超氧公司派出整治河流污染的小队。主要任务含：意识污染清理，淤积污物清理，沉积价值物打捞，桥梁房屋等公共设施建造，建立河岸街道并吸引入住民众和投资者。治理完成后，河管办小队在清澈许多的水下意外发现了灭绝的白鳍豚。

故事中期，三位仿生人少年意外发现了一只美人鱼（意识生物），她自称失忆，是河中诞生不久的、意识污染的受害者，三位少年与她相处一段时间，培养起了信任，向监护人和公司隐瞒了她的存在。但好景不长，三人发现总是有一些不对劲的事情在阻挠他们......

- **清桡**，女，仿生人。ESFJ时常自信过度，吃瘪会气鼓鼓的像河豚，有估价寻宝天赋和商业头脑，喜欢吃小摊。奇美拉：河豚，狗鱼

- **淮舟**，男，仿生人。INFP，内向，社恐，建筑设计师，三人的队长。奇美拉：河狸，水獭

- **濯帆**，男，仿生人。ESTP（ESTP的不成熟表现为爱挑战极限）充满激情，形象帅气阳光，三人中的王牌打手。奇美拉：虾蛄（雀尾螳螂）

- **沈嘒宵**，字**启明**，ENFJ/INTP女，超氧公司科研人员、仿生人陪管研究员。从培训期就陪伴三人，河管办成立后在后方营地驻扎，定期叫三人回来维护，宛若三个少年少女的母亲。（“嘒彼小星”“肃肃宵征”，出自《诗经·国风·召南·小星》，是先秦时期的一首诗，描绘了夜空中微小的星星，以及那些为官家奔忙的小人物的生活状态。诗中通过星星的微光闪烁，象征着社会下层小人物的命运多舛和无奈。）三名少年称呼她“启明女士”“启明老师”“嘒宵姐”。其真实身份大有来头，也因此公司信任她一个人的能力足以胜任管理三名仿生人。

- **白淇，**女，意识生物，人鱼模样的姣美女性，随性可爱，聪敏过人，为了生存而欺瞒所有人，传说中的鲛人、塞壬一类，真实身份是灭绝动物白鱀豚（最后一只名为淇淇）的意志。象征物：珠泪般洒落的谎言。

梗概：三位来自超氧公司的少年仿生人被派往治理河流意识污染，执行清理、打捞、建造、经营等任务，发现了一只人鱼形意识生物——白淇，她的真实身份是意识污染的核心，为此，三位少年要在挣扎中做出选择。

大纲

**第一章：**

三位仿生人出厂，在启明女士的陪训下通过训练，启明女士为三人赐名清桡、淮舟、濯帆，并委任看似最内向、柔弱的少年淮舟为三人小队的队长。

河道污染扩散严重，周边河岸已经不适合人类靠近，因此除了驻扎在外岸的启明女士，其他少量人员都只在大后方乃至本部提供后勤支持。

部署临时营地后，展开前期工作，勘察、考据、采样、测绘等。

在不知多少日忙碌后，三人躺在河面竹筏上漂泊，仰望朦胧的星夜，畅想河岸的未来。那一夜，他们决定成立“河岸管理办公室”。

**第二章：**

任务前期工作完成，进行勉强算顺利，三人的分工明确偶有矛盾，渐渐地清理了部分意识污染和沉积物，河道外的污染值显著下降，在清桡带头沟通的努力下，渐渐有居民商贩等入驻外岸。

**第三章：**

任务进行到了中期，需要深入探索河床深域再制定除污计划。清桡和濯帆充满自信，而淮舟却感到隐隐不安。果不其然，即便做好了万全准备，三人也在河床深域遭遇了不测，强大的污染冲击和洪流从污染源袭击了他们，淮舟拼命拽住了另外二人并试图游离危险，在濒临昏迷之际，他看到一道灵动的身影游来。

三人醒来后，已经躺在了河畔的砂石滩上，砂石中还有几粒洁白的珍珠闪闪发亮。三人将事件汇报给启明女士，对于三人的死里逃生，她在担忧与关心之余也若有所思。

。。。。

正式结识了拯救他们的人鱼，人鱼自称白淇，本来就诞生、居住在河里与世无争，直到被意识污染影响后失去记忆、被漩涡裹挟来到这里，暗中发现正在清理河道污染的三人，那天三人遇到危险，她便出手相救以报答恩情。但白淇也提出了条件，她不信任没有见过面的人，所以要求三人对她的事情完全保密，三位少年不假思索地答应了。

（后来启明无语地扶额：...自然界怎么会有野生的人鱼啊！没办法，仿生人缺乏常识很正常。）

**第四章：**

河管办三人与人鱼白淇的关系越来越友好，白淇偶尔会帮助他们完成一些任务，作为回报，三人在清洁的河床上为白淇搭建了新的居所。只是他们没有注意到，尽管三人在外对此事只字未提，也难免有目光从暗处投来。

认知监察组织——至高肃正早已盯上这片河域的怪象，尽管超氧此次以仿生人手段出手治河，已经暗中向肃正者势力报备，但肃正者还是密切监视着污染的河域，他们已经注意到，那只可疑的人鱼形意识生物，实质就是该域意识污染之核心。根除隐患，肃清孽业，不可恻隐。他们的使命很明确，收容危险意识生物——白淇。

超氧本部在眼线的汇报下，也得知了作为污染源的意识生物的存在。本次治河明面上是民生福利和环保除害活动，实际上是为了控制河域管辖权、为武装进军北岸和谈判增添筹码。也因此，超氧希望控制污染，但并不愿意在短期内根除污染。另外，对于意识生物白淇，它会是绝佳的奇美拉意识素材，成为打造新一代搭载声纳功能仿生人的意识基石，还可以通过地下渠道转手、天价卖给富人作观赏用。必须赶在肃正者出手前夺取它。
