# 穆父线

【穹顶有巨大的缺陷！巨人的苏醒是必然！】

【穹顶…巨大缺陷…

…巨人必然苏醒…

所有…】

女二的母亲，年轻时，不顾家里的反对，以名门大小姐的身份与女二的父亲私奔。她坚定地相信，这位年轻、有才但缺乏自信的小伙，会作出一番事业，甚至成为拯救城市的英雄

“我发现了穹顶系统的一个隐患，不，应该可以说是巨大缺陷。放着不管的话，它将在潜移默化中同化人类精神——也可能更糟。我正计划着 设计一个新的、更完美的穹顶系统。但那帮人并不看好我，我的论文也石沉大海了，所以…唉”

“既然有计划，那就去做啊！你要自信才对！”

这是穆氏夫妇的往事。

穹顶系统是完美的，市民们需要这么认为，穹顶的维护者也需要以此保住工作。穆先生的论文实则是被有意雪藏了。但随着时间推移，超氧和仿研所先后发现了穹顶系统内的矛盾。后来，穆的论文在这些机构内得到重视。

“如果测算仪器没有同时损坏，那这道波动后最大的可能性是，西北方向，有一座穹顶城崩溃了。”针对“316意识浪潮”现象，十四号城的官方科学报告会议，报告人语气凝重。

为了避免市民恐慌，这个消息被尽大程度地封锁了，但没有瞒住同为科学研究者的穆先生。

如果能找到这座毁灭的穹顶城的存在，那就能证明他的猜想全都是对的。

巨人的尸体在等待。

可穹顶的高墙无法逾越。

又过了多少年，此时的穆先生，为了家里的收入，不得不做违法的意识产品、仿生体的地下交易（加工，验货，倒卖）来维持生存，供两个孩子学习。但当他听到线人说，黑神党瓦解，一批仿生人和湿件流入走私网络时，他看到这是翻身的机会。但真正让他惊诧、心跳加速的是：

“等等，你刚刚说什么？”

“对，这个仿生人，它会吸收其他人的意识体。就像吃东西一般。”

这是让他血脉偾张的事实。

多年前

“现在穹顶还能运行，都建立它能维持长期休眠、不轻易苏醒这一前提之上。可如果它被唤醒呢？”

“如果猜想没有错，这个量级的意识体，要维持稳定、无害的构态，唯一可行的处理方法是，用另一个意识体去‘包’住它。否则，活化的穹顶意识足以把整座城市的生物送上天。”

“实验再次失败了，用来包覆α意识体的β意识体会被反噬，同化，或者自行消亡，这不应该…β意识体所用材料没有出问题，模态非常稳固。花掉了家里半年的收入和仅剩的全部投资，却依然承受不住α意识体的侵扰。除非…”

没错。这具仿生人，将是他设想中的，最合适的“吞噬者β”原型。

他瞒着家人，买下了这具仿生人。并将她放在自己的秘密研究所中。

二号彻底倒台。

女二在二号的计算记录中，发现了它所重视的东西——穹顶系统“一号”缺陷的证明。那是一篇论文，署名是他的父亲，最后修改时间是他和母亲失踪的那天。

！

“珂博，这篇论文的最后修改内容，里面是否有什么值得注意的东西？拜托了！”

“……发现了一段密文。我想，你们俩有必要看看。”

“会长，我想听听你的想法。”

“押宝一个超级个体去吞噬这样巨大的矛盾，可谓豪赌，我们可承担不起背后的风险。眼下最成熟的方案是，借助带回地面的‘那个东西’，将所有穹顶城连入量子网络，任一意识体破灭形成的空洞都会被其他意识体迅速补上，彼此兜底，形成真正稳定的‘联结系统’，这便是我们展开‘星火行动’的真正意义。不过，我们的世界还有多少时间？”

“下一次破灭，预计会发生在半个月内，来自十三号城的‘脑石’…根据‘蜂鸟’传来的情报，还要再加上十三号城政变爆发的可能性…这恐怕是迫在眉睫。”

“嗯，是时候了。对了幸司，你听过特洛伊城的故事吗？”

“…启明，我们会成为罪人的。”
