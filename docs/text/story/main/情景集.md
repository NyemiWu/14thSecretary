# 情景-重启

琳用最后一丝生命解放温迪戈，让意识生物的本能彻底吞噬她的人性。

“琳…？”

病床上白色头发的少女像受惊的松鼠一般退缩。女二伸出的手停滞在空中。

“琳”死了。他们治好的，是这具身体长出的另一个人。

琳的人格是从吞噬女二的情感而来。

随着与琳相处的这些日子，女二的情感再度丰满。直到青发的少女离开了她的世界。

于是女二跪在白发少女的跟前，双手逼她握住那把断刀，抵近额头，乞求她再一次刺穿自己的灵魂。

可白发的少女只是颤抖。

（琳没有死，也不是失忆了，而是人格退行后重启了。组成一个人需要人格与记忆和身体，琳的记忆和身体一直在，而她的人格来自与女二的相处，所以，只要她依然在女二身边，那么不管重来多少次，她都会长出“琳”这个人格。）

情景：铁吻

女二的双手被铐住，栓在墙上

她张嘴接过甩来的子弹，黑色的长发飘散开，划出一道轨迹

等她抬过脸来，咬在嘴里的是𬭎键化形的一把特质枪，头发凌乱间，是她准星般坚毅狠厉的眼神，仿佛在说，

“你们完了。”

砰！！

她用牙咬下结构特化的扳机，子弹轰击出膛，射穿了敌人的脸。

迷迷糊糊呆萌呆萌的

女二会说，“我想妈妈了”，然后开始哭得像个孩子

情景-执念

女二杀死琳的执念化作了意识生物。

“我向她的要害刺去，可她死死掐住我的脖颈，直到我再也无法呼吸。数不清这样无谓地厮杀了多少次，每一次我没有动摇。她也没有。”

冥蝶会浮现于女二的镜像里，可以通过模因传播和寄生。女二破坏了家里的镜子，破裂的镜面映出无数分裂的眼睛。她在痛苦的煎熬后，最终依靠于琳的关怀。然而她的倾诉却带来可怕的后果，冥蝶借由模因传播到了琳的认知中。杀死琳的执念在此刻高涨、具象化，化作要处之以极刑的长矛。

这执念催生的意识生物，本质依旧是【未竟】，只不过更加强大、无法摧毁，除非执念完成。

此时的琳共鸣了所有意识生物和仿生人的能力。想要击败祂几乎是不可能的。唯一的方法是先杀死现存的仿生人，使其削弱、失去一部分能力。由于此时持有琳的刀，所以也就具备了一部分“吞噬者”的特性，可以吸收被杀死者的能力。（击杀名单和顺序可以由玩家选择。会触发不同分支剧情。有些仿生人不会反抗，有些会在同伴先死后向你复仇，有些必须同时击杀，有些会在一定时间内逃出城市必须尽快抓到并杀死，有些会帮助你杀死其他人或是提供情报。土拨鼠之日。）
