# 闫洇浮之章

剧情：闫洇浮袭击仿研所/琳的质问

（闫洇浮章，视角反转来到闫洇浮，琳和女二作为反派客体。闫洇浮最深的恐惧便是平庸。）

​

出城前，琳在超市里找女二嘱咐的采购物。她不小心碰翻了水果架上的几个橘子，堆成小山的橘子掉了几个到地上滚散开，她眼疾手快抓住一个空中的，又连忙去捡剩下的。这时，一个橘红色头发、戴眼镜的少女，帮她捡起了最后一个橘子，递给她。

“谢谢！小芊说过，被帮助了要说谢谢！谢谢你！”

那位少女穿着一件似曾相识的校服衬衫，散发着一丝不苟的正直气质，严肃地说：“没关系。这位同学，公共场合里请不要手舞足蹈，你碰倒的要是那个架子（指向一旁的红酒柜），可够你打三年工来还债了。”

“三年…三年？！那岂不是三年都不能买水果披萨吃了，补药啊啊——”琳捂着头边摇边叫唤。

“对，你的父母还会狠狠教训你一顿，没收你的全部零花钱，甚至还会让你退学，后果非常严重！”

“诶？可是我好像没有父母。”琳。

“啊！真对不起，我不是故意的！”正经的少女慌乱了一下，连忙道歉。

“（遭了糟了，小芊叮嘱过…）啊！我是说，我的爸爸妈妈可厉害了，会给我好多零花钱！根本花不完的！我闯点儿祸也肯定没关系的…吧？”琳的脑海里浮现的是女二一脸厌恶地说：果然应该把你丢垃圾场报废才对。

“噗嗤…你这人还挺有意思。以后可别笨手笨脚的。”

橘红色头发的少女别过，她拎着的篮子里装满了各种罐装咖啡、速溶咖啡、功能饮料和压缩饼干。琳对她橘红色头发的背影看着出神，又看了看手里的橘子。

“（她的衬衫，我在小芊的衣柜里也见过，是校服吧？）橘子，橘子…橘子小姐姐！再次谢谢你！！”

“我不姓橘！”

不远，“橘子小姐”接起电话。“组长，嗯，收到，我和提尔锋三点钟在现场报到。”

女二和琳出城时，闫洇浮直接带超氧人来仿研所刁难，一度动手，然后疗养师出面劝阻她。但闫洇浮非但不看老同学的情义，反而看到疗养师这个女二小跟班的怯懦的样子就来气（扭曲的心理），于是出手攻击，但疗养师也并不是真的糯，一声“对不起”就掏出术杖就挡下这一击，把音符生生弹开。

​半天后，正好女二终于回到仿研所，看到被打伤的众人，混乱的现场，以及打绷带的疗养师，瞬间就怒了，双眼瞪圆。琳也从来没见过她如此生气的样子。

“谁干的？”

“是超氧的人…不，是…音符。”

怒火攥紧了她的双拳。

“音符她留手了。不然，那个仿生人冲过来的时候，我已经死了，如果她没叫住的话。”

疗养师绷带下的抓痕渗着殷红，触目惊心。

女二强忍愤怒转过身，在她看来这是赤裸裸的挑衅。

闫洇浮愤怒地训斥了提尔锋，这次行动不应该杀伤对方（更何况是自己的校友）。但她也意识到是自己先动手，提尔锋只是想帮助自己解决目标。

终于闫洇浮和女二正面对峙上，2对2。

“那个软蛋，你的小跟班，她没死吧？”

女二不语，尽管她对这挑衅忍无可忍。（实际上女二不知道，闫洇浮其实是真的在担心疗养师，毕竟疗养师确实是被她所伤。女二和闫洇浮都是说话非常非常别扭的人）

“哦，现在有新的跟班了。我还以为，你会找个不怎么要喘气的工作。你是打算让仿生人抱着你跑吗？”

女二依旧不语。琳已经有些呲牙。

女二：“我是代表仿研所来解决问题的。依我看，贵方还是直入正题为好。”

闫洇浮脸黑了下去。这种无视让她恼羞成怒。

“你以为我在跟你叙旧吗？？你这个书呆子！”

琳和提尔锋在巷道间疾走、追逐、厮杀

闫洇浮和女二也陷入鏖战。

“那柄虹金，是教授给你的？就凭你也配？”

女二不应，调动贴身的虹金流淌，在要害处挡下闫洇浮的匕首穿刺，然后拉开距离，以虹金凝成手枪反击，精密的意识波弹轻易击穿了金属子弹也无法穿透的千年盾立场，但是被闫洇浮预判到而擦边躲开。

虹金手枪发射一发意识波，枪膛就会陷入几秒钟的不稳定波动态，需要重新凝形。而女二的做法则是每开一枪后立刻散掉手枪形态，将虹金收回身上，以应对可能到来的攻击。

这样下去太被动了。琳那边还在缠斗，我也无法甩掉闫洇浮，拖得越久越不利。

于是她将全身虹金调度过来，凝成狙击枪。然后，瞬间甩出，一发意识弹划破空气直奔闫洇浮。闫洇浮抓住这个机会，以虹金匕首护住眉心，弹开意识弹，瞬身冲到女二跟前，一记顶撞将对方推翻

没有虹金护体的女二失去平衡，被摁倒在地，随即，闫洇浮双手握住虹金匕首向她的咽喉狠狠刺来，女二则用两只手全力接住，两人角力。闫洇浮胜券在握，近身搏斗下，女二毫无胜算。

闫洇浮：“你在期待什么？你以为能得逞吗？”

女二：“自以为得逞的…是你！”

闫洇浮狠厉的笑容消失了，她这才发现不知何时对方的虹金狙击枪已经消失了。取而代之的是，下一秒，女二的袖子里窜出一条流金的细影，

“蛇？！”闫洇浮吃惊。

那流金的蛇张开口，迅速地扭曲着咬上闫洇浮的手，惹得一声吃痛的怒咽，然后蛇头迅速分散化作流动的虹金水纹在闫洇浮的手上游走，源源不断的虹金顺着蛇身注向闫洇浮，直到包裹住她整个拿匕首的手。紧接着，迫近女二咽喉的匕首尖开始软化，融化，退缩，顺着刀身刀柄逆流而上，形成反转的新刀刃，朝向闫洇浮的眼睛。（意志力决定了虹金的形态的稳定性，这也是女二虹金技艺的长项。）

闫洇浮眼睛睁得前所未有的大。她心里的愤恨也到了极致，她绝对不能容忍眼前的这个人在自己最得意的领域挑战自己一分一毫。“好啊，你要跟我比这个吗？！”青筋暴起，面红耳赤，闫洇浮和女二都将全部的意志力注入到匕首上，女二面色冷若冰霜，无波的眸里泛着无神的光，那黑洞让分外失态的闫洇浮感到一丝不寒而栗的恐惧。

没错，恐惧。所谓不甘也好，愤怒也罢，从一开始就是恐惧。她太害怕了，眼前的这个人，真的会把她的骄傲踩得粉碎。她也一直以来都做着这样的事。而最让闫洇浮害怕的，是这个家伙根本无意于此。不，她甚至从来无意于把自己放在眼里吧？就像看待那群庸人一样。

“我才、不是！那种蠢货！！！”

虹金匕首在剧烈的振动中爆裂开。宣告这场意志力的角力就此结束。

BE：闫洇浮死亡

闫洇浮的葬礼下着小雨。她的父母掩面泣不成声，“都是我害的，是我害死了小洇…”

僻静的远处，青发的少女却低声说，“是我们害死了她，对吗？”

黑发的少女注视着那边的一把把黑伞。“是超氧害死了她…不，或许，是她自己害死了自己吧。”

两人转身消失在阴雨里。

【是啊。是谁害死了她呢？】

【当晚，我做了个梦。

闫洇浮喝得半醉，喋喋不休地痛骂她那些个不争气的下属。户外的夜风拂起我俩的发丝，那些烦恼也一并消散在风中。

“不到一个星期就要交付的项目，他们几个居然还有闲心给我买生日蛋糕！！你说这算哪门子犒劳啊？真是不给我省心…”她越说越来兴头。

“是吗？我看你明明乐在其中呢。”

闫洇浮冲我挤出一个气鼓鼓的鬼脸，脸上泛着难掩的霞红。

“时间差不多，他该来接我了。”她看了眼手机消息，眼神里少见地流露出些许暧昧。

我轻笑着看着她的侧脸：“好啊，以后有男人替我照顾你了。”闫洇浮把手伸向我的脸，发泄似的用力揉搓一通，“尽会贫嘴！”

一辆黑色的轿车缓缓停在路边。驾驶位车门打开，走下来一个穿西装捧着花束的高挑身影。

“常联系这种话就不说了，好姐妹，保重。”闫洇浮抱过我来，拍打了我的背。此时，我看到了那个捧着花的身影。

不，那不是男人，那是一张没有五官的灰白色的“脸”。

我的汗毛突然立起，倒吸一口凉气。那张脸用光滑的惨白凝视着我，发出机械的男性声音，

“这位女士，我要感谢你对闫洇浮小姐的‘照顾’。”

恐惧爬上我的脊柱，意识好似被卷入深不见底的漩涡。刚才的一切都消失了，只有那西装里白色的脸刻印在我的眼里。

他怀里捧着的不是花束，而是一枚青发的头颅。

“——！！！！”

那漩涡越来越大，将我彻底吞没。

】

黑发的少女从梦中惊醒过来，浑身瘫软无力，衬衫已经被冷汗浸湿。窗外的世界嘀嗒作响，桌上放着一封封信，那是闫洇浮的绝笔。她再也无法克制，五官扭曲起来，无助的泪水撕碎了她的面容。狭小而黑暗的房间里，她孤零零地蜷缩着，掩面啜泣着，直到天亮。
