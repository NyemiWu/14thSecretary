# 琳-女二剧情-闫洇浮章节末章

回到屋内。青发的少女站在窗边，惨白的光线射入，照亮空气里的薄尘，打在她凌乱的青色短发里的脸上，她低头看着自己的手，上面沾满黑红色的血污。黑色长发的少女，自顾自地收拾装备，想作出一副无事发生的掌控感来。一股难掩的火药味儿似乎弥漫开来。

终于，她身后传来了琳沙哑的声音。

“你要我杀了你的朋友，是这个意思吗？”

“超氧是我们的敌人…”

“是不是这个意思？！！”

突如其来，琳的咆哮震住了女二——她怔忪（zhengzhong，形容惊惧）失色，本能地低头，想要回避那双沸腾的眼睛。

“回答我啊！！”琳的情绪越发激动，眼看要动手。

女二紧张地举起𬭎键手枪：“别过来！”

她的喝止没有起效，愤怒而失望的仿生人少女向她走近。

“你要把我也杀了，是吗？好啊，那就开枪啊！”散发着恐怖气场的琳不断逼近，用心脏抵住了那颤抖的枪管。

“反正我也不是你的朋友，对吗？”问句里杂糅着苦喉的哽咽，四目相对，不到一尺的距离，青发少女噙着热泪，凝视着那汪深渊。女二气息紊乱，被那气场死死地钳住，无处可逃。

眼前的琳，陌生而可怖。

她大脑一片空白，无法思索对策，更无法扣下扳机。

10秒，压抑到极点的对峙后，琳那双炽热的眼睛甩下几滴眼泪。青发少女气势汹汹、头也不回地离去。女二脱力地瘫坐下去，枪也随即化作一摊软泥。冷风从门外吹进来，零星湿润从她的眼角渗出，她这才发觉。

在失去大部分情感后，她再也没有体会到浓烈的喜怒哀乐过。直到与琳相处的这些时光，那些鲜明而有温度的色彩似乎渐渐回来了。可是，这也揭示了让她不堪的事实，她今天对闫洇浮起的杀心，并不是什么绝对理智的判断，而是由愤怒驱役的，错误的判断。

冷静下来，或许是悔恨和自责又占据了上风，又或许是被琳突如其来的质问和离弃压垮了心，又或许是长期的孤独、无助、不被理解被引爆，她抱紧双膝，紧紧蜷缩起来，小声地啜泣。

另一边，琳逆着晚风跑出去很远，丝毫不顾虑自己的身份，也不顾行人的目光。

“小芊做的太过分了…！不…她也有苦衷才对，她也是受气了，说不定只是一时冲动呢…可是…那可是她的朋友啊！我…呜呜…”

她慢下脚步来，自顾自地掉了好一会儿眼泪，哭得乱七八糟，引得好几个路人都回头打量，没注意到她身后不远处，裹在风衣里的黑发的少女已经正默默地跟着，走走停停，保持距离，时不时用不经意的余光瞥视她。

女二的双眼还有些红肿，发丝在晚风中凌乱地起舞。她想要挽留，道歉，但她不懂得如何直面强烈的情感。于是她不敢接近那个熟悉的影子。

她也不知道琳是什么时候发现自己的。琳也没有向她靠近，二人很默契地保持边界。琳走在前面，一会儿踢踢路边的石子，一会儿蹲下来盯着野花上的瓢虫发呆，女二则吹着风，偏头看向远方夜分塔照射出的晚霞。

凉风吹得路上的行人们瑟瑟发抖，匆匆加快步子。

此刻，二人已分别坐在花坛边长椅的两端尽头，互相别过脸。过了一会儿。

依旧是琳先开了口：“对不起…。是我不好，我任性，我应该听你的，你是我的领航员。对不起。不管你把谁当作是朋友都是你说了算，我不该多管闲事。啊，我不是那个意思，我…我想…呜…”

“对不起。”芊说。

“…诶？”

“咳咳…对、对不起。是我有错在先。”她泛红的脸没有转过来，藏在厚厚的黑色长发里

“对不起什么？”

“我被情绪控制了。做出了不合理的判断。这是我的失职。”

“嗯，嗯，还有呢”

“还有…我拿枪指了我的队友，这无疑是错误的。”

“还有呢？”

“呃…啊啊，真是的！得寸进尺的话，我可要收回道歉了。”

“别嘛别嘛，嘿嘿。我被小芊一本正经的认错报告给吓到了呢。”

“…那你接受了吧？”

“不接受哦。难得能看到小芊这副表情，我呀，不多享受一会儿怎么行～”

“…不接受算了。”

“喂等下，我还没说完呢！”

青发的少女挪过来坐正，郑重其事地说

“那个说话很气人的女孩，是你的朋友，没错吧？”

“…姑且，嗯，大概算是吧。”

“那…”琳想问“那我呢”，但是到嘴边的话却没有勇气说出口。“那，去对她道歉吧。”

“可、可她还在超氧。”女二语气带着藏不住的犹豫，像在思索借口

“私下去找她不就好了，超氧也会下班吧，走，我们现在就去！”

“诶？？不是，等一下！别拽我——”她惊慌失措地抹了两下眼睛，低着脸被琳拽起手腕就跑。

“可以了，放手！琳！哈…呼…”女二停下来，喘着气，“琳，我不想现在去找她，尤其是，不想带着你去。”

云霞与时间都安静下来。

“…这是，什么意思？”琳回过头，对着女二。

蓝调的时刻里，熙熙攘攘的街道蒙上一层浪漫的忧郁。两个纤细的影子就这么驻足对立。

女二咽了咽口水，站直，说道：

“琳，可以看着我的眼睛吗”

“我要说了，你听好——不是以领航员和仿生人的身份，我想说

谢谢你，我的伙伴。

我不想去见闫洇浮，因为我不想把你拉进我跟她的矛盾里了，那是在伤害你。至于道歉，我会去的——下次。

今天，我只想要你的原谅，我…不知不觉间，我自己也没意识到的，我已经不能没有你了，现在不能，未来也不能。

所以…

所以不要再抛下我了，可以吗？”

她几乎是在恳求。

一排路灯很合时宜地亮起。

琳完全愣住了，瞪大了双眼，她的脑袋飞速运转。

“我是 小芊的 伙伴？那那那，我跟你比那个音符更要好吗？”

“嗯。”

“那…比风蕊呢？”

“你更好。”

“我，这是在做梦吗？”

“不是做梦。”

“你没有骗我吧！”

“骗你是小狗。”

“好耶——！！！！”

青发的女孩欢呼雀跃起来，兴奋地扑向女二。

“喂！！大街上都看着呢！”她本能想逃，却挣脱不开

“小芊！我绝对不会抛下你！永远永远都不会！！”少女的呐喊引来阵阵驻足回头。

黑发少女脸涨得通红。

“…嗯，我听见了——整条街都听见了。”

破镜无法重圆。

但失而复得之物，一定要好好珍惜才对。
