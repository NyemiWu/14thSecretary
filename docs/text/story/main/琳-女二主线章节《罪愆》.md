# 《罪愆》

**第一幕**

琳和女二接到任务，前往野林击败游荡的高危仿生人萨莉伽，从方槊口中得知萨莉伽是黑神党劫持改造的仿生人，其意识是纯粹的意识生物，对于靠近的个体有强烈的攻击动作，但杀人后不会同化吸收对方的意识，似乎只以意识生物的意识为食。

琳隐约有一种直觉，自己终于到该要面对的时候了。

当二人进入森林后，传来了强烈的意识波动，却没有物理动静，循迹前去，侦察到了无形的、隔绝认知的现实场域结界，二人谨慎地穿过，进入领域，映入眼帘的不是黑白，而是猩红的血月——血狩之罪林。

不祥之中，异响传来。

二人向树林深处的响处探去，看见几名黑袍独臂的肃正者和智械塔罗-审判，正陷入与萨莉伽的苦战。伴随萨莉伽的暴起，审判的核心被击穿掏出，彻底瘫痪，见状，四名肃正者从肋下取出并戴上哀恸面具，凄厉的哀嚎将萨莉伽重重围住。然而下一秒，两名肃正者就被赤红的光击飞，其中一人砸断了树干，二者皆失去生命体征。对死亡的恐惧通过尖碑碎片的意识共享链传递到仅存的两个肃正者。正当萨莉伽要猛冲向下一位肃正者时，一发极不和谐的巨响划破空气，击中了那躲闪不及的红色仿生人，不等她脚沾地，一道青绿色的闪电已疾速逼近到她咽喉前一寸处。

此时，萨莉伽突然迸发出红莲般的能量场，将近在咫尺的刀和琳一同击飞。即便琳娴熟地单手后手翻卸力，依然在强大的惯力下飞出十米外，飞身踩到粗壮的树腰上才蹲稳停住。开枪后的女二也现身，与落地的琳并肩而立，面对不远处的萨莉伽。幸存的肃正者此时也已重伤，对救场的二人有些意外：“是你…食人魔。”

奇怪的是，萨莉伽此时没有攻击的企图，只是开口呢喃出了几个奇怪的音节。女二无法理解，警惕着萨莉伽的一举一动，而琳却瞳孔骤然收缩，头疼欲裂，痛苦地用双手捂住了脑袋。也正是这个瞬间，萨莉伽非但没有发动奇袭，反而转身逃离了现场。

**第二幕**

见萨莉伽已经消失在树影间，女二立刻查看琳的状况，片刻后琳的头疼才缓过来。

“好些了吗？那个仿生人…她对你说了什么？”“她刚刚…叫我…姐姐？”琳疑惑，“然后我的头突然疼的要命，像有一群蜜蜂在蛰我的脑子，一些没见过的东西…我看到很陌生的画面，但又看不清。”

另一边，肃正者搀扶着另一名幸存肃正者走来，他们已经摘下哀恸面具——或者说，刚刚根本没来得及与面具合一就被萨莉伽打断了。“肃正之志无可违逆。现在，必须抹除——咳！呜呃…你们…”虚弱的肃正者向二人伸出手要抹除记忆，但她已经耗尽气力，黑袍里的身躯像风中残烛般颤抖。琳和女二无言，将两名重伤的肃正者安置在树下休息。二人已经不是第一次和至高肃正打交道，对此刻的状况没有很意外。

“所以，你们的目标也是那只红色的仿生人吧？我们只是奉命清缴，无意和至高肃正争夺。她的战力显然超出了我们所有人的评估，既然如此，我们该暂时联手。而打败她之后的处置，由你们决定。”女二率先提议，毕竟现在两名肃正者完全无力再对状态良好的领航员和仿生人出手，命不由己。

女性肃正者：“你是昆山门下的领航员，事已至此，至高肃正可以信任你暂时不会做出有违肃正意志之举。而你的这只仿生人…有任何出格，我们都将立即清算。”男性肃正者：“另外，对于你们组织首领的牺牲，我们很遗憾。作为合作诚意，至高肃正将向你共享一部分认知”肃正者将关于萨莉伽的情报说出，其中还有关于琳的身世与温迪戈的。

“这些信息是有代价的。保守秘密。”

**第三幕**

琳与萨莉伽激战

目光交错的刹那，萨莉伽道出：“（姐姐，我们，皆是罪人。）”一记致命的重击将琳击飞。

琳战败，阴暗的记忆将她吞噬，在肃正者锁链对萨莉伽的暂时禁锢下，女二带琳逃脱。

琳崩溃地大哭，她看到了那些记忆，知道了自己就是改变女二一生的罪魁祸首。她一直以来最希望得到的就是领航员女二的认可，可这样的现实无疑破灭了她的幻想，她觉得自己一定会被女二仇恨，她看到女二的目光像尖刀一般要将她活活拆解。

琳的意识创伤没有好转，过度吞噬意识滋养自身本就会导致温迪戈阴影的浮现，现在她的生命每况日下。

而女二，此前沉浸在昆山的牺牲中，在巨大的压力下处处强迫自己，用战斗麻痹自己，只为能担起昆山的遗志。如今搭档的倒下成为压垮她最后的稻草。或许自己错了，又或许一切都是造化弄人。她从琳口中得知了过去的真相，她已经完全不知道该怎样面对荒诞如此的现实。她或许该恨眼前这个仿生人少女，但不知道为什么，她一点恨意都滋生不起来。

女二决定先放下任务，寻找治愈琳的方法。

**第四幕**

女二深潜到琳的内心，在意识领域的影响下，此处所见依然是一片枯槁的森林。这里所见几乎没有色彩，白雪覆盖，荒无人烟，被琳吞噬的意识体如孤魂野鬼般倒挂、游离。干渴和饥饿逐渐吞噬女二，这是温迪戈的欲望外摄，也是琳的心病。

她认同了琳的阴影，二人在这一隅心境中促膝长谈。完整的琳也在此时诞生。

**第五幕**

重返野林，只见萨莉伽坐在石头上，脚边是先前那名男性肃正者的尸体，另外那名女性——也是唯一幸存的肃正者在地上挣扎着站不起来。哀恸面具依然在他们的脸上，涌出漆黑的血泪。

萨莉伽抬起空洞的眼眸：“（姐姐，只有你是特别的。人类不配做我的食物。）”

琳拔刀，没有半点动摇。

最终，琳和女二以前所未有的默契攻势压倒萨莉伽。萨莉伽受创，无力抵抗地被压在地上，闭上了眼，可是琳的刀却悬停在了半空，没有刺下，一如当年面对年少的女二时。

琳默默起身，收刀入鞘。背后是萨莉伽的不解愈发歇斯底里。“（为什么，为什么不愿意吃掉我？我不是你的同类吗，姐姐？！）”

琳没有回头：“或许我曾经是食人的恶魔，或许我曾经欲望着吞噬一个个同类，到头来填满我的只有无止境的饥饿。如今，我的名字是琳，我不再是本能的奴隶。”

萨莉伽发出绝望地咆哮，“（我是那么渴望，被你接纳，成为你的一部分，还要我怎样，怎样！你的灵魂才会看我一眼？果然，都是因为…！）”

她如发疯的困兽一般扑向琳一旁的女二，琳闪身到女二跟前持刀招架——然而萨莉伽僵直地停住了，带血的尖牙颤抖着，嘴里哈出炽热的血雾，胸口，她的胸口已经被肃正者的手从背后贯穿，淋漓的黑色液体里是她被掏出体内的心脏。紧接着，在萨莉伽痛苦的咆哮中，她挣扎的四肢被锁链牢牢束缚，离体的意识与心脏发出炫目而诡异的辉光——然后被肃正者之手一把捏爆。

猩红的结界散去，森林回到原来的样子，一切都结束了。

琳和女二收起武器，确认仿生人——不，意识生物萨莉伽死亡，其意识被至高肃正祓除。她们看向一旁，刚刚出手的，唯一幸存的肃正者，此时跪坐在地，膝上是死去的同僚：褪去了哀恸面具与头套，那张冰冷而年轻的男性面庞，安详瞑目，在树隙透来的阳光下映着苍白的光辉。她用血污的独臂抚摸他的脸，终于将他放下。

琳和女二看向彼此，肃正者虚弱地起身，走来，能量在她手上汇聚，“肃正之志，无可违逆。”二人警惕起来，琳将女二护在身后。肃正者抬起手，却揭开了面具与面纱，一头金褐色的短秀发散落到肩膀，清柔的面容苍白如冰，却又好像有某种余温，“我必须抹除…不，我要请你们忘掉这一切。”她抬起脸，睫毛在日光里闪耀，琳和女二不再警戒，向她微微点头。“谢谢你们。谢谢。”肃正者将手放在琳的额头，对二人依次执行记忆抹除。

白色的光点汇聚，将二人的意识裹挟，遮蔽了视线，不再看得清那位肃正者的脸。

良久，二人从草坪上醒来，周围只有恢复原样的森林，什么都没有发生过。
