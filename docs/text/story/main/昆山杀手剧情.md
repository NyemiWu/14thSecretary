# 对于制造昆山杀手的二号，昆山杀手就是城市的免疫细胞，它们用于肃清仿生人这种病毒。

打败昆山杀手的关键是诱发其突变，使其往错误的方向进化，然后因环境不适应性而被杀死

生物比喻

昆山杀手决战的夜晚会下雨。十四号城的雨，为了增加水汽循环效率，使用的是含有添加剂的冻雨，这可能是杀死昆山杀手的关键。需要有人往冻雨里添加反应剂。

让琳承当传播病毒的病原体。这就是夜袭装甲的作用。

夜袭装甲有广播意识信号的作用，用于聚集和诱杀昆山杀手

副作用：十四号城穹顶会排斥琳（识别为意识生物或者意识污染），潜意识扩散的影响会使得琳渐渐叠满来自穹顶的debuff

昆山杀手设定：

免疫细胞，会摄入、适应、进化。

对于琳，如果看作病毒，那么刀相当于突触

昆山杀手篇

琳做出预备跑动作，随后在高架公路上疾驰，拉出绚丽的青蓝色光带。

结局是在夜晚的城市，灯光聚光灯和直升机探照灯将街道与楼宇打成舞台，昆山杀手如丧尸围城般涌向琳，似乎重现了二十多年前恐怖主义泛滥时的惨相。

这是琳第一次以仿生人的身份站在市民的聚光灯下，这是她的成名之战。

在琳即将胜利的时刻，二号切断了城市内的通信网络，所有直播都被掐断了。珂博奥使用了某种技术，让琳在胜利后对整座城市放声宣告超氧的恶行。
