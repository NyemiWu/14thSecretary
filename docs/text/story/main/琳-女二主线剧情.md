# 琳-女二主线剧情

琳：Lynn女，仿生人。刚刚诞生时，心智仅相当于婴儿，但靠着极强的感知学习能力、共情能力，心智也会迅速成长。在与女二相遇时，心智约8到10岁。在面对二号的决战时，心智已经接近20岁。感官功能的强大加上意识交互，使她可以快速完成模仿和拟态。

性格：善良、开朗、外向、充满活力与好奇心，富有同情心，同时也莽撞、冲动，易于意气用事。

奇美拉：鹿，温迪戈。意识交互：离神断魄，精灵，吞噬者。

琳是第三代仿生人中的某个原型。她的意识素材来自于食人魔温迪戈，因此她拥有吞噬同类意识的本能。这一阴暗面在她诞生前就显现，并会伴随她终生。

动机：希望获得领航员女二的认可，希望保护所爱的大家，希望得到宠爱，追求自由与自然。

女二（临时称号），女性，青年，黑灰蓝色

长直头发，性格冰冷内向，行事理性利落，具有缜密的思维和优越的洞察力，有话直说的习惯偶尔会引起别人尴尬。身份是领航员，与仿生人琳是互补的搭档，二人性格迥然却又有着微妙的默契。

由于意识创伤，患有长期偶发性解离症状，发作时丧失现实感，发呆失神良久，失去大部分主观能动性，伴随有多疑、多虑、丧失信任感等心理症结。难以分辨梦与现实的界限，并可能因此长眠不醒。或许是因祸得福，这种解离也带来了一定的抗意识侵蚀体质（意识障壁更密），能隔断部分污染。见..\意识交互方法集.doc“解离症”词条。

喜欢的事物：机械，湖畔散步，茶，艺术字，

不喜欢的事物：运动，热闹的场面（但是对热闹的音乐会并不抗拒）

外在目标：完成组织的任务，继承昆山意志

内在目标：家

琳&女二的全部故事-三幕式

第一部：相遇到打败二号。毁灭孕育存在。我是谁？“我不再是食人的恶魔，我是琳”

第二部：至高联合降神计划。意义拥抱虚无。我从哪儿来？“我们不是为了被神明统治、或是成为神明而生的，我们是为了爱与被爱才降临到这个世界的”

——“我可以不是”

第三部：传承，培养继承人，散播希望。生命雕琢死亡。我要去哪儿？“我不想成为你的缺憾，我想为你留下一段完满。因为我们共同写下的故事才刚刚诞生。”

琳&女二的矛盾：1.琳的无意识暴走给女二及其家庭带来不可磨灭的创伤

2.  琳的冲动和女二的缜密在战斗中总是出现矛盾

3.  琳渴望女二的认可，但女二疏离且多疑，几乎不曾认可任何人

4.  琳总是对他人表现出同情，而女二总是理性决断（被误以为不把人当人看），眼里更多只有目标

5.  琳更向往自由、自然的生活环境，而女二更喜欢平静、有条理的生活

6.  女二会让深受意识污染或创伤的人解脱，她深知其痛苦，自己也做好了自我解脱的准备，而琳从最开始的极度不解，到看到女二发病痛苦时的理解，最后到自己也受到了意识污染，而她已经获得女二的认同、没有了遗憾，希望女二能为自己解脱；这时的女二也从了无牵挂、渴望解脱，变成了珍视身边的人和自己，所以她不忍完成琳的心愿。

第三部：回环书D.S(Da Segno)

（反派：战争？）

三战对人类的种种创伤，凝聚成了最可怖的意识生物“WARⅢ”。人类迫不得已用逆模因武器无差别清除认知，虽然抹去了祂的名字，但也造成了严重的历史断层。而现在，至高联合用逆模因武器向全体人类解放了祂的真名，带回了祂的力量与人们心中的恐惧。

文明被摧毁了。

女二通过壹，将意识回溯到一个个愈发遥远的、断代的过去，寻找灾难的源头与解决办法。她看到了与一个个挚友、与琳相识的日子，看到了城市合围，高塔筑起，戍卫军团殊死奋战，看到了千疮百孔的战火，看到了第一起意识污染，最后她看到了“现代”——壹诞生的日子，“平安夜时代”。

回溯结束，她使用了从回溯中得到的关键线索——海鞘入侵技术，她通过壹向平安夜时代的人们发出求救，以自身为领航员，将过去的人们领航至他们的未来，改写故事的结局。
