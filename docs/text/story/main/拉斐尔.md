# 拉斐尔

拉斐尔：意识生物，治愈天使。外表似蚕蛾。幼体身长约5公分，成年体可达三米左右。对应执念为牺牲与奉献，能力是在死亡后会自愈并成长，其血液和眼泪可以承载相近似的作用。它的血液和眼泪用于合成治疗剂，对治愈意识体和机体有极其夸张的效果。可以说，只要剩一口气——甚至是死亡后一分钟内的生命体，都可以被拉斐尔之血完全复原。这也是女二和琳不要命的战斗模式赖以存在的根基。但，凡事都有代价。这些伤势会转移到拉斐尔，或是持有拉斐尔契的人身上。

*【拉斐尔】正在破茧......*

主线

前情：女二和琳出城探索成功带回了幼体意识生物拉斐尔和若干研究成果

成绩平平的疗养师毕业后进入圣莱山德医院作为实习护士

疗养师受到莱山德院长推荐，加入新成立的仿研所七所。

闫洇浮自毕业就职于超氧后处处碰壁，经过打拼成为见习领航员，获得配备仿生人提尔锋。

超氧得知拉斐尔的存在，以前阵子的科学器材货车劫案为借口，派出力量去试探仿研所，闫洇浮领命。

疗养师加入仿研七所，这里的实质是围绕拉斐尔建立的收容所，同时也是仿研所的新医疗后勤部，而拉斐尔的秘密（伤势转移与起死回生）即便对仿研所内其他所的人员也是闭口不谈的，只有本所人员和昆山等人知晓。

疗养师目睹了被收容和残忍剥削的拉斐尔的样子，尽管她极力压抑对意识生物的同情，但还是忍不住向琳和女二旁敲侧击地倾诉过，而对于意识生物的态度，几人也流露出截然不同的观点。

女二：意识生物是危害人类乃至全生物圈的异种生物，需要保持敌对和隔离，必要时，也需要充分利用其价值。

琳：我们和意识生物确实没办法共存吧，但即便这样，看到意识生物，任人吃它的肉，喝它的血，不知道为什么，我也会变得难过。或许利用它们是必要的（下意识看向女二，又低头看自己，语气渐弱），可是，只是不能成为伙伴，就要变成奴隶吗？

女二：奴役，或是被奴役，杀死，或是被杀死，选择题的标准答案只有一个。

琳：也就是说，一定要有被虐待的一方吗？

女二：在所难免。除非......

    大纲

    城外生物实验室中，琳拿到罐子，澄澈的绿色溶液中装着一只蚕蛾。琳和女二完美完成任务，带着实验资料等回城复命。（待定，拉斐尔投入使用可能比女二加入仿研所更早）

    一段时间后。

    疗养师受到莱山德院长推荐，来到仿研所报到，她被分配到了新成立的仿研七所（拉斐尔收容所）。

    为了庆祝，疗养师请客琳和女二，女二和疗养师回忆了些许学生时代的事情。

    第一次学习控制虹金，得到年轻教授赠与的虹金，以及班上那个好强的班长闫洇浮。

    疗养师想起前些时候，闫洇浮曾向她递出橄榄枝去超氧面试，但被她拒绝了。疗养师并没有那个自信，她不想应聘失败后面对闫洇浮那凶巴巴的表情。

    一段算是休假的时间后，琳和女二在技术部领取了一种新研发的医疗剂，其效果惊人，可以有效地扭转战斗损伤。得益于它的兜底，女二和琳的战斗风格也愈发激进，一度在生死边缘起舞。

    超氧注意到仿研所的异常表现。仿研所作战能力上升速度快到了匪夷所思的地步。于是派人去调查。顺着一股奇异的药剂气味，仿生人提尔锋找到了仿研七所。

    自从来到仿研所工作一段时间后，疗养师的心情反而低落不少，琳问到其工作内容也总是隐瞒。

    闫洇浮带一批超氧武装人员来到了仿研七所，借口超氧货物被劫，要求质询这个“不明机构”。（超氧方态度强硬，与仿研所方爆发冲突。闫洇浮打伤对方的安保仿生人罡风，然后，她看到疗养师将某种试剂扎入自己体内，然后像施展巫术般的，她的身上凭空多出几道伤口，而几个安保仿生人则霎时恢复如初。这一超乎预期的景象震惊了闫洇浮，同时珂博奥的无人机赶到此处，闫洇浮意识到再战不利，于是带人撤退。）

    琳、女二、珂博奥赶到，看到了一片狼藉和正在包扎的疗养师。

    回忆

    学生时代，女二总是被闫洇浮找茬，二人关系可谓水火不容。

    她们总是争夺着第一。而在体能以外的科目上，闫洇浮总是被对方压一头。

    这是赤裸裸的挑衅。

    女二询问疗养师的伤势和遭遇，而疗养师支支吾吾，只说是超氧的人来了，受伤是意外。通过无人机拍到的画面，女二看到熟悉的闫洇浮的脸。她罕见地生气了，认为是闫洇浮打伤了疗养师，而疗养师惦记同学情谊所以包庇对方。对于这个结论，疗养师想要反驳，但又支支吾吾着不敢说明，显然有所隐瞒。

    回到本部，闫洇浮修理提尔锋。她总是严厉地训斥提尔锋，又总是保护他。

    待人都走后，疗养师一个人来到收容核心，封闭的收容装置，透过玻璃，绿色的荧光里，浸泡着巨大的意识生物拉斐尔，针头和导管刺入它的泪腺和全身各处，将液体源源不断的泵到体外。拉斐尔之泪，这是仿研所正在使用的医疗剂，原理是将伤势转移到拉斐尔身上以治愈使用者。当拉斐尔承受过量伤势而死后，它会自愈、进化并复苏，体型也由此成长。

    就在前不久，疗养师注射了另一产品——拉斐尔之血，使她临时拥有了一部分拉斐尔的能力，即，将身边人的伤势转移到自己身上。这是七所的所长同意的临床实验，如果成功，可以分担一部分拉斐尔的压力，防止其在一次次起死回生后进化到无法收容的地步。疗养师自告奋勇成为了第一只小白鼠，她同情拉斐尔。或许隐隐地，有些“羡慕”——她想成为那个牺牲自己去奉献他人的人。
