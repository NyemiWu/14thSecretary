# 学校

穆颖芊，闫洇浮，教授，同学若干

学校，实验教室，上午

教授：（穿制服，近四十岁男子，站在讲台上）虹金，是一种对意识有显著反应的特殊材料。距首次发现至今，已经在医疗和军事等领域发挥出无比重要的作用。它所承载的份量，可以说，象征着我们从意识灾害手中夺回的希望。现在，它就摆在你们的桌上。（学生课桌上、讲台上，都有一座方形玻璃容器，里面装着一枚掌心大的圆形金属球，表面闪烁着淡淡的虹彩）

教授打开容器盖，并托起容器

教授：在自然条件下，虹金性质稳定，密度接近于铁。（轻微摇晃容器，金属球纹丝不动）但是，在人体接触以后（把容器放回讲台，戴着手套伸手抓取虹金），他的物理性质将会彻底颠覆。（虹金在被抓取的一瞬间“融化”，变成一滩金属光泽的烂泥，从教授收回的手指间挤溢而出，流在底座上的一部分又重新固化）就像这样。而你要做的，便是集中注意力。（下一秒，底座上烂泥般的虹金顺着粘稠的流液丝又重新向上凝聚、钻回教授的手心，教授翻转手掌，虹金在他手里重新结成了一枚坚固的圆球。）然后，去感受它。（教授的手发力一捏，虹金球被“抓爆”成水银般向拳头两边溅射，但是没有散落出去，而是振动着发出低鸣，凝成一根四十公分长的、两头尖锐的杵，牢牢抓在教授手里。）理解它。（虹金又一次液化，像两条蛇一般缠上教授的手，沿着他的小臂蜿蜒游走，并且颜色也开始变化，先是变亮，然后变暗，再然后变成灿烂的烤蓝色）想象它。（虹金流回手心再次凝形，教授握拳放在眼前，虎口朝上，凝视着手下波动着、滴落着、凝结着的虹金——它变成了一把金属匕首，有着精密的血槽和一小排手写体的精美刻字。随即，教授将手一落而下，笃的一声，伴随清亮的金属嗡鸣，匕首稳稳地插在讲台上，刀锋闪烁着漂亮的虹光。）

讲台下的学生阵阵惊叹。

教授教学完毕，说明注意事项，授意学生自主进行虹金控制训练。

被取出的虹金球在不同人手里呈现出截然不同的样子，有的变成一滩水溅出去，有的只变形了一点点便纹丝不动，有的呈现出斑驳的色彩。

闫洇浮双手握住沥青一样粘稠的虹金，面色紧绷着，眼睛凝视着，像在和虹金打仗。不一会儿，虹金拉扯得越来越长，磨砂般的表面也逐渐清晰、光滑，最后变成一把大致呈刀形的武器，刀面如镜子般锃亮，映射出她挂着汗珠的脸。她终于松一口气。但随着这口气的呼出，刀的轮廓一下子融化，她不得不再次紧绷，重新维持刀的固形。终于，她将这把小刀对着顶灯举起，看那闪亮的光泽在流淌着，身旁的同学投来羡慕的眼神，

同学A：好厉害...一下子就成了

同学B：不愧是她啊

同学C：怎么做到的，根本不行

她没有在意，而是瞥向了后排的穆颖芊。然后，她原本那一丝微微得意的神色消失了，取而代之的是目瞪口呆。她看到穆颖芊手里的——

那是一把枪。

一把精美的左轮手枪。穆颖芊双手紧握着它，低着头，面色凝重，汗水浸湿了些许发丝，有些颤抖。

闫洇浮的表情有了些恼羞成怒，咬牙，禁不住地发出一声“啧”。其他同学顺着她目光也看向穆颖芊，于是议论的风向发生了转变。

同学D：我天

同学E：你看她...

同学F：跟音符（闫洇浮外号）比起来也没什么大不了

同学G：我也觉得...

穆颖芊身旁邻桌的女生（代号疗养师）放下手里的虹金（一只羊角的小玩偶），轻轻地凑过来

疗养师：（温柔、小声，带着高兴和期许）小芊，你好厉害！你是怎么做出来的，可不可以教教我呢？

穆颖芊依然垂着头，近距离看到，她的身体止不住地发抖。

疗养师：（惊讶地吸了口气）小、小芊？（关切）你还好吗？（担心）是不是身体不舒服？

穆颖芊依旧没有回应，只是颤抖着紧紧握住那把虹金凝结的左轮手枪。她的手指没有扣进扳机护圈，但，虹金也在颤抖，在主人的意志下发出阵阵嗡鸣，好像积蓄着某种不稳定的能量。

疗养师低下腰凑近一步，终于透过穆颖芊的发丝看到她紧张而恐惧的脸。她的双眼失神像一对黑洞，死死挂在那把枪上，脸上的汗珠清晰可见。

疗养师：小芊？！（惊吓到，头本能地后仰，她没有后退，也不敢伸手去碰。）

周围的同学议论声稍稍大了几分，疑惑，不解，好奇。“怎么了？”“不会吧...”

闫洇浮已经将注意力转回自己的虹金上，她对这些嘈杂感到越来越不耐烦。

疗养师：老师...！

不知何时，教授已经穿过课桌，来到后排的穆颖芊桌前。

教授：（面色凝重严肃，语气沉而慢）放轻松，把它放下。（又走近一步）穆颖芊，放松，深呼吸，让虹金自然散开......

在众人的关注中，穆颖芊脸色发白，双唇紧闭，呼吸急促，依旧僵硬地维持着姿势，就像被毒蛇死死咬住了一般。

教授：（眉头紧蹙，慢步靠近，右手试探性的放在身前，向她握着枪的手伸去）

疗养师紧张地捂住了自己的嘴。穆颖芊不像是在控制虹金，反倒像是被虹金控制了，无法挣脱出去。

教授：看我这边，别紧张，把注意力分散开，把它放下，听得到吗？

教授背后的左手攥着一团虹金，虹金流出，裹覆住了教授的整条左手。

穆颖芊：老师...我做不到...

无论如何用力，如何暗示自己“放下”，那把枪的外形都没有丝毫散开的趋势，她不敢放松，更不敢松手，她知道、教授也看到了，那转轮里是有子弹的。

教授：（突如其来地呵斥）放手！

像紧绷的弦断开一样，穆颖芊的手顿时松开，手枪向桌面掉去，然后——在半空中被教授那覆盖满虹金的左手稳稳抓住，拇指堵住枪口。坚冰般的手枪在教授手里好一会儿才软化开，与他左手的虹金融为一体。

教授：太危险了！下次不要乱来，否则我会给你记过。（把穆颖芊的虹金凝成球，装进她面前的容器里。转身走回讲台）

同学的议论声也停止了。教科书上的内容来看，虹金可以凝成锋利而坚固的武器，但热武器的激发需要火药或其他形式的蓄能，所以，那把手枪是不会开火、更不会走火的，充其量只是一把精美的工艺品——包括闫洇浮在内的大部分同学都是这么认知的。而疗养师，她更多是非常担心穆颖芊本人的状态。只有教授没有多说什么，而是把穆颖芊单独叫到了办公室。然后，领她去了学校的靶场。

教授：再试一次吧，像今天上课时那样。（将一盒虹金递给穆颖芊）

穆颖芊心照不宣。一把左轮手枪再次出现在她手中，然而她再一次“陷”入了虹金，意识难以挣脱。在教授鼓励下重试了几次后，她才终于维持住了清醒，凝成的手枪看上去比上课时的更稳定。

教授：嗯，拆开它，不要有任何情绪波动。

穆颖芊照做。枪管，握把，弹巢，弹簧，以及六枚子弹。

教授扫视一眼，拿走了子弹。

教授：很好，组装起来吧。

穆颖芊照做。然后，教授将一枚子弹递回给她。

教授：右手拿枪，左手握住这枚子弹。记住，依旧不要有任何情绪波动，不要对子弹有任何影响。感受它、维护它微妙的存在。

教授递来的子弹显然变得不一样了，细看轮廓有些模糊，拿在手里才感觉到，它正小幅度地振动着，与之前的“死物”相比就像被赐予了生命。于是，穆颖芊以一种肃穆的态度感受着它，理解着它，仿佛在与之共鸣。

教授：上膛，10米靶准备。

穆颖芊持枪对准十米靶，相比平时的射击训练多了几分紧张，她正在用一把不可思议的枪击发一枚不可思议的子弹，陌生感让她很难信任手中之物——更何况那还是一把枪。就算枪能够开火，那如何保证它不会炸膛，或是发生更难以想象的事故？

不等她继续深思，教授吹响了指令哨。

砰！

一道介于枪声、打字机声和音叉声之间的声响后，子弹砸在了十米靶的八环上。显然子弹初速并不如正常手枪，导致更久的下坠，否则它可能就正中靶心了。由于虹金离开了人的身体，便和普通金属无异，甚至强度更低，所以子弹瞬间融化、碎裂开，掉在靶纸下的地上。

穆颖芊：不可思议...为什么？（没有火药的虹金子弹顺利击出，即便威力不如预期的十分之一，也让她感到了惊奇）

教授：虹金很难打造成有效的热武器——教科书这么写的。但我们有某种直觉，意识液态金属的几乎一切性质，都可以取决于人的精神。正所谓，虹金是意志的延申，是心象的实物。

穆颖芊：唯心主义？

教授摇摇头。

教授：我个人相信，宇宙是一片汪洋，（顿了一会儿。）人的每一举一动，每一道涟漪，必定（重音）都有所回应（微微点头）。你的虹金以这种形态作出了回应，这是为什么呢？

穆颖芊：我想到了以前看过的枪械结构，很感兴趣，所以试着复现（低声）。

教授：这样啊。嗯..这些工件的尺径，还有这材料，用精神去做出来...啧啧，可不是一般人做得到的。怪不得老张说这届学生有家伙。不过，学校的书里没有这么古老的枪型吧？

穆颖芊：（不愿回应问题，若有所思地沉默一会儿）老师，今天上课的时候，抱歉，我控制不住自己，不管怎样都解除不了那块虹金，明明其他人都能做到。

教授：嗯。因为你手里握着的是一把枪，而不是摆件。上膛着，随时会崩开，自然也不敢放下。

教授：这把枪就是你的心，它还不能收放自如。按照上上个时代的心理测定标准，这年头绝大部分人都是潜在的精神病。而心病，特别是对于我们，那是足以致死的弱点。（郑重地拍拍穆颖芊的肩膀）也别太压迫自己，记住了，不知道该把枪口对准哪儿的时候，你就来靶场吧。

穆颖芊：（低头看看枪，抬头）老师，请等一下。（把枪递给教授）

教授接过枪，上了一发子弹，对准十米靶，屏息，扣动扳机。砰！靶纸上没有看到孔洞。

教授苦笑：用虹金做的枪还是太局限了。仿研所研究快十年了，依然造不出虹金的热武器。子弹的强度和侵彻力甚至不如扔飞刀。（把枪放在手里把玩一下，称许地点了点头）枪倒是踏实。行了，好好练吧，这块虹金是我自己的，能救命的材料，送你了，别伤着人。（把枪还给穆颖芊）

穆颖芊有些窘迫，没有接过枪

教授：嗯？收着吧，好材配人材。不违纪的。

穆颖芊摇摇头，指了指虹金手枪：那个，老师...能教我怎么解除吗？

教授无奈地叹气。

十米靶上没有子弹孔，而是一堆密密麻麻的“针”立在上面，由教授的手一拂而消失了。
