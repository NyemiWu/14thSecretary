# 昆山死了。

仿研所不在了。

恐怕琳也无法战斗了。

双眼空洞的黑发少女独自一人，回到了尘封的旧家中。

她记得被掳走那天，父母失散的那天，明明发生了好多好多事情，那么多的惊险，她却只记得一个念头。“八音盒坏了，我还没有修好。”

外面下着雪。

房间里湿冷。她坐在床边。火炉里没有火，落地窗外是一片白，那片皑白里有她的倒影。

那个八音盒摆在窗边的角落。上面的小人偶断掉了，与八音盒分开。八音盒也卡住了，转动发条只能听到喑哑晦涩的齿轮喀哒声，然后是寂静。

钢琴盖没有合上。偏偏只有那一天没有合上。琴键上积满了绝望的灰尘。上面那翻到最后一页的乐谱也是。

火炉里还是没有火。也没有柴。

垃圾桶里有一堆碎掉的陶瓷片和干枯的花枝。

她坐在床上，深海般的瞳色里映出窗户的两大片皑白。除此外，那双眸子里什么都没有。

她空洞地朝房门离去。

就在此时，她突然警觉起来

“谁？谁在那儿？”

转身的一瞬，她已经将虹金凝聚在手，变成一把手枪。

寂静。好像有沙沙的白噪音。轻得像灰尘在洒落。

她的警觉愈发尖锐。

集中意识。睁开眼。

她看到了角落的八音盒人偶，立在那儿。

！

不自然感绷断了那根弦。

砰！

一发子弹从虹金枪膛中射出，击中了人偶。人偶倒下。

她持枪瞄准，谨慎地靠近。紧绷着。

然后，像是有丝线牵引一般，人偶又立了起来。

砰！！

一发威力更强的子弹射出。瞬间击碎了人偶。但就在下个刹那，穿透的子弹在墙上回弹，最后碎成细小的虹金颗粒散落在地，也就是在这一个瞬间，人偶如时间回溯般修复了。地上的子弹碎屑也消失了。

？！

确认遭遇意识生物。她本想这么说，可是没有人可以听到。

睁开意识视野，她看见意识波动处有一只越四十厘米高的“幽灵”，穿着一袭黑色的长裙，没有左腿，脸挡在面纱下，似乎有蝴蝶闪翼的光泽。然后，幽灵游动过来，从她身旁擦过，蹿到了门外去。

她开始追逐那个黑色长裙的小幽灵。追遍了家里的每个角落。不论如何射击，或是用东西打砸，它的躯体——人偶，都会在不同长度的片刻后“恢复”，就像从未被攻击过。

凭借领航员的天赋，她很快找到了规律。

这个意识生物会在“攻击【完成】后”复原。落地停滞的子弹，放下的刀，每当她确认到自己做成功了，这个意识生物就会回应以功亏一篑。

这种事与愿违的感觉让她恶心。

她没来由地愤怒起来。愈发焦躁，焦躁得不像是她的作风。

明明做到了。

子弹穿过粉碎的人偶，然后一切复原。徒劳。

明明好好地做到了。

碎得满地都是，又消失。徒劳。

地上刮擦灰尘的痕迹也跟着消失了。像是嘲讽她的无能。

徒劳。愤怒。她将心智压进枪膛，一遍一遍地射击。

迷失而无能的愤怒间，她想起被掳走那天。

对了，八音盒坏了。我还没有修好。

嘈杂的记忆如雪花般涌来。

八音盒还没修好。

那首奏鸣曲没有弹完。

他们吵了起来。打砸东西。

不应该放着不管。

花瓶碎得到处都是。

垃圾桶里的垃圾得倒掉。

管家先生也坏掉了。

炉子里没有火。

要把哥哥找回来。

把爸爸妈妈找回来。

还要完成任务。

还有职责要履行。

理想还没有实现。

琳在等我。

不能逃避。

我不能。没有为什么。

肩膀好重。

真的好重。

八音盒人偶静静的矗立在那里。

她也矗立着，握枪的手无力地耷拉。

意识视野里，幽灵的黑色的长裙静静垂着，它面对着她，像是在等她做些什么。

她终于从恍惚中醒来。

这只意识生物是她的“未竟”。

【没有完成的事情，会刻在记忆里很久很久。

完成了的事，总是遭到遗忘，就像从未发生过。】

就像最后一根稻草。在意识揭露的一瞬间，她终于被责任压垮。

昆山，琳，父母，哥哥，老师，同学，还有好多人，那些期许的脸，在朦胧的眼泪里打转。

她失声痛哭起来。

“我还没有把他们带回来。”

未竟的事业，未尽的责任，像是恶毒的祝福，缠绕的水草般，把她死死地往水里拽。她的精神早就到极限了，或许是见昆山最后一面的那一刻，或许是闫洇浮倒在血泊里的那一刻，琳用失望的眼神看着自己的那一刻，或许更早。

人偶静静地矗立在那儿，就像矗立在八音盒上。

它自始至终没有展现一点敌意，它只是她的镜子，她未竟之事的执念。

哭了一会儿后，她才收拾好了自己。

重新坐在了尘封的钢琴前。琴键还没有擦，但她不想擦了。

乐谱翻回第一页。

双手悬落在琴键上方，随即音符奏响。

人偶依旧矗立在那儿，面朝着演奏的她。

良久，房间里只有钢琴奏鸣的乐声和乐谱翻动声。

她过腰的黑色长发散落，随着音符跃动，那乐曲和她那专注的模样都如此迷人。

但人偶只是矗立。

二十多分钟过去，乐谱又来到了最后一页。

沉重而响亮的琴音，情绪渐渐紧逼，像是有一股灼热的苦涩逼近咽喉，窒息，不得以挣脱。

直到最后那个和弦将要落下。

然而，最后的和弦没有落下。那口气久久地没有喘出。

她沉重地呼吸着，肩膀随胸腔上下起伏，黑丽的秀发盖住她的眸子，沾满灰的双手就这么悬停在琴键上方，停在最后一个音前。

因为她意识到这是她没有完成的事。这也是她要完成一生的事。

明明是这么沉重的认识，可这一刻，她却感觉到前所未有的安心和畅快，眉头与肩膀终于舒展了开。乐章从澄澈如明镜的水面上空飞去，不惊起半点波澜。合上钢琴盖。未竟的执着，终于在此刻瓦解。

“谢谢你。”

人偶躺在地上一动不动。

意识波动终于彻底归于平静。
