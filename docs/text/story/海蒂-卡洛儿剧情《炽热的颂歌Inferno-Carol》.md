# 《炽热的颂歌Inferno Carol》

主角：海蒂，女，26岁，ESTP，性子直烈，叛逆，不合群，有话直说，讨厌被规则束缚，迷恋赛车和速度，号称征服者海蒂（Heidi the conqueror）。年少叛逆的她将淡金色头发染成了红色，她飙车时连出动直升机都抓不住她。最大的愿望是在赛场上征服强者，视卡洛儿为宿敌。那场雨战成为她的心魔。

仿生人：卡洛儿（Carol，称号：颂歌），女性仿生人（奇美拉：阿哈尔捷金马，夸特马），外观24岁，ISTJ，奶油般光亮的淡金色头发，三无，毋庸置疑站在顶点的竞技女神，强大到无可匹敌，这份力量来源于在试验场中被严苛对待、调教，内心缺乏安全感，容易依恋能带给她安全感的人。在她眼里，海蒂是带来温暖的火，而她甘愿赴身于火中。

习惯：开心时会点头、仰头，生气时会气鼓鼓，并用拳头指关节敲击对方胸口，极度生气时可能还会上嘴咬

特性：从诞生后，她就被关在赛车模拟训练室里，看着海蒂的竞赛录像训练，她的特性是非常擅于分析和复制其他选手的运动，可以跑出完全一致的走线，压弯的角度也相差无几，且速度可能会比原主更快。就连海蒂那以激进著称的赛车风格，也被卡洛儿完全模仿了去。

关系：宿敌，姐妹

配角：

焚风：机械师，戍卫军团退役老兵，同时也是骑袭退役选手，莫西干发型

凯瑟琳：骑警，海蒂的骑友，曾将年少飙车的海蒂抓回警局，也是她将海蒂引荐到骑袭运动的赛场上。

BOSS：失控而意识生物化的新一代仿生人/使用违禁药物而异变的选手

教练

戍卫军团时代，强袭编制有一类特种士兵，被称作骑袭兵，他们会一边驾驭单兵机动载具，一边与意识生物短兵相接，他们的英姿鼓舞着那个时代的人们。为了纪念这一特殊的兵种，穹顶时代将**骑袭**发展成了一项竞技运动，选手需要一边骑乘量身定制的载具，一边使用兵器淘汰其他选手。起初这项运动是在北岸发起的，参赛者也都是些机车爱好者和爱打架的好事之徒，后来规模越来越大、越来越正式，到如今，名次已经由一些大企业赞助或自研的车队垄断，赛制与规则也变得和之前大相径庭。

而女主海蒂，正是城市里这项运动曾经的冠军，但她在大雨的退役赛中，败给了一位备受瞩目的完美骑手卡洛儿，并落得轻度烧伤和残疾，再也无法回到赛场。后来，卡洛儿成为聚光灯下的宠儿，华丽不败的赛场女王，主角却只能隐去荣誉，退居二线，偶尔给车队的老友打杂帮忙。

后来，主角因某些原因不得不和卡洛儿同居，并得知了对方是仿生人的秘密，同时还要照顾对方的起居（其实是被对方照顾）

主角依旧讨厌这个夺走她荣誉的异类，并视她为赛场上不得不战胜的宿敌。但随着关系加深，她的态度也发生了微妙的变化。这个仿生人其实是个心理非常依赖他人的家伙（三无属性），再加上她是根据主角的机体数据打造的，所以就像主角的亲妹妹一样。

结局：最后的比赛，主角复出，以选手的身份骑上车，拿起武器，与她的宿敌/妹妹同台较量。而异变突生，BOSS袭来。为了胜利，也为了保护妹妹，主角抱着牺牲的觉悟把速度加到极限，“我终于超越你了。”

但她回头看到的，不是那个高高在上的冷面女王被打败的错愕，而是一个普通的妹妹，害怕失去她的姐姐。

用载具爆炸的火焰杀死意识生物，也是致敬戍卫军团时代的战斗方式了。

卡洛儿不惜暴露仿生人的身份，冲进火海，救出海蒂

最后在城市的焦点下，两人搀扶着从火海中走出。卡洛儿烧灼的皮肤下露出仿生人的生体结构。全场哗然

结尾：两人戴着墨镜和帽子，卡洛儿小鸟依人地挽着海蒂的手臂，直到在街头偶遇凯瑟琳。海蒂已经停止染发一段时间，她的头发露出原本的、和卡洛儿一般的淡金色。二人亲密无间的样子就像亲生姐妹一样。

十多年前，刚上任的骑警凯瑟琳接到一个棘手的任务，逮捕一名未成年飙车的鬼火少女。之所以交给她，是因为没有人追得上这名少女，哪怕出动直升机也不例外。就这样，凌晨四点左右，持续半个月的轰鸣声终于停下，一个穿着皮衣头发凌乱的丫头被年轻的凯瑟琳亲手“请”到了警局喝茶。这年，两个骑友就此结下了梁子，也结下了友谊。

语录：

“你是哑巴吗？”“你是狗吗？”“你是跟屁虫吗？”“你原来是笨蛋吗？”“你还是个宅女啊？”“你是人机吗？哦忘了，你还真是。”

“今天，我终于超越你了。”

“别啊…为什么露出那样的表情…这样的话不就，没法在生命最后的时刻，品尝胜利的喜悦了吗…”

大纲

第一幕

海蒂的荣誉，从19岁一战成名到分赛冠军，打败无数经验老成的选手，以年轻而赫赫有名的“征服者”著称。

总决赛，雨战，被卡洛儿打败，轻度烧伤残疾，退役，而卡洛儿则一路高歌蝉联冠军，成为骑袭竞技的女神。

相比于曾经新星闪耀的模样消颓不少，给车队打杂工

曾经的车队因失去得力车手走向破产，被卡洛儿的所属集团收购，老友要么被集团挖走，要么转会，要么退出行业

得知车队老友们的下落如此，海蒂怅然，放下拖把水桶，站在大海报前，凶狠地凝视上面这个夺走她荣耀的女人，“颂歌”卡洛儿，特别是那一头浅金色的头发对她来说是如此刺眼。她发誓总有一天要回到赛场击败她，击败这个命中注定的宿敌。

“我一定！一定会打得那个洋娃娃满地找牙！”

可造化弄人。集团找到了她这个退役老将，邀请她作为卡洛儿的领航员兼教练兼陪练对手。海蒂火冒三丈，认为这是在羞辱她。但昔日老友的劝说还是让她冷静了下来，毕竟如果海蒂拒绝、或是和集团撕破脸，那留在车队的老友们都会受牵连。卡洛儿确实是毋庸置疑的最强骑袭选手，但其他车队的技术也在不断追赶，一度要后来居上，为了卫冕“颂歌”的名号，才找到了海蒂。

抱着了解对手的想法，她最终不情愿地接受了这份工作。

海蒂后来才得知，卡洛儿其实是参考海蒂的身体数据和基因打造的竞技型仿生人。她的竞赛数据最终会提交给超氧，以研发下一代仿生人。

来到新车队工作，卡洛儿正接受训练。海蒂没有给卡洛儿一点好脸色。她当然不能接受一个冷脸的机器人在自己得意的赛场上打败自己，更不能接受的是自己没有机会在下一次比赛中征服她。

车队介绍了骑袭竞赛的新规则和卡洛儿的情况，并给她俩测试了领航同步率——不出意外的，同步率非常低。赛场上海蒂作风激进，卡洛儿则稳重可控，几乎是一台只接受工程师指令的机器——但也正因如此，卡洛儿的成绩一直以来很难长进，她的潜能并没有被开发出来。

“这就是他们找你的原因，海蒂。他们的评估团队认为，你也好，其他人也好，不可能有人超越卡洛儿——可他们错了。卡洛儿不是不败的，他们重金打造的女神当然也会身败——而集团不允许那一天到来。”

“道理我都明白。但，谁能给我解释一下，为什么这家伙会住进我家里啊？？”

第二幕

日常

与仿生人同居是一件特别微妙的事。特别是，这个人是你的宿敌。更特别的可能是，她还是你的妹妹。

海蒂的住处不小。这里堆满了她在乎的和不在乎的玩意儿，照片，海报，装备，奖杯，纪念赛服，球棍，朋友送的礼物，各种杂物，几个大音箱上摆满五花八门的摆件，有些十年前的潮玩在今天看来依然不过时。沙发上两三摞不知道洗没洗的衣物，好几件掉在地上。卡洛儿目瞪口呆地正要往里走，海蒂一把拦住她，然后蹬掉鞋子也不穿拖鞋就往屋里跑，把浴室门口挂着的内衣裤迅速收了起来。

出乎她意料的，仿生人的起居模式与人类居然没多大不同。即便如此，二人的相处依旧水深火热。海蒂总是一脸不爽地面对卡洛儿，心直口快的她并不会考虑对方的感受。而平日那个高贵而耀眼的卡洛儿则反差地表现出木讷呆板的本貌，她似乎不那么在乎海蒂对她特别的恶劣态度，却对这一屋子的糟乱和海蒂过于野性子的行为很是烦闷。

海蒂把便利店买来的便当放进微波炉热了几分钟，当作二人的晚餐。几口狼吞虎咽后，她扔下没收拾的餐盒就要去泡澡。

卡洛儿突然起身拉住她的衣角，指了指餐盒。

“哈？”

晚上，疲劳一天的海蒂扔下卡洛儿，进屋子栽倒在床上便呼呼大睡。等到醒来时，她吓了一跳，惊讶地发现自己的屋子被动了个遍——确切说是被卡洛儿彻底打理了一遍，衣物被洗净烘干折叠好，摆件被摆正，相框上的灰尘被擦干，厨房的油烟污渍、浴室的水渍也擦干净了，洗净的锅碗筷也都沥干水收好，那些极其令人不爽的杂物全都收纳到了看不见的地方，过于脏乱、破旧一部分被打包扔到了门外边去。

海蒂的第一反应不是欣慰，而是生气，看到卡洛儿一脸木头地瞪着她，她更是气不打一处来，“没人教育你不能乱动别人的东西吗？！等等，我的XX呢？那可是陪了我七年的东西啊！”卡洛儿还是一脸木头，指了指门外。

海蒂把被当垃圾扔出门外的东西又拖了回来。她撸起袖子，打算教训一顿这个冒犯她的女人，可看到卡洛儿正望着她的冠军奖杯出神。

“喂，看什么呢？你自己没有吗？”

卡洛儿摇摇头。

海蒂短暂惊讶了一下。

“啊对了...你拿的奖杯都被集团收上去了吧。”

卡洛儿点点头。

“那还真是让人不爽......啧。我居然会共情你这种家伙。”

卡洛儿眼睛瞪得大了一点，被人理解，这是她从没有过的经历。

海蒂叹口气，“好吧。看到那个方的了吗？六年前还是七年前，我跑XX杯，那时车队和媒体都不看好我......”

海蒂绘声绘色地讲起这些奖杯背后的往事。

“那个呆佬，居然以为我不敢钻他内线！我一脚油门滑过去的时候，还能看到他一脸惊慌的表情，太逗了哈哈哈哈哈”

海蒂神采飞扬，自在地大笑着，仿佛回到了夺冠那天。

她没注意到的是，身边浅金色头发的少女呆瞪着双眼，微微张着嘴唇，用入迷而向往的目光看着她的脸。原来取得胜利是那么喜人的一件事，卡洛儿从不曾感受到。

驱使卡洛儿夺冠的从来都是集团的压力。

在海蒂准备一个人出门的时候，卡洛儿会用一种害怕和焦急的眼神看着她，用手牵她的衣角。

“啊啊啊...烦死了！我知道了还不行嘛，就出去一会儿。”

得到保证后，卡洛儿才会听话。

训练

海蒂本不想多插手，只当个教练做好本分。可她看到车队的新工程师和策略师过于缺乏实战经验，完全无法发挥卡洛儿的优势，心里还是非常不爽。她不能接受是这样徒有其表的团队打败了自己。

策略师还在有意无意阴阳海蒂。

后来她执意要踢掉原来的策略师，由自己制定战术，“我和他必须走一个”

出乎意外的是，车队似乎很重视她的意见，妥协了。

海蒂的战术风格非常激进、鲁莽，一开始有很多摩擦。

可也得益于她那些危险的奇思妙想，利用规则的漏洞和赛道特性，达成了很多捷径。

二人与车队不断磨合、改进，最终在赛事中，面对黑马挑战者，海蒂指挥的卡洛儿维持住了优势，有惊无险地卫冕了冠军。

但也就在此时，集团单方面解雇了海蒂，理由是她的作风给集团资产带来的损失风险超出了可以接受的范围，并支付了赔偿金。用人话来说就是，海蒂已经没有利用价值了。接下来，集团会格式化卡洛儿的记忆，并借下一次表演赛发布他们最新一代的竞赛仿生人。在计划中，新仿生人会在赛事中遥遥领先，与旧型号的卡洛儿分别包揽冠军和亚军，向市民展示集团的雄厚实力。

海蒂收拾包袱，离开了车队。她没有跟卡洛儿告别。她猜卡洛儿又会露出那个惹人讨厌的、矫情的表情，来动摇她的信念。“开什么玩笑，我怎么会吃这套？”

但这时，是老友兼机械师的焚风找到了她。这个莫西干头的中年瘦子一直没少照顾海蒂，他知道海蒂这一去恐怕再也不会回到车队了。

“好啦，本来就公鸭嗓还一副婆婆妈妈的样子，吵死人了。”海蒂笑笑，眼角含着泪，“走了。”

第三幕

那场表演赛，她本来一点也不想看。从早上浑浑噩噩地醒来，早得不像是她习惯的起床时间，然后心绪如乱麻般纠缠着，什么车队，战术，训练，她烦躁着，明明这些事已经彻底与她无关了。可等她反应过来时，她已经来到了酒吧，酒吧里稀疏的酒客都聚精会神地看着那电视屏幕。

“颂歌以完美的走线连过五个弯道，紧随其后0.7秒的是......”

海蒂的心绪像被拨动的吉他弦。她不由得咂嘴，抿一口酒，试图熄灭烦躁。

“续一杯，加冰。”

酒红色头发的青年酒保接过杯，熟练地调酒，呈上。

“这杯算我请的，请慢用，海蒂小姐。”

“切...被认出来了。”

“您放心，我不会告诉其他顾客。不过，他们大多都是你的老粉丝。”

“行。你就当不认识我吧。呵，你叫方槊，对吧，既然看出我不爽了，那就陪我喝一杯。”

“你说，反正都比不过仿生人，反正都会被取代，那我们这些人上赛场的意义是什么？”

“我们熟知的海蒂小姐...不，赫赫有名的征服者海蒂，她对镜头对面的对手大放厥词，把挑战书下到不可一世的老将家门口，当众怒骂赛制的不公平。她做这些事的时候，会鼓舞更多不能亲身来到赛场上的人，替他们出一口气。”

“出一口气？”

“嗯。被别人抢走了东西，如果换做是我，我一定不会善罢甘休。相信那位红发的女士也是这么想的。”

“啊，你说的没错。我正好有一口恶气还在肚子里头憋着呢。”攥紧拳头，将酒一饮而下。“看不出来，你这小伙还挺会聊天的。”

“职业需要。”酒保笑笑。

那场比赛如计划中一样，神话般的“颂歌”首次位居第二，将冠军拱手让给了集团旗下更新一代的仿生人。观众的嘘声和质疑如潮水般袭来，其中有不少人下了注。这样的结果显然是受到集团操控的，毫无竞赛精神的人偶戏，他们一开始借口的“用新时代的技术去碰撞出竞技的火花”这一遮羞布终于被撕下。表现不佳的卡洛儿，她的身名也从此破裂。

卡洛儿已经被迫忘掉了那些日常的生活，颅内嘈杂的白噪音中，她只记得有个声音曾炽热地呼唤着、指引着自己前行，像风暴中不灭的火焰一样。她几乎是完全机械化地跑完了表演赛，变得比从前更麻木、更无机质，所谓最强，也只是人偶罢了。现在，人偶到了谢幕之时。

她本闪过这么个念头。

念头越来越放大。

嘈杂中，那团火光越来越小，也越来越模糊。

她木讷无助地站在赛场起跑区，淡金色的长发没有了往日耀眼的光泽，曾经那飒爽的英姿如今却是行尸走肉。

就在这时，观众的吵闹和嘘声突然安静下来，随后，爆发出热烈的高呼，化作热浪一阵阵袭来——

“我们没有看错！征服者海蒂！是她！时隔一年，我们都知道她遭遇了什么，但现在，出乎我们所有人的意料，她奇迹般地涅槃！一年前的暴雨，此刻再度降临！它究竟会是遗憾的延续，还是复仇的宣告？”

“颂歌——卡洛儿！！你怎么可以输给别人呢？？！给我听好了！今天，打败你的，只能是我！我要看到你那洋娃娃一样的脸蛋拧作一团，哭着鼻子回家撒气！你那不可一世的，完美的，忸怩的，做作的样子，会和你颂歌的神话一起，碎得满地都是！而我，会以它们为养料，高歌我最后的胜利！”
