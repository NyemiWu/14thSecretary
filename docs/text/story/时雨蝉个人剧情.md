# “蝉小姐的武艺是无懈可击的！脸也是！”

“我们技术部门对她的表现很满意，她的陪练工作是昆山先生特地安排的。”

“即便是姐姐跟我一同出手，也没能从时雨身上占到便宜呢，你俩可不能小瞧她。”

“为什么不在一线作战？嗯...可能是要这种深藏不露的高手做咱们的底牌吧？”

我从同事们欣赏的目光下悠然走过，回以矜持而礼貌的微笑，一头齐耳短发也随我轻快的步伐起落律动。作为仿研所的作战型仿生人，其他人总是在去维修室和出外勤的路上，但我几乎从来不需要。我的工作是武术陪练，在形形色色的作战型仿生人前，我几乎未尝一败，再迅猛的刀剑也没法破解我完美的招架。然后，不需要我出手，对方就认输了。于是我就可以微笑着说“我只是险胜阁下一筹而已，承让承让~（尾音拖得很长）”——每每此时，我那没眼光的领航员就会翻白眼。

“二位可爱的小姐，幸会，前辈已经和我介绍过你们了。我的名字是时雨蝉，请多指教哦~（尾音拖得很长）”

我熟练地鞠躬微笑，接待刚加入仿研所的一对搭档。一个是黑色长发的少女领航员，不发一言地回礼点头。另一个是一名青色短发的仿生人女孩，外表似乎与我同龄，但却只是直愣愣地站着，用一种奇怪的眼神打量着我。三秒，四秒，那双眸子里的颜色愈发诡异，不自在的感觉爬上我的背，简直像把我看了个精光，我的微笑也变得僵硬起来。“遇到怪人了呢...”我暗想着，在尴尬中等到了对方的领航员先开口。

“我们进入正题吧，时雨小姐。”黑发的领航员手揣在制服大衣里，用手肘戳了下那个青发女孩儿的胳膊。

我抓住这个机会，回避了那个令人不适的视线。“当然~那么，琳小姐，还请不要留手哦！”

毕竟面对这么可爱的我，留手不是理所应当的吗？

然而我听到那家伙的第一句话，却是——

“蝉...好好吃！”

“......”“......”

“我可以吃掉你吗？（似乎有挂着哈喇子的声音）”

我没听错吧？？

是我的耳朵坏了，还是她的脑子坏了？

我不可置信地看向她，引以为傲的表情管理都险些失控，但那要把我吃干抹净的表情却给了我重重一击。

“你这家伙在说什么下头话...？！”

这句话是从我嘴里溜出来的，没有憋住真是抱歉。

带着刚才的羞耻，我在竞技场中心摆开了架势，左手扶鞘，机械的右手悬放在刀柄上一寸处，屏息凝视着十米外与我对峙的青发少女，她也紧紧握着自己的刀。

我轻语：“长刀，【止鸣】。放马过来吧！”

似乎起风了。

下一秒，视野里的少女骤然消失，一道青色的闪电突来，急促如雨的脚步在四米外爆开，一跃而起，闪光眩目，一记下劈猛然袭向我的头盖——“咣！”被我以同样迅捷的拔刀招架住。电光火石间，她炽热的眼神里映出我的刀光，于是，我趁机发起突袭——髋骨外的两只机械臂启动，拔出了我腰后的打刀，随即向那家伙挥去。一丝惊讶闪过，她提腿蹬在我的刀上，一记后空翻拉开了距离，迅猛的力道让我不禁后退几步。

青发的少女站定，歪了歪脑袋盯着我：“三把刀，四只手吗？大姐姐，你好卑鄙啊！”她的右手漫不经心地转着刀。

大姐姐？卑鄙？这都算什么话！跟这么多人交手至今，我还是第一次见到说话这么气人的家伙。我压抑着恼怒，挤出微笑说：“过奖呢，琳小姐的反应也不赖哦~（依旧尾音拖得很长）”

但我不知道的是，一会儿后我就再也挤不出笑容了。

那个青发少女好像跟她的领航员窃窃私语了几句，然后，她再次启动，持刀突来。

我丝毫不慌：“没用的！”

她的速度虽然难以用肉眼捕捉，但刀的落点，招架的本能，早已深深刻在了我的直觉中。

在这无死角的招架前，再强大的攻势也会迎刃而解！

不出意外的，“铮！！”一声刀鸣，火花四溅。

但超乎意外的，刀没有被架住，而是顺势滑下。

她要做什么？连斩？变线斩？还是转而突刺？无所谓的，我的刀反术是无敌的！

我的目光紧紧锁住那把青光闪烁的长刀——直到腿部突然传来一声闷响和一阵剧痛。

什么？

“咿呀——！”我很不优雅地失声尖叫出来。

那个青毛丫头，压低身子，一脚扫堂腿，踢中了我的脚踝，我失去重心朝侧面倒去，一身的铁疙瘩们跟地面打架，我差点被自己的刀划破了脸。

“你...！！”

“没想到吧？啊哈哈哈哈~！”她爽朗地笑着，像得意的小学生，又像动画里的老巫婆，总之在我听来就像俩块铁皮摩擦一样刺耳。

很不想承认，但她真的很擅长惹恼我。

我涨红了脸爬起身来。

“咳咳...阁下，真是，好·身·手·呀~”

“再来！”她退回到发起进攻前的位置。

我可爱的脸上涨出了不是很可爱的青筋，咬紧牙，摆好了架势，然后。

“欸？！”

等我回过神来的时候，失重感已经升袭上我的眼，一阵黑色的晕眩，随即地面再一次向我重重撞来。

“呜哇！！痛死了啊！！！”

我又被她一记扫堂腿踢翻了。这次甚至没有反应过来。

脑袋疼，肩膀疼，侧肋疼，还有那被她踢中的小腿更是，似乎在跟我一同尖叫。

我右手捂着小腿，左手扶着脑袋，一只机械臂撑起身子，另一只揉着肩膀。眼里尽是狼狈和委屈——要是正常人看到我这楚楚动人的泪眼，又怎么狠心下得了手呢？

可那个青毛丫头只是愈发上头，小跳着踱步，漫不经心地甩着刀花，脸上挂着得意而开朗的笑：“我热好身了！水煮蝉小姐，准备接下一招吧！”

“你叫我什么蝉？？？”

我气得不顾疼痛一下子站了起来，这一次，我决定不再坐以待毙。转守为攻，主动出击！

深吸一口气，正身，疾步，【止鸣】出鞘，一记足以劈开电线杆的、精湛的一文字斩，从正上方直直切下。还不止如此！两把握在机械臂里的打刀一并射出，左右袈裟切，从左右上方各自45度挥下。

三刀同出，可毁枫落，断雨露，止蝉鸣。

可是，那丫头泥鳅一般扭动，然后以一个诡异的姿势躲开，顺势向下俯身去。而就在她身子下沉的那一刻，一股不好的预感升上我的心头。

一声闷响，好像有什么裂开的声音，顺着我的骨头传进了耳朵里。

“咿呀啊啊啊啊嗷呜呜啊啊！！！我的腿——！！”

地面再次结实地亲吻着我。我则甩丢了刀，抱着小腿打滚。

“呜呃...真浮夸...”我的那个笨蛋领航员还在落井下石。

人不是都说事不过三吗？怎么会这样呢？

“你要干嘛啊！！还要不要脸了啦！你你你，啊啊啊你到底懂不懂比武的规矩！”

这时对面那个一言不发的黑长直领航员倒是开口了：“果然，你的下盘太脆弱了。虽然招架得很扎实，但下肢的关节却没有任何保护，骨材料强度也一般。琳，试着乘胜追击，攻击她另一条腿。”

“好嘞！”

我脊背一凉，快要被踢得粉碎的腿也跟着软了下去。

“不打了不打了！我认输！！投降！！是我输了呜呜呜呜哇......”我伏地求饶，连连磕头。

偷瞄了一眼，身后那个家伙又在用嫌弃和嘲笑的眼神看我。啧。回头再跟她算账。
