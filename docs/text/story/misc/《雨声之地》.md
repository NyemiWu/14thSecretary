# 短篇：《雨声之地》

老雷拖着那条在“低语沼泽”被腐蚀液泡烂的右腿，每一步都像踩在烧红的刀片上。劣质的防护面具滤芯早就该换了，每一次呼吸都带着金属锈蚀和某种甜腻腐烂的混合气味，直冲脑仁。他身后，是同样在死亡线上挣扎的“队伍”：沉默寡言的拾荒者“哑巴”，背着一个鼓鼓囊囊、用防水布裹着的包裹；还有小雅，一个从某个陷落的“静谧之城”逃出来的年轻女人，眼神空洞得像蒙了灰的玻璃，怀里紧紧抱着一小盆早已枯萎、只剩下几根焦黑枝干的植物——据说是她“格式化”前唯一偷偷带出来的东西。

他们已经在这片被意识污染彻底扭曲的荒原上游荡了不知多少天。补给耗尽，精神稳定剂只剩空瓶。幻觉如同跗骨之蛆：哑巴总对着空无一物的沙丘比划，仿佛在跟死去的同伴交谈；小雅偶尔会突然对着枯萎的植物低声啜泣，喊着听不懂的名字；老雷自己，则无时无刻不“听”到他那死在“认知瘟疫”中的妻儿，在耳边发出意义不明的、令人发狂的呓语。

“歇…歇会儿…”老雷靠着一段扭曲得如同巨人肋骨的金属残骸滑坐下来，肺部像破风箱一样嘶鸣。视野边缘，色彩在疯狂地蠕动、流淌，仿佛有活着的油画在试图吞噬现实。绝望像冰冷的铅水，灌满了他的骨髓。也许下一分钟，他就会像昨天消失的那个同伴一样，被突然“活”过来的沙地无声吞没，或者被某个看似避难所的幻影嚼碎。

就在这时，哑巴突然发出了一声短促的、沙哑的喉音。他浑浊的眼睛死死盯着个人终端——那东西本该早就被污染废掉了，此刻屏幕却诡异地亮起了一小块区域，断断续续地刷过一行冰冷的坐标代码，以及一个重复的、意义不明的词组：“雨楼…安全…雨楼…安全…”

“废…废了…”老雷喘息着，以为又是幻觉。但哑巴异常执着地指着那个方向，喉咙里发出更急促的“嗬嗬”声。小雅空洞的眼神也聚焦了一瞬，看向终端。

一丝荒谬的、连自己都不相信的念头闪过：万一呢？反正横竖是死。

靠着哑巴模糊的方向感和那终端时断时续、如同幽灵信号般的指引，他们在污染迷雾中又挣扎跋涉了两天。幻觉越来越强，小雅几乎是被老雷半拖半拽着走，哑巴则像一头沉默的骡子，固执地前行。就在老雷感觉最后一丝力气也要被抽干，准备放弃时——

他们翻过一座由破碎混凝土和扭曲钢筋堆成的“山丘”，眼前的景象让三人瞬间僵立在原地，连呼吸都停滞了。

一座巨大、扭曲的旧时代穹顶发射塔废墟，以一种违反物理定律的角度斜插在地面上，塔身覆盖着厚厚的、不断缓慢蠕动变化的暗色菌毯，散发出不祥的气息。这本应是污染深重的死亡之地。

然而，在塔基处，一个巨大的破口敞开着。破口内部，景象却截然不同！

雨声。

淅淅沥沥，清晰而持续，带着一种奇异的、安抚人心的韵律。但更诡异的是，那雨水是倒着下的！

无数细小的、晶莹的水滴，从布满蠕动菌毯的地板上凭空凝结、汇聚、升起，如同被无形的力量牵引，轻盈地向上飘去，最终消失在同样覆盖着厚厚菌毯的天花板里，仿佛被吸收了一般。整个塔内空间，弥漫着一层湿润、清新的水汽，与外面干燥、腐朽的空气形成天壤之别。破口处仿佛有一道无形的屏障，将塔内湿润洁净的空气与塔外污浊致命的污染隔绝开来。更令人震撼的是，塔内地面和墙壁上的菌毯，在雨水的持续冲刷下，呈现出一种被“压制”的状态，虽然依旧存在，但明显萎缩、黯淡，失去了塔外同类那种令人心悸的“活力”。

“雨…倒着的雨…”小雅喃喃自语，空洞的眼睛里第一次映出了光，她怀里的枯枝似乎也微不可察地颤动了一下。

老雷的心脏狂跳起来，不是因为恐惧，而是一种近乎窒息的震惊。他经历过“静谧之城”的压抑，见识过“蜂巢”的麻木，但从未见过如此…违背常理却又宁静的景象。这雨声，像一只冰冷的手，暂时抚平了他脑中妻儿的疯狂呓语。

哑巴第一个迈步，毫不犹豫地朝着破口走去。老雷和小雅紧随其后。

跨过那道无形的界限，如同踏入另一个世界。塔外的污染低语、色彩扭曲、精神重压瞬间被削弱了至少七成！虽然仍有残留的诡异感萦绕（塔壁的菌毯仍在蠕动，只是缓慢了许多），但那持续不断的、倒流的雨声，像一道清泉冲刷着他们濒临崩溃的神经。空气是湿润的，带着一种难以言喻的洁净感，深深吸一口，仿佛连肺里的污浊都被洗去了一些。

“安…安全区？”老雷的声音干涩发颤，难以置信。

他们小心翼翼地深入塔内。光线从破口和塔身其他裂缝透入，被弥漫的水汽折射，形成朦胧的光柱。然后，他们看到了。

在塔内相对空旷的中心区域，在那永不停歇的倒立雨幕之下，矗立着一座座姿态各异的…雕塑？

不，那不是雕塑！

那是人！被一种幽蓝色的、半透明的、如同纯净冰川般的物质完全包裹、冻结的人形！

他们凝固在生命最后一刻的姿态：有的相互搀扶，身体倾斜却顽强挺立；有的单膝跪地，一只手紧握着早已锈蚀粉碎的武器残骸；有的仰着头，张着嘴，仿佛在无声地呐喊；还有的，则保持着警惕的姿态，空洞的眼窝“望”着入口的方向。

而在这些冰雕群像的最前方，最靠近塔基控制区域的位置，矗立着一座最为高大的身影。他双手深深插入地面（那里蠕动的菌毯被冰晶牢牢压制着），身体挺得笔直如标枪，头颅高昂，同样被幽蓝冰晶覆盖的脸庞上，那双空洞的眼窝，仿佛穿透了塔壁和重重迷雾，死死地“盯”着某个遥远的方向——十四号穹顶城的方向。他破烂的军装前襟敞开着，露出枯槁的胸膛，仿佛在无声地展示着什么。

老雷认出了那身制服的样式，虽然早已残破不堪。那是戍卫军团的制式服装！是“牧马人”！他瞬间明白了那个幽灵信号的含义——“雨楼…安全…” 这是牧马人用生命换来的！用他们最后的存在，撞响了这座“塔钟”，驱散了部分污染，制造了这片奇异的、倒立雨声庇护所！

小雅慢慢走到一个保持着搀扶姿态的冰雕前。冰层幽蓝剔透，能清晰地看到里面士兵年轻而痛苦凝固的脸，以及他搀扶着的、另一位半边身体都覆盖着类似岩石纹理的同伴。她颤抖着伸出手，指尖轻轻触碰那冰冷的表面。

刺骨的寒意顺着指尖蔓延，但奇异的是，伴随寒意而来的，并非死亡的恐惧，而是一种深沉到令人落泪的…悲怆与决绝。那感觉如此强烈，仿佛冰封的不是躯体，而是他们最后燃烧的灵魂。小雅眼中积蓄已久的泪水终于无声滑落，滴在她怀中那盆枯枝的焦黑土壤上。她没有擦泪，只是更紧地抱住了花盆。

哑巴默默地卸下他沉重的包裹，放在相对干燥的一角。他走到常思将军那座最高大的冰雕前，没有敬礼（他早已忘了如何敬礼），只是深深地、深深地弯下了腰，额头几乎触碰到冰冷潮湿的地面。一个无声的、沉重的敬意。

老雷环顾四周。倒流的雨滴依旧淅淅沥沥，永不停歇地向上飘去，消失在菌毯覆盖的天花板。雨声在这死寂的塔内空间回荡，是唯一的背景音。冰雕群像在朦胧的光线下肃立，如同沉默的守护者。塔壁的菌毯在雨水的持续冲刷下，缓慢地、不情愿地退缩着。

塔外，依旧是光怪陆离、充满死亡低语的污染荒原。但塔内，这一方被倒立雨声和冰雕守护着的空间，却弥漫着一种劫后余生的、带着无尽悲凉的…宁静。

安全。是的，这里暂时是安全的。

老雷靠着冰冷的塔壁缓缓坐下，那条伤腿的剧痛似乎也减轻了些许。他闭上眼，第一次不再抗拒涌入脑海的、关于妻儿的记忆碎片。这一次，他们的面容似乎清晰了一些，呓语也淡去了，只剩下模糊而温暖的轮廓。泪水混合着塔内湿润的空气，从他布满污垢的脸上滑落。

他听着那永不停歇的、倒流的雨声，像是在倾听一座由牺牲铸就的钟，在绝望的荒原上，敲响了第一声微弱却无比清晰的…希望的回音。
