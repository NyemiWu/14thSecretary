# 《铁砧》

戍卫军团第九十四军独立炮兵营的阵地，代号“铁砧”，此刻正承受着意识污染最沉重的锤击。炮火曾一度撕裂那粘稠的、蠕动的前锋，但更多的、更加光怪陆离的形态从各方涌来。炮弹能撕碎有形之物，却难以彻底驱散那无孔不入的、侵蚀存在本身的意识污染。

更恐怖的事情发生了。

一门来不及撤下火线的重型自行火炮，其装甲表面开始浮现出类似血肉的纹路，炮管如同痛苦的触手般扭曲、挥舞，最终调转方向，将致命的弹雨倾泻向曾经的友军阵地。它被“活化”了。

紧接着是运输车、通讯车……任何带有复杂结构或文明痕迹的装备，都在被那被称为“喑霾”的污染接触后，逐渐“活”过来，变成扭曲、疯狂、充满恶意的怪物，反过来攻击它们曾经的操纵者。

命令冰冷而绝望，通过所有尚能接通的频道嘶吼：“死守阵地！直至所有技术装备、尤其是重炮及各类辎重被物理拆毁或引爆！重复，绝不能留下任何还能用的东西！”

铁砧，必须在自己被彻底摧毁前，先亲手砸碎自己。

观通连的观测点，设在阵地侧翼的一个半地下掩体内。何叙生透过观测镜，看到的不仅是潮水般涌来的喑霾，还有阵地上那地狱般的景象：士兵们一边对着涌来的“色彩”开火，一边含着泪将炸药塞进昔日战友般呵护的炮管、塞进载具的引擎盖。爆炸的火光不是胜利的礼花，而是为自己举办的、提前的、零碎的葬礼。

连长喉咙沙哑，声音却异常平静，透过掩体内嘈杂的干扰传来：

“叙生，你都记下来了？”

“记下来了，连长。”何叙生的声音没有任何起伏，他数据板上存储的，是整个阵地从有序防御到有序自毁的全过程，是无数战友在化为怪物前，亲手毁灭自己“第二生命”的影像和数据。这是一份浸透了鲜血与残骸的战地报告。

“行。”连长点点头，布满血丝的眼睛扫过掩体内仅存的几名观测兵，“指挥链路已断，我们成了孤岛。但这份记录，必须送出去。告诉后面的人，我们是怎么死干净的！”

爆炸激起的碎屑飞溅过来，击在连长的钢盔上，发出刺耳的响声。已经来不及退到更安全的位置了，炮兵们正在不顾一切地爆破着辎重设备，爆炸的冲击波不断撼动着掩体。

“我们得有个人活着回去，现在就走！”

所有人都明白这意味着什么。留下，与阵地同殉，是军人最直接的归宿。但活着把消息带出去，是比死更艰难的任务。

“我去！”

“让我去！我跑得快！”

几个年轻的观测兵争抢着，仿佛那不是生路，而是最危险的火线。

连长却看向了何叙生，那个平时最沉默、记录最详尽的前天文系学生。

“何叙生。”连长的声音不容置疑，“你的体能保存最好，你对路径记忆最清晰，你的…记录最完整。你去吧。”

何叙生猛地抬头，嘴唇翕动，想说什么。他想说我可以留下，让其他人走。他想说我和大家一起死在这里更轻松。

“这是命令！”连长打断他，眼神锐利如刀，却又带着一丝深不见底的疲惫，“你不是去逃命，你是去当信使。把我们所有人的‘看见’，把我们的‘眼睛’带出去！你得活着，哪怕像条狗一样爬，也他妈的得爬到有人的地方！明白吗？！”

掩体内一片死寂。其他观测兵看着他，眼神复杂，有羡慕，有解脱，但更多的，是一种沉重的托付。他们将自己无法亲眼看到的“后方”，将自己存在过的最后证明，押在了他的肩上。

何叙生感觉肩上瞬间压上了整个阵地的重量，压得他几乎无法呼吸。他张了张嘴，最终，从喉咙里挤出一个破碎的音节：“…是。”

没有告别。连长将自己的配枪和仅剩的两个弹夹塞给他，又粗暴地扯下他几乎已经失效的个人标识牌，扔进角落：“从现在起，你‘死’了。活着的，只是这份记录的信使。”

何叙生被战友们推搡着，从掩体后方一个隐蔽的逃生通道离开。在钻入黑暗前，他最后回头看了一眼。

他看到连长和其他几名战友，正将最后的高爆炸药堆放在通讯设备和观测仪器旁。他们神色平静，甚至有人对他挥了挥手，嘴角扯出一个难看的、鼓励的笑容。

然后，沉重的防护门在他眼前缓缓关闭，隔绝了那地狱般的景象和即将到来的、最后的殉爆。

他开始了逃亡。

每一步，都仿佛踩在战友们的尸骸上。

他听到身后“铁砧”阵地方向，传来一连串比之前任何炮击都更沉闷、更决绝的爆炸声。那是最后的自毁。他知道，连长他们，连同那些可能被活化的装备，一起化为了灰烬。

他没有回头，也不能回头。他的任务才刚刚开始。

逃亡路上，喑霾的低语如影随形。他携带的数据板仿佛一块烙铁，烫着他的胸口。里面不仅有理性的数据，还有他记录的、战友们临死前的面孔——那带着解脱，又带着无尽遗憾的眼神。他们推他出来时，那混合着期望与诀别的目光。

他成了“逃兵”。

他想，在军事记录上，他或许会被标注为“失踪”，甚至可能因为“擅自脱离阵地”而背上污名。但只有他自己知道，他背负着什么。他背负着整个观通连，乃至整个独立炮兵营最后的、无声的呐喊。

他躲过畸变的怪物，穿过现实脆弱的区域，那里的大地像融化的蜡一样流动。他不敢睡，怕梦里全是战友们质问的眼神：“为什么是你活着？”“我们的牺牲，值得吗？”

他的防护服早已破烂不堪，腿部不知何时被划开巨大的口子，寒冷和失血让他的意识逐渐模糊。但他死死抱着数据板，靠着铭刻在脑海中的路线和那点可怜的运气，竟然真的看到了——远方，二十九号穹顶城那巨大、尚未完全合拢的穹顶轮廓，在污染弥漫的天地间，如同海市蜃楼般摇曳，却散发着令人窒息的诱惑。

近在咫尺！

他用尽最后力气向前爬行，身后拖出一道长长的血痕。探照灯的光柱似乎扫过了他，他奋力抬起手臂，想举起那染血的数据板……

\*\*……然后，他跌进了黑暗。\*\*

并非昏迷，而是被更深的、来自意识层面的剧痛强行唤醒。

何叙生猛地睁开眼，发现自己趴在冰冷的、泛着油彩光泽的泥泞中。他想站起来，却感觉不到双腿的存在。他艰难地抬起头，向下看去——

膝盖以下，空荡荡的。

不是被炸断，也不是被砍断。那里的血肉、骨骼、乃至防护服的碎片，都如同被无形的橡皮擦抹去，只留下光滑得令人心悸的断口，仿佛他生来便是如此。断口处没有流血，只有一丝丝如同活物的、暗沉的色彩正在缓慢地、尝试性地向上蔓延，带来一种比疼痛更可怕的、存在被否定的虚无感。

他愣了片刻，突然低低地笑了起来，喉咙里发出破风箱般的嗬嗬声，却挤不出一个清晰的音节。他的肺叶早已在逃亡和污染的双重折磨下千疮百孔，每一次呼吸都带着血沫和绝望。

他抬起头，望向那片近在咫尺、却又遥不可及的穹顶光芒。那光芒在他开始模糊的视野里扭曲、变形，与周围蠕动的喑霾色彩交融，再也分不清彼此。

原来，他从未真正逃离“铁砧”。

他只是将阵地的坟墓，从身后，搬到了自己的脚下。

他用尽最后一丝气力，将怀中那枚被体温和鲜血浸透的数据板，更紧地、更深地按入自己胸膛，仿佛想将它塞回心脏，与自己那即将停止跳动的、承载了太多记忆与嘱托的心室融为一体。

然后，他死了。

瞳孔里最后映出的，不是家园，不是希望，而是那片吞噬了一切、连绝望本身都一并消化了的、永恒变幻的喑霾色彩。

戍卫军团第九十四军独立炮兵营，观通连列兵何叙生，于二十九号穹顶城合围前夜，确认阵亡。他携带的数据记录，最终未能送达。
