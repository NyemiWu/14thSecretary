# 风铃花

韩文总是听到很多说话声。

准确地说，他听到的是两个声音。每个人开口时，声音之外总叠着另一层——心声。那声音不大，却挥之不去，好像有另一个影子被钉在每个人的舌根底下，他说话时它便同步颤动，把心底真实的东西抖落出来。

“没事的，会好起来的。”——这是安慰人的话。底下那层却说：好不起来了，你我都知道。

“我从来没有嫌弃过你。”——底下那层说：但你能不能离我远点。

“你是个好孩子。”——底下那层说：可惜了。

韩文七岁那年被确诊为意识污染适应性变异。医生说这是极为罕见的症状——意识污染没能摧毁他的心智，反而让他的识子漩涡产生了某种“超开放”的结构，能同时接收多个层面的意识信号。换句话说，他成了一个行走的读心器，只是这能力从不受他控制。

他记得母亲最后一次抱他时说的话：“妈妈爱你。”底下那层是：我撑不住了。

那天晚上她离开了。父亲坚持了几年，最终也走了。走之前留下一句“我会回来看你”，底下那层是：对不起。

从此韩文不再需要别人开口。他学会了聆听那底下的声音，因为那才是真的。而真的东西，总是更疼。

三年了。他被安置在十四号穹顶城边缘的污染隔离监护所，这里收容着各种被意识污染侵蚀、却又因种种原因无法被归入“危险级别”的边缘人。监护所的条件谈不上好，但韩文无所谓。他早已习惯了。

他每天的生活很简单，早上领药，早餐，上午的自由活动，午餐，下午的自由活动，五点晚餐，例行检查，然后熄灯。日复一日，像某种精密但毫无意义的钟表。他习惯了在活动室里翻来覆去地看那几本翻烂了的老书，习惯了躺在床上盯着天花板上的水渍发呆，习惯了走廊里那盏永远在闪的日光灯发出滋滋的声响。

他甚至习惯了这里的沉默。因为即使在监护所里，他也听得到那两个声音。护工说“今天感觉怎么样”的时候，底下那层是：又一个等死的。病友说“你今天气色不错”的时候，底下那层是：反正大家都出不去咯。

所以当那个姑娘被推进隔壁床的那天，韩文并没有在意。监护所每隔一段时间就会来新人，也会走旧人。走的大多是抬出去的。他习惯了。

可他那天晚上没睡着。因为他只听到一个声音。

那个姑娘很安静。她躺在床上看书，偶尔翻页，偶尔抬头看着窗外。她什么都没有说。但韩文的耳朵里——他那永远充斥着两层声音的耳朵里——只有一个声音。一个干净的、纯粹的、没有阴影覆盖的声音。

他感到恐惧。他盯着天花板，手指攥紧了被角。他想听清楚那到底是什么——是说话声还是心声？他听不出来。因为那声音就是声音本身。没有两层，没有叠影，没有那些令人恶心的、粘稠的、从意识底层渗上来的真相。

他第一次无法看透一个人。

第二天早上，那姑娘跟他打招呼了。她微笑着挥手，然后指了指自己，又指了指他，做了个吃饭的手势。韩文愣了一下。她在邀请他一起去食堂。他点点头。他不知道自己为什么会点头。

她叫小铃。这是她写在纸上的名字。她说她不喜欢说话，嗓子不太好。韩文问为什么，她只是笑了笑，没有回答。韩文没有追问。因为他听到的那个声音没有变——依然只有一个。她笑的时候，只有一个声音。她写字的时候，只有一个声音。她看着他时，只有一个声音。

那束光就这样刺进了他阴霾的天空。

小铃和他见过的所有人都不一样。她吃饭时会把自己那份菜里的肉挑出来夹给他，然后用筷子敲敲碗沿，“多吃点”。她会在活动室里找到他，然后坐在他对面，安安静静地看书，偶尔抬头冲他笑一下。她会在晚饭后拉着他去院子里散步，指着灰蒙蒙的天说：“你看，今天的云不错诶。”

韩文听到的声音只有一个。只有一个。

他开始害怕。他害怕的原因很多。他害怕这只是一个更长、更深的幻觉。他害怕某天醒来，会发现小铃的声音也变成两层，底下那层写着：可怜的人，我只是同情你。 他更害怕的是——他已经习惯了她的陪伴，习惯了她的笑容，习惯了她的光彩，习惯了那束光。

这样的他，配吗？

他只是一个被父母抛弃的怪物。一个能听到所有人心底的丑陋、却无力改变的废物。一个被困在污染隔离病房里等着生命慢慢耗尽的编号。

他不知道自己有什么值得她这样对待。

那天下午，小铃约他在院子里见面。

她穿着一条浅蓝色的连衣裙，韩文不知道她从哪里找来的。她的头发挽起来了，别着一枚风铃花形状的发夹，银色的花瓣在灰白的日光下微微发亮。她手里捧着一束花——也是风铃，白的，粉的，小小的钟形花朵挤在一起，像一串串无声的铃铛。

小铃站在他面前，将花递过去。然后她好像开口了。她说得很慢，很轻，声音有些喑哑。但她说得很清楚：

“韩文，我喜欢你。”

只有一个声音。

只有一个。

韩文站在那里，捧着花，看着她。他应该开心的。他应该抱住她。他应该说我也喜欢你。可他脑海里只有一个念头：这样的我，配吗？

他什么也没说。他看着小铃的眼睛，那双眼睛里有一种他看不懂的东西——期待？不安？还是某种早已知道答案的了然？

他把花递了回去。他转身走了。

他听到身后没有声音。或许小铃什么都没有说。因为她的心声，也和她的说话声一样，是无声的。

韩文在那之后躲着小铃。在食堂里避开她的目光，在活动室里坐在最远的角落。小铃没有来追他。但她依然会在走廊里对他微笑，依然会在他桌上放一颗糖或者一张写着“今天也要好好吃饭”的纸条。韩文把那些纸条都收起来了。他不知道自己在等什么。也许只是在等自己足够勇敢的那天。

可那天没有来。

意识污染潮汐在一个深夜毫无征兆地爆发了。

监护所位于十四号城的边缘地带，防护等级本身就低。当那道足以扭曲现实结构的污染潮从穹顶外渗透进来时，隔离监护所是最先被侵蚀的建筑之一。

韩文是在震动和尖叫声中醒来的。走廊里充满了灰白色的、五颜六色的光。墙壁和天花板扭曲在一起。有人在哭喊，有人在乱跑。他本能地爬起来，往出口冲。他跑过走廊的时候，看见了那一个他幻想过的房门。

门开着。

他来不及想。他继续跑。

救援队在污染潮汐退去后的第二天抵达。监护所已经被侵蚀得只剩下框架，像一具被吃空了血肉的，被随意丢弃的骸骨。幸存者不多，韩文是其中之一。他蜷缩在废墟边缘，满身尘土，被救援人员扶上担架。

“这是最后一批了。”一个救援人员说。

“那边还有几个。”另一个说。

韩文听到他们谈论废墟里发现的遗体。

“有一个女孩，在隔离病房那条走廊上，”救援人员说，“别着一个风铃花发夹，跑的方向是往里的。应该是想回去找人。”

韩文的心跳停了。

“你说什么？”他开口，声音嘶哑。

“那个女孩，”救援人员看了他一眼，“我们查了监护所的记录。她是个哑巴。声带在十多年前就因污染侵蚀被切除了。她从来就发不出声音。”

韩文躺在担架上，看着灰白色的天空。

那个女孩一直只听得到一个声音，不是因为她的意识结构特殊。

是因为她本来就只有一种声音。

那就是她的心本身。她不需要开口。她用整个存在对他说话。

而他，因为自卑，因为恐惧，因为那些根深蒂固的、被驯化的怀疑——他错过了。

救援人员又说：“那个女孩，尸体很安详。像是刚刚睡着一样。”

韩文闭上了眼睛。

监护所的废墟在他身后，灰雪开始落下来。在很远的地方，十四号城的意识穹顶幽幽地亮着，像一颗永远不会被摘下的、冰冷的星星。

韩文攥紧了口袋里那些皱巴巴的纸条。上面歪歪扭扭地写着：“今天也要好好吃饭。”

他后来再也没有听到过只有一个声音的人。
