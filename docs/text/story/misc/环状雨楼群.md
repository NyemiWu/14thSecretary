# 环状雨楼群

环状雨楼群：位于（地点未定）的雨楼群落，其分布呈环状，包围着一处严重污染源。与常规雨楼不同，进入该雨楼群落的人员并不会感受到明显的“安全感”或其他正面情绪，反而会感到剧烈的恐惧和不安感，感受强度随着其进入该雨楼群的距离递增，最终使得人员无法接近雨楼群包围圈的中心。

其他与常规雨楼不同之处还包括：该雨楼群内倒流雨的雨滴声均在可辨认范围内以摩尔斯电码传递“立即远离”的信息；雨量明显小于其他雨楼等。

据史料证实，该雨楼群坐落在一支戍卫军团通信营战位旧址，该通信营在（懒得编）战役中整编制失联，后续情况未知。

据无人机图传显示，该雨楼群包围中心的严重污染区已不具有物理可用信息量，其污染强度、污染性质无法测定。

中期调查发现，环状雨楼群的雨量正在逐渐减少，似乎与其中心的重污染源强相关。无法确认雨楼群降雨完全消失降导致怎样的后果，目前正围绕该雨楼群边缘建设重型防御工事及综合监控站，究竟能否应对其重污染源爆发仍是未知数。

近况：志高肃正已介入对环状雨楼群的监控及保护性研究，目前已部署四组“小阿卡纳”塔罗牌战监编组，预部署大阿卡纳牌三台：“隐者”、“命运之轮”、“审判”。一线设施已由志高肃正接手继续建设和运行，半永久防御工事建设正在进行中。

近况修正：基于反识子漩涡解链技术建设的环状雨楼群穿越机已投入正式使用，该设备简称“AVWG”（Anti-consciousnessum Vortex Wormhole Generator），可以支持基于领航员体系基础下的最小编组进入中央重污染区调查研究。目前，针对中央重污染区的调查研究表明，该污染源物理覆盖物理直径约三百米的圆形区域，与环状雨楼群有明显且锐利的分界面。污染源内部时空不对等分摊，呈现为空间扩张，时间压缩，且越靠近中心，时空畸变越严重。污染区内意识怪物数量庞大，普遍具有攻击性，且越靠近中心，污染强度和意识怪物攻击性均呈现明显上涨趋势。

由于严重时空畸变，目前无法确认达到该污染源中心，或横穿该污染源、测量其平均污染值和最大污染值。对污染源中心的靠近无异于直接增加深潜深度，对仿生人及领航员均会造成严重威胁。

识子黑洞假说：基于现有识量子物理模型，可认为该污染源为一个识子黑洞，直接连接意识空间与物理空间，意识空间“直接存在”于该污染源“内部”，故呈现出时空畸变特性。对该污染源的探索实质上是直接探索意识空间与物理空间的“现实边界”。
