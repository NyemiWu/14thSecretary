# 人物

凯瑟琳，警局副局长、副总警监，出了名的严格，说一不二，强势，英雄主义。动机：驱除不公，践行正义，希望建立一个公正的社会秩序来保护弱者，保护妹妹

芙蕾雅，凯瑟琳的亲妹妹，律师，昵称阿雅。动机：希望姐姐和男友能远离危险，渴望家人的平安，希望为家人分忧担责，希望社会能多几分同情。

王sir，芙蕾雅的男友，新人警员，总是受到凯瑟琳的严苛对待。虽是菜鸟，但富有责任心和毅力。动机：希望带芙蕾雅过上更幸福的生活，希望获得尊严，得到上司的认可。

警局事件线

地下竞技场案——开源帮案——峰会事件——游行事件

**地下竞技场案**

出身偏远的小王经过严苛的考核后加入警局。芙蕾雅约了饭局，要介绍交往几个月的男友给姐姐认识认识。到饭桌上，凯瑟琳脸色顿时阴沉下来，小王强装镇定也止不住手抖，芙蕾雅这才知道，男友小王为了稳定的收入和向芙蕾雅证明自己而考入了警局，但没想到芙蕾雅的姐姐就是警局的副局长、自己最严苛的上司。

“好啊，你小子，跟我家小雅好上了。”凯瑟琳语气核善。

警局虽然为小王提供了身份上的尊严，但如今的警局收入却难以满足小王撑起未来家庭的需要。为了给女友芙蕾雅更好的未来，小王趁着身体还算健强，为了破案，铤而走险以“报名参赛者”的身份去卧底地下竞技场。然而不久，凯瑟琳发现了他手上的淤青和疤痕越来越多，再三逼问下，小王将地下竞技场一事托出。地下竞技场是富人的俱乐部，穷人的斗兽场，而在这里打赢几场比赛赚的钱比警局一个月工资都高，而且是自愿参赛，这使得小王也一度动摇过。但凯瑟琳知道，任何非法活动，所谓“自愿”往往是强者剥削弱者的陷阱，悬崖勒马为时不晚。

在狠狠教训了一顿小王后，凯瑟琳亲自潜入到地下竞技场进行调查。

结果：凯瑟琳的行为在警局内获得一部分人的敬畏，以及另一部分人的鄙夷，同时面对巨大的外部压力。大部分被“解救”的民众没有感谢凯瑟琳。

**开源帮案**

一个自称开源帮的黑客组织正在肆无忌惮地发布各大企业的破解资料。其中不乏安全等级较高的设计图纸和企划书等。他们宣称要以开源精神将大公司的资源分发到平民手里，引发了浩浩荡荡的开源运动。再这样下去，恐怕仿生人的机密也会被这群法外徒挖掘出来。警局，珂博奥，超氧公司等各方势力纷纷介入到了此次案件。

意识生物：一种新闻模因

**峰会事件**

警局的日渐势微众人都看在眼里。穹顶政联中，有人（商会联盟）将在即将到来的峰会上提议除名警局在政联的席位，警局作为同属司法系统的一份子合并到衡南法庭之席去。这样一来，警局将几乎失去仅剩的政治话语权，沦为权势们的工具。凯瑟琳认为不能坐以待毙，需要在即将到来的峰会上出动更多安保力量保护峰会，证明警局的行动力。

然而，超氧早就计划着对警局进行控制和换血，并将要上演一出自导自演的好戏。

峰会上，当商会代表的关于警局席位变动的提案提出后，超氧代表竟然首先提出了反对，讲述了警局为保护民生与企业做出的牺牲与努力，在开源帮事件中保护了超氧集团等民营企业的重要财产（其中还包括涉及到仿生人的机密），超氧代表民营企业与百姓对警局表示了高度赞赏。由于涉及仿生人的公共认知保护功劳，因此城市认知监察（至高肃正）也没有理由赞成除名警局的政治权力，也投出了反对票。衡南法庭作为变动牵涉对象之一，不便表态，弃权。星枢学会已经察觉到个中蹊跷，弃权。新戍卫军团（包含地下反抗军势力锈火）知道，警局作为城内防卫势力，实质上是与自身地位利益冲突的，削减其权力对自身不无好处，再加上军团与超氧立场处于对立，于是表示警局与法庭合并有利于司法系统执行的高效统一，投出赞成票。来自白氏制药的医药联盟代表与商会已有串通，为了保护自己的地下药物走私链，拿出警局的内部腐败丑闻，对警局性质提出质疑，投出赞成票。

而就在峰会讨论到焦灼之时，场外传来激烈的躁动声......

峰会暴动，警局虽出动几乎全部警力，但碍于科技和人力依然不足，还是陷入被动，而此时，神秘的超氧超级士兵小队出现，靠着强大的装备和素质迅速完成了镇暴，在警局眼前保护了峰会，又在硝烟中悄然退至幕后。

事后，警局保留了穹顶政联的一席之地。

**游行事件**

超氧向警局伸出了橄榄枝。警局接受来自超氧赞助的先进技术、装备和人力，条件是以此镇压北岸区的反超氧游行。警局大多数人投出赞成，但凯瑟琳知道，这样一来，警局无疑是成为了超氧公司的棋子。面对阳谋，眼下她没得选。

游行镇压的最后，六号代表北岸帮派与凯瑟琳和谈，达成共识，解散了双方力量。事后，凯瑟琳以镇暴不力为由引咎辞职，她无法面对被大公司控制的警局的未来。

而游行事件，实质上也只是调虎离山的幌子。

六号，各大帮派，警局，这些势力的对峙给超氧创造了一个绝佳的时间窗口，一个除掉昆山的窗口。

**后日**

凯瑟琳已离职，辗转后加入主角团。此时警局已经成为超氧的傀儡。在政联中，超氧的权力也日益扩张。商会和医药也都已被超氧的利益拴住。可以说，超氧已经形成了十四号城政治的一家独大格局。而超氧发动的昆山杀手事件，彻底让至高肃正走向对立面。至高肃正对超氧宣战。
