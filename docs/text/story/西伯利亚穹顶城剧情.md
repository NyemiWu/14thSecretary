# 二十八号城（西伯利亚穹顶城）引入短篇

《幻觉》

雪是灰的。

这里的雪永远是灰的，像燃尽的纸屑从铅灰的天空飘落。伊万站在七号瞭望塔的顶层，看着雪花一片片盖住远处锯齿状的城墙轮廓。那座墙——人们管它叫“混凝玛利亚”——据说有大几十米厚，地基深埋进冻土两百米，可以抵御任何已知的物理冲击。墙上的探照灯每隔半分钟扫过边境线，惨白的光柱在灰雪中切开一道道口子，随即被黑暗吞没。

他掏出怀表。五点四十七分。还有十三分钟换岗。

瞭望塔内部是暖的——暖气管道从城市心脏的核聚变堆芯一路延伸到这里，金属外壁摸上去微微发烫。伊万把手掌贴在管壁上，感受那种人造的、机械的、近乎虚伪的温暖。外面零下四十度。而墙外，据说更冷。据说冷到空气本身都会碎裂，像玻璃一样扎进肺里。

但他从未去过墙外。城里没有人去过墙外。那些偶尔出现、爬过边境线的“东西”——那些被污染扭曲得面目全非的残骸——是唯一的证词。伊万见过一次。三年前，一具从墙外爬进来的躯体，四肢像融化的蜡一样扭曲，眼睛的位置只剩下两个深不见底的洞。它还活着。或者说，它还在动。医疗队用了快半个点儿才让它彻底安静下来。

那之后，伊万就明白了为什么城里的人从不谈论墙外的世界。

换岗的人来了。安德烈，比伊万大十二岁，脸上的皱纹像西伯利亚冻土上的裂纹。他们交接时从不说话。语言在这里是多余的——所有的话都在换岗日志上，用制式钢笔写在泛黄的纸上，字迹潦草而绝望。

伊万走下盘旋的铁梯，靴跟敲击金属的声响在空旷的塔内回荡。一层大厅的墙上挂着一排褪色的照片——城市初建时的模样：崭新的钢铁墙壁，锃亮的炮台，天空中还没有灰雪，阳光照在士兵们年轻的脸上。他们笑着，像是真的相信这座城会永远坚不可摧。

照片下方有一行褪色的标语，油漆剥落得几乎看不清：“为了文明的火种。”

伊万每次看到这行字都想笑。火种。这座城自己都快熄灭了，还谈什么火种。

他推开塔门走进街道。主干道曾经双向八车道，现在只有一条车道勉强通行，其余路面布满蛛网般的裂纹，裂纹里渗出黑色的油状物——那是地下管道泄漏的核电冷却液，有毒，但没人管了。路灯一半是坏的，亮着的那些也在有气无力地闪烁，发出令人烦躁的滋滋声。

他路过中央食堂，门半开着，里面传出水煮卷心菜的味道。队排得很长，人们裹着厚重的灰色大衣，沉默地挪动。食堂墙上挂着巨幅壁画——还是那个主题：堡垒、光明、希望。画中的人们昂首挺胸，目光如炬，齐刷刷望向远方的地平线。

伊万加快脚步。

他住在城西的公寓楼高层。电梯早就停了，楼梯间的感应灯坏了一大半，他摸着黑往上爬，脚步在水泥墙壁间回响。楼道里很冷，家家户户的门紧闭着，只有一扇门开了一条缝，传出收音机的声音。

“……今日伤亡通报：北墙三号段，两人。南墙七号段，一人。东墙……”

数字在减少。伊万记得小时候，每天的伤亡通报还有十几人。现在只剩个位数了。不是因为他们变强了，而是因为人少了。城里的人口已经从鼎盛时期的两百万降到了不足五十万。剩下的人里，年轻人大都想办法走了——走？去哪里？没有别的地方可去。但他们还是走了，走进灰雪深处，再也没有消息。

也许他们找到了别的堡垒。也许他们只是换了个地方冻死。

伊万打开自家的门。房间里暖气管道也凉了——城西的供热优先级最低，只有在核聚变堆满负荷运转时才轮得到这边。但堆芯已经老了，三天两头出故障。今天显然不是满负荷的日子。

他在黑暗中摸到书桌，拉开抽屉，取出那瓶藏了很久的伏特加。酒液已经浑浊，但他不在乎。他拧开瓶盖，灌了一大口，烈酒烧过喉咙的感觉像某种迟来的安慰。

他坐到窗边。玻璃上结着厚厚的霜花，他用指甲刮开一小片区域，看向外面。

从公寓楼高层俯瞰，城市尽收眼底。那道著名的城墙在灰雪中只剩一道模糊的轮廓，像一条濒死的巨蟒匍匐在大地上。墙上依然有探照灯在扫，但伊万知道那些灯已经换了柴油发电机来供电——核聚变堆连居民的暖气都供不起了，哪还有多余的电力给那些灯。

可灯还是要亮的。因为灯亮着，人们才能假装这座城还在运转。假装墙还在守护着什么。假装明天和昨天没有什么不同。

伊万想起小时候，父亲带他去看换防仪式。那是这座城市最后的辉煌时刻——士兵们穿着笔挺的军装，步枪上的刺刀在阳光下闪光，军乐队吹奏着雄壮的行进曲，人群在街道两旁欢呼。父亲把他举到肩上，说：“看，伊万，这就是我们的堡垒。永远坚不可摧。”

永远。伊万又喝了一口酒。永远是个可笑的时间单位。父亲已经死了，死在墙外的巡逻中——他们甚至没能找回他的尸体。军乐队解散了，步枪上的刺刀生了锈，欢呼的人群如今沉默地排队领水煮卷心菜。

他看向墙外。灰雪茫茫，什么也看不见。但他也不知道墙外有什么——或者说，他想，墙外什么都没有。没有敌人，没有污染，没有足以灭绝文明的力量。那些爬过边境线的“东西”是什么？是幻觉。是这座城自己制造的幻觉。没有人来过。没有人出去过。墙外和墙内一样荒芜。

或许只是人们需要一个敌人。没有敌人，这座城的军事化管理就没有理由。没有敌人，人们凭什么忍受这一切？没有敌人，这座城就只是一座逐渐冻僵的废墟，没有任何意义。

所以他们等待。等待那场永远不会到来的决战。等待与天灾鱼死网破的一天。他们谈论着那一天，像是谈论一个必然到来的救赎——要么胜利，要么毁灭，总之不会是现在这种半死不活的状态。

伊万突然觉得，他们等的只是一个幻觉。就像这座城本身——一个庞大的、集体的、无法醒来的幻觉。

酒瓶空了。他把瓶子扔到墙角，听着玻璃碎裂的声音。窗外，探照灯又一次扫过灰雪。光柱短暂地照亮了城墙，伊万看到墙砖上那些修补的痕迹——用胶带、用木板、用废铁焊成的补丁，层层叠叠，像是给一具腐烂的尸体穿上拙劣的寿衣。

这座城市已经死了。只是还没有人敢说出这句话。

他闭上眼。暖气管道发出一声呻吟，像是某种巨兽垂死的叹息。楼下的收音机还在播报伤亡通报，声音断断续续，像从很远很远的地方传来。

伊万·伊万诺维奇·彼得罗夫，四十七岁，瞭望塔值守员，在灰雪覆盖的深夜里，独自坐在高层公寓的窗边，听着一座死去的城市继续假装活着。

明天早上五点半，他会再次走上七号瞭望塔的顶层。他会看着灰雪继续落下，看着探照灯继续扫过空无一物的边境线，看着墙上那些补丁在严寒中继续开裂。他会和安德烈交接班，一个字也不说。

他会继续等待那场永远不会到来的决战。

就像所有人一样。

探照灯又扫过一圈。这一次，光柱的边缘似乎照到了什么——远处灰雪中，一个模糊的轮廓，人形的，正在缓慢地、艰难地向城墙移动。

伊万没有睁眼。

他想，那只是一个幻觉。
