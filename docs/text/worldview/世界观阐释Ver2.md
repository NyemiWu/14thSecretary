# 十四号城世界观

在人类历史中那些无法解释的超自然现象，一度引发人们对“灵魂”“精神”“意志”的畅想和描写，即便在科学主义与唯物主义普及后，鬼神志怪的民间传说也不曾消弭，以至于人们投入大量精力试图揭开它们的面纱，希望其背后不过是常识范围内的可知现象——

然而这便是我们捅破禁忌的根源。

**意识污染**：意识界与物质界的平衡打破导致的灾害，其规模呈滚雪球式地扩张。作用形式包括但不限于：各类精神性瘟疫（涵盖几乎所有已知的心理、精神疾病），生物基因突变，辐射，EMP，特定物质解体重构，出现超自然意志体，超自然意志现象（如意识结构紊乱，蜂巢意识现象，意识夺舍、寄生、剥离现象，伴随有物理性变化）。由于科技发展不成熟，该类灾害的防治手段相当局限，穹顶系统与仿生人是其中最有效的之二。

意识污染的一个实质，便是意识空间的规则律反过来影响到了现实世界的表征。比如昆山，屡屡在作战中幸存归来，于是越来越多的人开始相信他是所向披靡的龙将，带领将士们一次次行军、一次次摧枯拉朽。所以昆山受到的意识污染表现为，他的外貌变成了半龙半人、与盔甲融合的模样——意识污染将人们的期望变成了诅咒。以及圣莱山德医院的院长，被污染变成羊角的恶魔，也是来源于规则律的影响。温迪戈的诞生也是如此，食人恶魔温迪戈渐渐流行在阿尔冈昆语族传说中，而意识污染则会让温迪戈降临，随着传说范围扩大，接受信仰的温迪戈的力量也会不断增强，最终扩大成不可收拾的文化症候群，以及一头蜂巢级以上的大型意识生物。

**穹顶城**：打造超级智能意识体作为城市核心，再连接巨大的“意识波隔断穹顶”作为祂的器官，覆盖整座城市以隔绝意识污染。除了基本的城市系统，配套有一系列特种设施，如氧塔，子午夜分塔，穹顶柱等。主线故事发生于第十四号穹顶城。而十四号城穹顶的智能意识体，被称为“一号”，其本体是一颗巨大的仿生脑和遍布城市的“神经元”。

**领航员**：仿生人作战刚需一名领航员，通常是人类，少数情况下也可以是仿生人。仿生人在深潜到意识空间后是不具备感知的，需要领航员用自己的感知与想象为仿生人指明方向、构建空间。不同领航员具备的才能截然不同，有人可以通过强大的想象力建构意识空间的规则为己所用，有人可以将强大的意志力打造成无坚不摧的进攻手段，也有人可以用缜密的思维谋划为仿生人作战提供完备的战术支持，还有人会以强烈的共情能力将仿生人的共鸣同步率提高到极致。领航员+仿生人的搭档是穹顶城时代所使用的最主要的对意识作战方案。

**意识空间**：在**物质界**和**意识界**之间，人为模拟出来的中介空间，用以形成连接物质与意识的通道域并在其中作战，以达成一些意识技术手段。仿生人在领航员的领航下可以将自我意识深潜到意识空间。意识空间不完全遵守现实物理法则，而是遵守符号规则“**规则律**”，需要以领航员的感知为眼，以领航员的想象力为法则，仿生人才能在深潜中顺利地打败意识生物或是别的仿生人。意识空间的第一层边境为“灵薄域”，随着深潜的不断进行，意识空间的维度会愈发倾向于意识界，变得更加超现实、抽象、不稳定、不可测，直到仿生人意识不可逆地侵蚀，彻底迷航在意识海中。

意识海技术：仿生人对意识污染作战的基础。该技术通过“深潜”，将仿生人直接投影至“意识海”（准确来说是作为中介的意识空间），在识子层面直接对意识污染源发起攻击与清除，同时也可以直接在该层面抹杀人类意识和其他造物。该技术决定了仿生人在该世界观中不可或缺的地位。

**规则律**——意识空间作战的底层逻辑

意识空间的规则来源于人的普遍认知。如，石头剪刀布，金木水火土，杀鱼刀能杀死鱼，中元节会有百鬼夜行，越无知越自信——任何事物在意识空间里都是符号化的，于是通识下的一切符号规则便可以在意识空间里成立、奏效、以及得到利用。这种认知域规律被称为“**规则律**”。其中，心理效应的规则占比尤为显著。

符号力学与认同能量经济学

在规则律中，认同的程度即是符号的力度。接受大量认同的符号及其规则，将成为普世认知规则，在意识空间内生效。如果某片区数万人都认同一种民俗，那么这种民俗文化的规则将会在意识空间中实现，也将会在意识污染到来时具象化于现实世界。越是大众认可，符号规则越是稳健。认同来源于以人类为主的智能意识生命，仿生人也在其列，而闪点以下的智械则不具备该权能。

数量原则：认同者的意识体量越大，赋予能量越大。以一个标准的、成年人类意识体为单位，这样的认同者越多，则赋予能量越大。

质量原则：认同程度越深，则赋予能量越大。

空间原则：如上述例子，一万个具有相同认识的人集中在一个片区，在该片区的意识空间内，其赋予符号的能量，将大于同等人分散在世界各地时的赋予能量。即越聚集紧密、越有效，越分散越稀释。（因为意识空间是结合了现实三维空间而建模的中介空间）

涉己原则：被认同的符号的所指本身如果有意识，比如一个人，那他自我的认知将对自身的符号产生更大的影响（相比于他人对其符号的认知）。通过这个原则可以建立最基本的个人模因防护（自我暗示）。

转喻原则：符号和符号、符号和规则之间的连接（能指链）难以改变，但是可以通过转喻来在一定范围内改写和借代符号。比如鱼型意识生物→鱼。这也是为什么领航员的意识空间作战需要丰富的想象力与联想能力。转喻后符号力度可能会发生变化，取决于转喻过程中的认知能量耗散。简单来说，手→hand这样的转喻几乎不会发生变化，但鱼→水生动物这样的转喻则涉及大量能量变化。否则，一切意识作战都可以变成【我→剪刀，敌人→布，无→石头】然后结束。

**智械**：具身智能的种族。与仿生人的意识科学方向所平行的，人工智能科学发展的结晶，本质是体型接近人形的机器，具备“冰点”以上“闪点”以下级别的智能，如果智械个体链接了意识海中的意识体，该意识体会连带一小片域的意识海被封装隔断，无法像人或仿生人意识那样在同一片意识海中交换信息和质料。智械的“语言”与人&仿生人不相通（这里是指基本精神结构的不相通，相关术语见拉康学派）。智械的智能如果到达闪点以上，则会突破限制，拥有完整独立的自我意识，并且意识可以在意识海中与其他生命意识交互（就像人类和仿生人）

智械意识：理论上，智械不可能存在自由意识，即不可能以智械的硅基躯体突破“闪点”达到自由意识。该现象在识子理论中的解释为，智械“意识”为一个完全封闭的、完全固定独立的识子结构，无法被拆分、细化、调整，可以理解为一个单独在意识世界“宏观可见的识子”，无法产生意识所必须的识子漩涡结构。一旦以某种形式强行突破“闪点”，将导致智械意识在意识世界中“破碎”，而因为该结构体不存在互相纠缠的识子漩涡，将直接如一盘散沙般烟消云散。“寻乡人”所找到的突破“闪点”的方法是，强行将大量人类的意识作为介质，影响智械识子结构的内部运动，从而诞生封闭的自由意识识子漩涡结构，但代价不言而喻。

**意识生物**催生于强大的执念，这种执念本质同样是“对于某种符号规则的坚定认知”，所以在意识污染的影响下，这种执念成就了现实——形式则是意识生物。而其中一些强大的意识生物，将会发育至“赐名级”，链接一个可以被认知的特定符号，并享有该符号所牵连的规则律。比如神话传说中的怪物名。或是某种物件。围绕这些赐名，有专门的职业负责研究它们，比如**测名师**，或是祓除名讳的肃正者、颂读者。总的来说，杀死一般的意识生物需要同时斩杀其物质躯体和意识体，但即使这样做，赐名级别的意识生物依然会以同样的名字重新降临在世界上任意一个地方，所以需要至高肃正这样的组织用逆模因手段专门祓除其名字，让赐名从人类文化里彻底抹去，才能避免赐名再临。

赐名规则：赐名所指范畴越广泛，则名字能量越低，比如“鸟”“兽”“木制物”“玻璃器皿”等，反过来，所指越独一，则名字能量越高，如神话名字、专有名词。字符长度本身对能量的影响可以忽略不计，因为多余的字符在认知里可以作为符号附属，如“奥丁-神王-独眼的知识之神-诗歌之神-法术与化身之神”中，“奥丁”一词即可承受全部意义，其余捆绑词缀不额外附加意义。与信息熵原理一致，即该名字消除的可能性越多，则信息量越大。通常看来，一个意识生物的生命轨迹，如果与某赐名命运高度吻合，则获得该赐名的可能性越大。而赐名的发生对象是否局限于意识生物，以及赐名机制如何转化、移植和利用，还有待科学定论。

**测名师**：测定意识生物赐名以及符号规则的的专业调查员。一种对人文社科素养要求很高的职业，要求职业者需要通读世界文化史，了解全球各地文化传说，他们就像警局里的画像师，需要通过只言片语和零碎影像锁定目标的身份，并使用专业的模因设备进行测定。很多时候，意识生物的赐名并不诞生于已知的传说，因此需要测名师进行田野调查来确认意识生物可能的赐名。

**（由于确定意识生物赐名的过程，是一个典型的局部“降熵”行为，根据信息通道学说，一个系统越是试图消除污染的不确定性，则越是会受到意识污染侵蚀，因此“测名”的过程有概率会受到意识污染反噬。）**

**超现实认知管理条例**

由于意识污染会以规则律影响现实表征，所以一切封建迷信、宗教信仰、坊间传说、神秘学、超验认识、集体唯心主义、超越现实的理念、以及一切不切实际（字面意思）的幻想，都必须受到范围管控。**城市认知监察委员会**就是对此类条例负责的主要机关。一旦管理失责，再遇上意识污染的袭击，极容易造成重大公共安全事故。但是，城市认知监察委员会并不妨碍一般市民的民俗信仰，也没有权力胁迫所有市民刻下唯物认识论的思想钢印，那样，压抑的公众思想反而容易执念化，催生意识生物的诞生。他们做的，只是监视认知域模因和意识污染的大幅波动，并在危机未至时加以干预。而如果危机已要酿成，他们则会用更不可示人的那副面貌出手。
