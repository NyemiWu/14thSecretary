# 基因占据了欲望，模因占据了享乐

认同是精神的食粮，获得认同就是获得心理能量。求同存异的本质是追求更稳定高效的心理能量获取环境，即心理生态。

心理能量和生理能量在某些情况下可以相互转化。如果不转化（或转化受抑制），则其中一方会率先枯竭。

某种原型的症结导致心理能量耗散（就像气球的漏洞）享乐输入的能量无法修补症结，反而将欲望缺口进一步撕裂。欲望与现实的差距带来超我的批判

能量的品质：原始本能-自我实现（马斯洛）

优越感，实质是对高品质的心理能量（即高级认同）以及他者欲望的需求，呈现一种向下排异

符号是信息对意识的编码，符号是意识理解信息的中介，由此，符号结构了精神主体。

模因是符号的一类所指，借助主体来繁衍自身。类似于基因，它们是主体的寄生者，假借主体的能量来行使自身的目的。模因往往成体系，基本构成是互联的符号族。

模因的奖励是认同（即心理能量），基因的奖励是欲望满足（即生理能量）

基因以主体为区分，模因以群体为区分，比如亚文化群、圈子。

由于主体1与主体2在意识形态上相似，模因在他们之间也会易于传播，因为认同是容易的，认同是模因的产品、也是主体意识的需求（欲望）。

能指是所指的符号，所指是能指的象征

消费：支出价值物，获得符号的所指（旅游，购物），（注意是所指不是所指对象，所指是概念，所指对象是实体）

生产：在输出符号时获得认同或欲望（他者的欲望）

心理能量学和心理信息学，即心理学和符号学

符号的所指扎根于意识的认知域，集体意识的认知域是符号或者说模因的生长空间，也就是文化域。那么意义在何处？

意识的始终：存在与虚无，对应生物学的生与死。意义是意识的生命。生物学的生死与意识的存在虚无构成聚合共识性和组合历时性。

情绪是心理能量流动形成的某一状态的现象？

注意力是什么？前意识的调控功能

睡眠的本质是？通过梦消解压抑情结（本质是不被认同的、异化的欲望），恢复心理能量，修复心理结构漏洞（创伤）。同时也包含了对生理能量-心理能量平衡调控的作用。
