# 意识工学技术

本文档收录意识科技在物理工程学领域的一系列应用，包含能源动力、机械、电子信息、通信、材料学、交通工具、武器、航空航天、生物工程、化工等实用技术，以及包含上述技术的工学设计产品。

**肉虫技术**

**肉虫α001**，最先发现的阿尔法虫，通过特定意识频谱激发后会导致意识体纽带的链式反应，引发剧烈爆炸，爆炸的意识波会导致意识污染和次生爆炸，三战时被极端军事用于与仿生肉脑一同制作肉虫炸弹。

**肉虫∑039**，西格玛虫的一种，激发状态下会与虹金共振，加热虹金，是较为常用的能源型肉虫源，∑039制备的肉虫电池通常对散热有较高要求，通常用于重型低功率工业设备的能源。培养成本较低

**肉虫∑011**，西格玛虫的一种，活跃于-16℃以上的有机溶液环境，能够通过代谢合成清洁燃料，但这种代谢行为需要与仿生人意识体共生才能发生，且受宿主意识状态、情绪、生理水平等因素影响，还可能会反过来干扰宿主意识。尽管依赖于意识共生，但在代谢速度可观的条件下，它们可以源源不断地提供能源，这一特性使得∑011依然是仿生人意识装备与武器的最理想能源之一——尤其是作为发动机能源。其上限至今也有待发掘。培养成本较高，并且容易随着宿主的死亡或意识崩溃而死亡，平时需要低温冷冻保存于抗冻培养液中。

案例：外壳【夜袭】所搭载的雨燕发动机组。装备者与肉虫群落连接时，肉虫会从沉眠中被激活，并在宿主意识控制、电路控制与溶液环境的共同作用下开始合成燃料。由于燃料中混有大量极细小的肉虫角质碎片，在经过不充分燃烧后喷出发动机，会悬留在空气中，并发出幽蓝色的荧光，形成一道炫目的“光轨”。

**肉虫α008**，阿尔法虫的一种，被称作“肉虫界的孢子”，在空气中有较强传播性

有一种人造纳米肉虫技术，旨在将人造肉虫植入到意识生物或者生物脑内形成寄生群落，以控制其意识活动。拉斐尔事件中有出现。

**武器&装备篇**

**SACA七千年式识子适应性装甲**

SACA（Seven-thousand-year Adaptive Consciousnessum Armor）

是配发于全部戍卫军团士兵的小型化识子适应性力场发生器，通过在小范围内生成反识子漩涡屏障以在一定程度上抵抗意识污染。早期型号体积较大，需要单兵个人使用背负式携行具结合单兵外骨骼系统使用和携带。后期型号逐渐缩小，从穿戴式一直精简为目前的佩戴式，并可按个人需求改造为更贴合使用者个性的款式。士兵往往亲切称呼其为“萨卡”，这个称呼在其后期型号出现并配发时亦未改变。在战场上，保持自己的“萨卡”处于完美状态成为重中之重。

仿生人使用的SACA型号相对人类而言更加精简，并可在仿生人机体设计中直接嵌入其机体，以省去诸多麻烦。新款的仿生人型号往往都采用SACA嵌入式设计，这也成为从外观上分辨新款仿生人和人类的特征之一。

现代SACA技术的核心是一种反牛顿流体材料，在意识激活下才能做功。加工时，会将流体浇筑于合金管道中，通过刻蚀虹金回路与触点来连接使用者的肌肤，所以SACA看起来才会像弯曲折叠的金属管。SACA力场以较大功率生效时，会因激波发出悬空的几何形光圈，被称为萨卡环。萨卡环的颜色和形状取决于较多因素，此处不作展开。

案例：由仿研所开发的仿生人技能，原理是通过SACA将仿生人意识能量汇聚，用以轰击前方空气使得空气高温膨胀无法形成阻力，同时将所有动力传导至仿生人的脉冲模块，蓄满后，脉冲发动机阵列爆发的马力可以使仿生人发起一次突破音障的猛冲。现象：在这个过程，SACA力场轰击空气时，会在仿生人的正前方形成耀眼的波动萨卡环，并释放灼热的高温，扭曲空气，四周和前方大范围的空气还会因电离而放电。

**材料篇**

**铋钒玉**

对意识活动有反应的人造物质，含铋和帆，锖色光泽奇异通透，有优异的意识传导能力和硬度、韧度，在意识活化下会随意识体特征呈现出不同的结构色，是制造意识武器的核心材料之一，同时也可以加工成涂料（颜料、填料）。

产业链：

矿业→铋金属钒金属原料→城外工厂→合成→铋钒玉

意识生物“铋物”→活化的铋合金→城内工厂→合成→铋钒玉

铋钒玉→刻蚀神经回路技术→合金加工→意识武器/医疗器械 等

铋钒玉+树脂→混合高温研磨→铋帆涂料

**虹金**

意识液态金属，又叫虹金，该元素被命名为**𬭎**（volinium，Vn）。具有随接触者意识改变一切物理性质的潜能。自然条件下密度接近于铁。制成防弹衣后，会根据装备者的反应速度在全身游走，对正常子弹有出色的格挡效果。

它的首次发现与某种意识生物息息相关。如今它是自意识生物的残骸上提取而来。

用途：

虹金是意识与传统电气工程接轨的桥梁。但由于意识技术匮乏，人类对它的开发不到其潜能的百分之一。目前已经有大量虹金产品，多数是受管制的。

影响

长期接触虹金者，会出现易疲劳、反应力衰退等不良症状

目前没有发现虹金对接触者造成伤残或致死的案例。

在特定意识波形下，虹金会蒸发成气态（较为少见，离散开的虹金会迅速固化，但一些微粒依然可能冲入人的口鼻腔），或是渗入皮肤，造成重金属中毒

生产

虹金的产量不小，价值算不上奢侈，但鉴于其受意识影响下的不稳定性，虹金的持有仍然是受到管制的。

一般市民禁止私自持有、开采虹金原料，禁止从含虹金产品提取回收虹金，禁止持有虹金管制物，违者量刑。

特殊工种作业人士，持有虹金原料需要报备，在工作范围内进行开采、生产、加工工作。允许持有虹金管制物（工具、武器等）

即便如此，依然有上层人士购买虹金制造的家私、奢侈品等。例如知名艺术家设计的画镜（宽4米，高3米），在高价拍卖后流入了超氧旗下，其特性是随着抚摸者的心情而变换和成像，如今装饰在超氧总裁办公室的立面上。

**零点能反应炉**

通过在意识维度完全榨取信息量，成功制造一维势阱，从而产生真空零点能。其后果是，一维势阱所产生的伪真空需要不断投入实际信息熵来防止其跌落为真真空核导致真空衰变，故不得不直接接入意识维度汲取大量识子漩涡结构所产生的信息熵，其后果直接造成不可控且不可预测的意识污染，但又由于一维势阱的不可逆特性，反应炉无法被关停，进而成为了不断吞噬“干净意识”的巨兽。

零点能反应炉建立于尼莫点（待议），其本意是尽可能延长真空衰变对文明产生影响的时间(事实上，真空衰变一旦产生，其扩张速度等同于光速，反应炉建立于尼莫点也只是自我安慰)，但误打误撞的使得其远离意识污染成分复杂、难以综合应对的陆地意识污染和文明污染，仅需要不断吞噬污染即可保证其不受意识污染影响，并持续产出零点能。

戍卫时代，零点能反应炉作为战略性设施由戍卫军团持有。戍卫时代后，其所有权过继到志高肃正，作为全视之眼的供能设施与物理存在部分。

对零点能反应炉的研究似乎是意识污染爆发的主要原因之一，其对信息熵的非零和吞噬加剧了意识维度不平衡现象，对比“肉虫”实验，似乎前者是最终引燃意识污染火药桶的火星，而后者则是持续堆积了意识污染的火药桶。志高肃正对此头疼不已，但一维势阱在物理规律上的绝对不可逆性也决定了这场灾难的无可避免。甚至在某种程度上说，志高肃正以零点能反应炉为基础而建立的总部，已然与其所对抗的意识污染“敌我同源”。

**AVWG技术**

AVWG技术的发展直接推进了针对环状雨楼群的研究。以Lynn和女二为首的一批领航员小队通过深入环状雨楼群中央识子黑洞污染区，确认了遍布全球的最早的一批自发性污染源物理“本体”都是丹朱阁上的肉虫，即第一批产生于地表的每一个超级识子污染源（因为这一批出现的最早，同时因为本体无法被摧毁，所以都发展成了超级识子污染源，）都和丹朱阁上的肉虫呈现一一对应关系。尽管早期的研究对此早有假说，但因为缺乏数据支撑，上丹朱阁确认数据的代价太大，一直无法确认，而目前通过AVWG技术，得以环状雨楼群中央识子污染源（以下简称：Central Pollution Source of Annular Rain Tower Cluster，缩写CePSART，构成Cepsart特指词，或缩写CPAC）进行进一步研究，确认了该假说成立。于是“逐日计划（Project Sun Pursuit 暂定，简称PSP）”应运而生。

计划以摘星行动为始，首先以击落丹朱阁为第一步，尽可能摧毁丹朱阁上的肉虫本体，以确保接下来可以完全摧毁地表所对应的自发性识子污染源。就算无法完全摧毁丹朱阁，也要将其拉入轨道之下，让其迫降，让其上的肉虫全部纳入地表人类的攻击范围。

摘星行动：其实关于击落丹朱阁的各类行动与尝试并非从未发生。而早前的各类行动中，无论是发射导弹，或是使用空天战机编组，无一例外的遭到因识子污染而行动失败。单鸢的领航员正是在之前一次击落丹朱阁行动（长弓行动）中受重伤而无法再担任飞行任务，但同时也因此积累了应对丹朱阁特有污染状况的宝贵经验，为其领航单鸢完成摘星行动埋下伏笔。而单鸢也因为其独特性，在击落丹朱阁的必要性和急需性并未明确前，未派遣单鸢参与相关任务。

摘星行动中，由目前仅有的、少量的、遗留自戍卫军团时代堪用的空天战机，较多的更早期的战斗机加装（外挂）火箭发动机机组，以及单鸢本人组成作战编队。这些外挂火箭发动机的战斗机改装几乎完全没考虑如何返航（骗你的，空天战机们也没有考虑返航）。而单鸢也同样加装了大量额外的模块化武装系统，这对其本身的输出容度和对领航链路造成了巨大压力，但也是为了能最大程度确保此次任务完成。

所以，无论是否能成功，参与摘星行动所有成员们的此次任务，都几乎一定是一去不回。

所有僚机都已为单鸢掩护而牺牲。单鸢终于抵达了可以直接在目视范围内攻击丹朱阁的位置。此时的丹朱阁已经几乎看不清曾经的物理轮廓，只能看见其所在的位置包裹着一层层流光，内部是一整个漆黑的球体，在外环绕旋转着数不清的轨道碎片和难以名状的意识怪物。

确认进入攻击范围。单鸢终于全功率启动了领航链路，哪怕是未加装额外武装系统的情况下，单鸢的领航链路在此工况下也仅能稳定运行五分钟，而此时，搭载额外系统的单鸢在经过了高强度作战之后，领航链路的状况已经不容乐观。

但机会只有一次。单鸢的领航员毅然主观超载领航链路，以意识融毁的代价换来单鸢成功锁定丹朱阁，最终将其击落。但毁伤效果差强人意，大部分肉虫并未被销毁，只是坠入地表。单鸢的领航链路永久失效，飞控系统最后只支撑到了单鸢返回大气层，随后单鸢陷入昏迷，坠落地表，生死未卜（修正之前的牺牲结果）。

总体而言，摘星行动在付出巨大代价后取得最低预期的成功。逐日计划进入下一阶段。

“燎原工程”：丹朱阁的坠毁清除了近地轨道的大部分污染，双月现象大幅度削弱，利用大气层进行波反射的长距离通信现在成为可能。燎原工程旨在系统性部署城际通讯基站，修复穹顶城之间的通联。在此基础上，新成立“城际联合”负责该燎原工程总体管理和筹划，后续由该组织继续负责穹顶城之间的长期沟通、合作商议和事物协调。

“阿尔忒弥斯工程”：在穹顶城通联完全修复的的基础上，构建穹顶技术覆盖下的物流网络和交通网络。穹顶城之间合作进行针对残留双月现象的防护技术研发和动态穹顶技术，并合理规划物流路线，绕开众多的原生污染源并尽可能组成最高效的物流联通网络。

“巴别塔工程”：该工程旨在通过修建矩阵式能量传输塔，重新建立与月面零点能反应炉的广泛通信和无线能量传输，支援地表建设。

“星火行动”：在穹顶城间恢复通联、物流网络建设完备的条件下，城际组织系统性的、有组织的、有计划的对原生污染源乃至于超级原生污染源进行清除。该行动的重难点在于寻找并摧毁原生污染源对应的肉虫“真身”，在寻找和摧毁污染源的同时，还需持续性压制污染源，防止其在“真身”被摧毁前反复产生意识怪物和污染扩散。

注：

1.双月现象：已知由丹朱阁污染源直接引起的广域污染扩散现象。表现为每月特定时间段内，丹朱阁投影与月球投影重合，此时会造成丹朱阁污染集中扩散到地表，轨道虽然会同时部分减弱，但丹朱阁造成的地表污染会陡然上升。双月现象最明显的表现为，该现象发生时，直视夜空会观察到两轮月亮，并且会使观察者难以移开对双月的关注，并逐渐导致意识丧失和躯体污染化。此外，月面会反射并加重丹朱阁污染，导致任何长距离通讯都无法实现，这种影响是无关于时间段而长期存在的，也被统称为双月现象。

2.肉虫投影污染源：即原生污染源，是最早突然出现在地表的意识污染源。其识子结构与肉虫的识子结构深度绑定，可以理解为，肉虫是连接意识空间与物理空间的“门框”，而原生污染源则是这扇门的“门”本身。故可称肉虫为原生污染源的“真身”，而原生污染源则为肉虫的“投影”。两者在物理空间可以相距极远，但在意识空间内表现为一体的识子纠缠结构。
