# 前言

对意识作战，最有效的体系为仿生人-领航员体系，既可以有效杀伤意识生物，又可以回收有价值的意识资源，可控，且战力保存较为容易，可以支持长期作战，减员率小，易于DIY。

而智械作战体系，起源于卫戍时代前期的主流战术，即人类作战小组配合智械的火力与机动性，大范围地、定向地清剿意识生物。智械的火力可以彻底摧毁意识生物躯体，但对于其意识体的交互十分有限，以至于长期的意识生物清剿战本质都是徒劳——直到仿生人体系诞生。

值得一提的是，卫戍时代曾实行过人类超级士兵计划，旨在将人类尖兵改造成能有效杀灭意识生物的超级战士，后由于生产成本极其夸张，转化率低，回收价值极低，有效性还不如把肉虫罐子当摔炮炸，于是不了了之。一直到十四号城现在，才被商会的少数人重新发掘。

而穹顶城时代，智械体系的发展也未曾停止，其优势在于：1.易于设计，可量产，2.使用寿命更长，即便报废也可以回收零件再加工，3.可控，智械依赖于“命令能指”行动，误伤率低，4.技术更保守，因此利于大规模的传统的工厂生产和补给，原材料获取也相对轻松，而仿生人生产所需要的跨学科技术注定了精尖仿生人生产会被一小部分组织垄断。5.意识污染抗性更高。

而智械对意识交互的无力也在一步步改善。最终，诞生了以智械为核心构建的有效对意识作战体系——**现实场域**技术。

**现实场域**

**——以智械为核心的对意识作战**

**现实场域：**

一定范围内稳定现实的领域，能有效压制意识的不稳定性，可以看作“**逆意识空间**”的存在。以智械意识为稳定锚，展开现实场域，范围内的所有意识生物、生命，其意识体会从意识海中拽离、连带一小片意识海暂时独立出来，与躯体完全合一化，成为完整不可分的个体（由于精神与躯体直接联系，且从意识海中隔断，此时生物将会暴走，进入“**超感**”状态）。同时，也连带着附属的规则律一同生效——所以在现实场域中，世界的物理法则与意识个体的规则律（比如信仰能量、愿力、意识技能）将会同时生效并叠加。**在场域中，直接使用物理手段摧毁意识生物个体，就可以彻底杀死对方，不需要单独斩杀意识体。**

现实场域发生器只能搭载在智械上，并且是以空间“光环”的形式生效，智械作为场域的中央锚点，智械移动则连带场域光环移动。

**设定：**

现实场域的技术建立在反识子漩涡解链技术之上。其首次发现与六号的小队有关，也与“一号”“二号”方案的竞争有关。该技术掌握在极少数组织手里（至高肃正），遭到超氧、二号的觊觎。

现实场域能稳定现实边界。现实场域本身的边界会阻隔意识交互/污染传播。

现实场域中的意识个体会进入“**超感**”状态，获得大幅强化，甚至获得跨感官的超感应力。“超感”是意识对世界的直接体验，在神秘学、超心理学等学科里有记载。

现实场域范围中的意识污染会被解明，从而得到控制，范围内的意识污染无法突破个体边界，但空间限制也导致其高浓度、高速度地侵蚀场域内的个体。

现实场域解除后，存活的意识个体会重新链接回到意识海，并解除“超感”，场域内积累的污染会重新开始传播，需要用额外手段净化。

有人将现实场域比作斗兽场或是八角笼，除了敢死队以外几乎没人愿意与搭载现实场域发生器的智械一同行动。（原因又见“区别4”）

智械被毁坏失能后，现实场域解除（存疑，也可能存在半永久生效的现实场域）。

现实场域的展开可以直接逆转、覆盖已在场的意识空间。（参考奈克瑟斯的美塔领域）

**至高肃正的塔罗牌展开的现实场域界限不但隔绝污染，还可以屏蔽认知，实现范围内秘密作战。而为了减少超感导致的肃正者感官过载，该领域内的肉眼视域被滤成了黑白色。**

现实场域技术与模因工程技术有较好相性。

**与意识空间的区别**：

1.现实场域中，规则律会叠加在一切物理法则上生效，规则强度受限于意识个体本身的意识能量/体量/意识海量，所以现实场域中使用的物理手段会更为有效，也因此现实场域是低级意识生物的克星（擅长割草，不擅长打BOSS）；而意识空间中，只有规则律会生效，即被共识认知的法则会生效，无关乎物理法则。

2.意识空间的构筑依赖于领航员-仿生人体系，需要至少一名领航员领航+一名仿生人深潜时，意识空间才存在，而现实场域的展开依赖于智械或者说人工智能。当然，只有搭载特定技术的少数智械才可以做到。

3.意识空间作战，无法将规则律带出意识空间，无法让规则律影响现实，只有意识污染才会将规则律现实化。而现实场域则可以做到临时的、小范围的规则律现实化，可以说其外在形式类似于一种可控意识污染。

4.由于现实场域将一部分规则律带到现实，因此领域中的意识污染积累会加速，但不会传播（因为个体意识海被临时封装了）。如果作战失败，现实场域解除，则累积的污染会迅速爆开，无差别影响场域内的个体，其中承受污染最大的是展开场域的智械本身。而另一边的意识空间，主要副作用是：长期深潜导致领航员的精神崩溃，以及深潜仿生人意识可能受污染、迷航，也有领航员为了解除危机而违规深潜殉职的案例。

5.意识空间是对意识海的建模，因此“意识体通过意识海互相联系”的定律是成立的，但现实场域中的个体意识会从意识海中暂时剥离、封装，因此互相之间无法进行意识交互，直到场域解除。

6.意识空间取决于领航员的**想象**，而现实场域则是以人工智能的**理性**所锚定的。原理相当于智械将自己的意识（一片独立的微缩意识海内的冷意识体）方程逆转，生成的锚定域，也可以比喻为智械将范围内的个体和污染源“请”到自己的局域网里做客。（闪点以上的意识会链接到意识海，此时的智械还能展开现实场域吗？闪点以上的智械可以开关自己的意识体封装吗？）

7.意识空间作战通过让深潜的仿生人斩杀作为意识污染源的意识体、意识生物，来遏止意识污染扩散，而现实场域作战则先囚禁、压制意识污染源，再用针对性战术解决意识污染，需要更专业、更细分的设备处理，也因此一次现实场域体系作战需要投入的资源和人力更多。

8.只有生物意识才能进入意识空间内，通常是由仿生人深潜进入，而现实场域“来者不拒”，任何人、生物、仿生人、意识生物、意识污染乃至环境都会被囊括其中，接受现实稳定场的锚定。

9.**意识空间**极其**不稳定**，并且会随着深潜时间增加而滑坡至深层，直到仿生人迷航，失联在意识海边境。而**现实场域**则极其**稳定**，规则清晰，便于理解，下限高，不过换句话说，由于很难被“具备充足想象力的领航员”重构，其上限也更低。

十四号城穹顶一号是生物意识智能，因此不具备展开现实场域的潜力。**但是二号将可以**。这也是为什么二号的计划本质是原子主义——他展开的全城现实场域将导致所有人的意识体被各自封装、隔离。届时，改造后的新穹顶智能二号以及全城的劳动智械都将搭载现实场域发生器，以牢牢稳固十四号城的现实边界，避免市民受意识污染侵害，也避免人与人彼此联结带来的不稳定因素——代价则是这座城市文明永恒的封闭。

由于高等级的现实场域将覆盖意识空间，所以二号构建的十四号城不需要仿生人这种一无是处的不稳定因素。
