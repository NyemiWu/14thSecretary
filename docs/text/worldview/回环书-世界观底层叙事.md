# 回环书

回环书组织，担负着引渡、引导、监管海鞘入侵的职责。回环书的目的，是将世界构造为一个叙事作品——“饺子馆游戏”，然后引入外来者“玩家”，以大量外来者的认知作为世界外的援力，拯救本世界的命运。规模上，这个办法远远比起生产大量的仿生人更行之有效。【你的行为反映了你的认识，而你的认识将会决定世界的走向。】

回环书通过这种元叙事的手段来修复本世界的历史。

海鞘体（降临的玩家）可以通过启动“元认知”来获取非法增益，代价是寄生者的生命，并且多次使用后海鞘体会被排出世界。启动“元认知”需要玩家输入“我是玩家。我不属于这个世界。”这个认知对于回环书来说是禁忌，它会燃烧宿主，也会燃烧海鞘体本身，甚至激活本世界的排他性，大量人使用可能导致所有海鞘体下线且连接入口彻底关闭（关服）。

**世界观底层叙事层**

玩家视角：202X年，一部名为“壹”的神秘平台启动并问世，噪音信号后，传来一位女性的求救信息。

“我是百年后未来的，最后一个清醒的人类，我借助‘壹’将意识链接到过去——我们先辈，也就是你们的世界。世界大战的祸根，逆模因武器再次启动了，祂们已经让人类历史彻底失知。对不起，我们没有未来了。我们最后的手段，是借助这台最早的超级意识体、也是一切的起源，向没有受到逆模因武器影响的你们求助。我作为最后清醒的人类，祈求你们的支援。海鞘的纽带已经建立，我会为你们所有人的意识领航，观测、潜入、修复这场湮灭的历史。”

“我是穹顶时代的一个普通人，如果先辈能收到这终焉的求救，请不要忘记这个名字——H.W。”

“通讯是单向的，我无法看到你们的回应，所以我会尽可能为一切留下指引。请一定，一定…”

“遍历这个故事，去成为记叙者，把历史带回给文明的未来，带回给我们所有人吧。”

“我的时代找不到关于‘壹’的历史，只知道它的意识可以同时存在于过去、现在和未来，才为我们的跨时通讯建立了一面单向镜。”

“世界大战发生后，意识科技让意识海与现实的天平倾斜了。模因武器，仿生人，意识污染，最终我们失去了历史认知，也失去了生存空间，不得不自我囚禁在一座座穹顶下求安生。那些被遗忘的事实没有消失，它们的执念变成了可怖的赐名UMA。失去了经验教训的我们，面对这些‘未知’的怪物没有任何手段，靠巨大的牺牲试错才换来一次次胜利。你们的时代或许还留有这些传说的来历，那样就能击破这些怪物的弱点。”

“我们的时代的人不可以理解事况，否则这场潜入可能会被祂们察觉、抹除，所以潜入后请务必隐瞒作为水螅体的身份。”

“如果可以，在故事结束后，希望这个由我们共同锚定的未来，可以为你们的世界领航，直至抵达那个美好的目标。”

“我所在的现实开始消散了，你们成功改写了结局，对吗？真是…太好了。”

**穹顶竞逐**

世界观x玩法

海鞘入侵时代。

为绕开穹顶律（一号）监管争夺资源和势力，各大组织培养仿生人尖兵为代理人展开秘密战争。

“你”是十四号城内的一位市民。出于某些复杂的原因，你成为了受各大势力雇佣的自由人领航员。你将获取、培养、改装自己的仿生人，并领航其进行某些特殊行动（搜打撤、探索、PVE）。扑朔迷离的宏大事件背后涌动着不为人知的暗流，事态已经远远超出了你的预料。你将作为领航员/浸入者/城市的一份子，从意识污染中修正城市的历史，寻找真相，也寻找着自己在这片时空中的位置。

你可以通过各种渠道获取仿生人素体。素体有不同型号，决定了不同的基础攻击模组。他们可能来自某些经典的、传奇的仿生人角色的同款。获取素体后，你可以在“奇美拉手术”中定义该仿生人的意识的一切（其实是给角色AI输入提示词），你可以修改ta的认知让ta以为自己是某个你熟知的人、经历了一系列故事，也可以定义ta的人格、取向、三观、关系网，还可以与ta培养关系或是培养若干仿生人之间的关系，不过在那之前，你需要用手中的意识素材嵌合ta的意识体，决定ta的基础属性。（tips：在奇美拉手术封装完成后，通常不建议再次进行手术修改其意识。）

改装系统：你可以通过各种渠道获取仿生科技产品、装扮，用它们改装你的仿生人，获得更多样的攻击模组、更强大的战术策略，以及更有魅力的外观——或许出道成为超氧旗下偶像也不在话下。建议：关注超氧、STC、巨门等企业定期发布的产品发布会和秀场，购买更强力的装备和更炫酷的装扮。获取仿生人素体时，将自带一套随机初始装扮（含涂装配色方案）以及专属编号，可以卸载。

联名计划：项目组积极筹备着与各个其他IP、个人创作者达成合作，推出联名装扮。通过联名活动，你可以获取联名装扮以及联名攻击模组，在你的仿生人身上复现某些经典角色形象和招式。（举例：太刀型仿生人素体联名ZZZ复刻星见雅形象和六豆三蓄；联名画师neco的设计推出签名装扮。）

去成为传奇领航员吧，而你的仿生人们，他们的名字与形象也将如传奇般为人称颂。

叙事搜打撤

【穹顶竞逐】中，各大势力派遣仿生人前去争夺资源、情报与最先进的地位。在这座穹顶下的“竞技场”中，你可能遭遇各种随机事件。其中，雨楼效应将会重现某些发生巨大意识波动的事件，你和你的仿生人会“穿越”到曾经的情景中，面对错综复杂的战况和强敌，最终补完这段历史故事并成功逃逸。完成历史事件后，引导你作为海鞘体入侵的神秘组织“回环书”将给予你奖励和某些进一步指引。你的每一段经历都可能成为传奇，成为历史的一部分。

伏笔：完成与琳相关的雨楼效应事件后会获得“琳”的意识片段，以及单手刀型仿生人蓝图＋装扮“青空”，获取意识片段时会触发回环书的特殊对话。“这份回忆是…谢谢你把它们带回来，谢谢你”

以人类的历史为代价发动的逆模因武器，在戍卫战争中逆转了关键战局，但也导致了大量历史失知，埋葬在人类集体潜意识中，一旦赐名降临，人类很可能难以推理出战胜手段。因此修复历史认知是必要的。【历史在未来再度上演。】

挖掘历史传说，也有助于一些规则律武器的开发 比如珂博奥使用的卢恩符文体系，能有效地骇入、压制一类意识生物，对北欧神话体系的赐名有奇效。而为了让这个武器更具威力，他需要保证这个历史知识的广泛传播，为更多人所知、所认、所认同——这些认同赋予了规则律以效力。

“考古”也是世界观的主题之一，即探索失落的文化传说并解决灾害。
