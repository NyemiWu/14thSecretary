# **规则律**——意识空间作战的底层逻辑

意识空间的规则来源于人的普遍认知。如，石头剪刀布，金木水火土，杀鱼刀能杀死鱼，中元节会有百鬼夜行，越无知越自信，还有各种法律——任何事物在意识空间里都是符号化的，于是通识下的一切符号规则便可以在意识空间里成立、奏效、以及得到利用。这种认知域规律被称为“规则律”。其中，心理效应的规则占比尤为显著。

一些典型生效的规则律

1.  常识（桌子是木头，水结冰）

2.  法律

3.  文化（习俗，传统，俗语，文化，神话，传说，神秘学）

4.  意识形态（主义）

5.  科学理论（物理公式，化学反应式，数学模型）

符号力学与认同能量经济学

符号力学 (Symbol Mechanics)

符号的力量直接来源于“认同”的能量。相信它的人越多、越虔诚、越集中，其产生的物理与心理效应就越强大。

认同的程度即是符号的力度。接受大量认同的符号及其规则，将成为普世认知规则，在意识空间内生效。如果某片区数万人都认同一种民俗，那么这种民俗文化的规则将会在意识空间中实现，也将会在意识污染到来时具象化于现实世界。越是大众认可，符号规则越是稳健。认同来源于以人类为主的智能意识生命，仿生人也在其列，而闪点以下的智械则不具备该权能。

数量原则：认同者的意识体量越大，赋予能量越大。以一个标准的、成年人类意识体为单位，这样的认同者越多，则赋予能量越大。

质量原则：认同程度越深，则赋予能量越大。

空间原则：如上述例子，一万个具有相同认识的人集中在一个片区，在该片区的意识空间内，其赋予符号的能量，将大于同等人分散在世界各地时的赋予能量。即越聚集紧密、越有效，越分散越稀释。（因为意识空间是结合了现实三维空间而建模的中介空间）

涉己原则：被认同的符号的所指本身如果有意识，比如一个人，那他自我的认知将对自身的符号产生更大的影响（相比于他人对其符号的认知）。通过这个原则可以建立最基本的个人模因防护（自我暗示）。

转喻原则：符号和符号、符号和规则之间的连接（能指链）难以改变，但是可以通过转喻来在一定范围内改写和借代符号。比如鱼型意识生物→鱼。这也是为什么领航员的意识空间作战需要丰富的想象力与联想能力。转喻后符号力度可能会发生变化，取决于转喻过程中的认知能量耗散。简单来说，手→hand这样的转喻几乎不会发生变化，但鱼→水生动物这样的转喻则涉及大量能量变化。否则，一切意识作战都可以变成【我→剪刀，敌人→布，无→石头】然后结束。

关于转喻能耗规则：

同范畴可以转喻（同属一个认知域，比如苹果、香蕉，天使、恶魔），跨范畴几乎无法转喻（比如风、马，电脑、薰衣草）。

向上跨层次能耗小，向下跨层次能耗大，如“狗→柯基，大”“柯基→狗，小”，柯基一定是狗 所以能耗小，狗不一定是柯基 所以能耗大。

将一个认知域的经验结构系统地映射到另一个认知域以理解抽象概念，即隐喻，隐喻关系会使转喻可行，比如“时间就是金钱”下，时间到金钱的转喻才会可行（即便是两个跨范畴概念），本质也是通识规则律生效的结果。

抽象的、形而上的符号，具象的、形而下的符号，互为异性，异性之间可以用隐喻来转喻（时间就是金钱），同性之间可以用范畴来转喻（柯基是狗），也可以用比喻来转喻（云像小狗），其中比喻转喻的耗能更大，语义流失多。

意向图式（认知语言学），容器，路径，力，连接，等，是认知结构也是符号的关系模式，比如“【陷入】阴影”，是用了容器图式，将阴影具有的结构（内部，边界，外部）映射为容器。图式类意识交互，可以将如“（陷入）阴影”的此类符号映射成图式，再通过图式映射到其他符号“（陷入）爱河”，以完成转喻。

**框架**，例如：【战争】框架，包含要素有敌人、盟友、目标、武器、战场、伤亡等，并且框架主题导向“对抗、牺牲、胜利”等。框架类意识交互像是一种叙事发生器，将多个目标作为要素填入框架，并发生叙事关系。借此案例：将“超氧士兵，戍卫军团，意识素材，工厂”作为“敌人，盟友，目标，战场”，以激活框架【战争】，在此框架下将遵循强化的战争规则律，然后你可以将“铁管”装填到空白的“武器”要素位置上，就能获得一把受到【战争】框架赋能的铁管武器。总的来说“框架”是一种很有角色扮演乐趣的规则游戏。还有诸如【商业】【餐馆】等一系列框架。与规则律的大众通识条件略有不同，框架的规则律只需要框架影响内的人认同就会强制生效。

执念与意识生物

意识生物催生于强大的执念，这种执念本质同样是“对于某种符号规则的坚定认知”，所以在意识污染的影响下，这种执念成就了现实——形式则是意识生物。而其中一些强大的意识生物，将会发育至“赐名级”，链接一个可以被认知的特定符号，并享有该符号所牵连的规则律。比如神话传说中的怪物名。或是某种物件。围绕这些赐名，有专门的职业负责研究它们，比如**测名师**，或是祓除名讳的肃正者、颂读者。总的来说，杀死一般的意识生物需要同时斩杀其物质躯体和意识体，但即使这样做，赐名级别的意识生物依然会以同样的名字重新降临在世界上任意一个地方，所以需要至高肃正这样的组织用逆模因手段专门祓除其名字，让赐名从人类文化里彻底抹去，才能避免赐名再临。

**测名师**：测定意识生物赐名以及符号规则的的专业调查员。一种对人文社科素养要求很高的职业，要求职业者需要通读世界文化史，了解全球各地文化传说，他们就像警局里的画像师，需要通过只言片语和零碎影像锁定目标的身份，并使用专业的模因设备进行测定。很多时候，意识生物的赐名并不诞生于已知的传说，因此需要测名师进行田野调查来确认意识生物可能的赐名。

**（由于确定意识生物赐名的过程，是一个典型的局部“降熵”行为，根据信息通道学说，一个系统越是试图消除污染的不确定性，则越是会受到意识污染侵蚀，因此“测名”的过程有概率会受到意识污染反噬。）**

要求：具备良好的心理素质、信息感知和洞察力，以及基本的极端条件生存能力，推理能力是加分项。在仿研所这样的意识科学组织里，他们是收集敌人情报的先行者，由他们揭露真名后才能揭露作战规则，因而测名师或者说测名能力是不可或缺的。有一个案例是，仿研所在剿灭某只九头蛇型意识生物时陷入困境，原因是“用火把烧断颈”的规则律并没有生效，而在测名师介入后，才重新确定了意识生物的真名并不是希腊神话的“**海德拉Hydra**”而是山海经的神祇“**相柳**”。该次行动后以“治水”为代号收尾。

赐名规则：赐名所指范畴越广泛，则名字能量越低，比如“鸟”“兽”“木制物”“玻璃器皿”等，反过来，所指越独一，则名字能量越高，如神话名字、专有名词。字符长度本身对能量的影响可以忽略不计，因为多余的字符在认知里可以作为符号附属，如“奥丁-神王-独眼的知识之神-诗歌之神-法术与化身之神”中，“奥丁”一词即可承受全部意义，其余捆绑词缀不额外附加意义。与信息熵原理一致，即该名字消除的可能性越多，则信息量越大。通常看来，一个意识生物的生命轨迹，如果与某赐名命运高度吻合，则获得该赐名的可能性越大。而赐名的发生对象是否局限于意识生物，以及赐名机制如何转化、移植和利用，还有待科学定论。

意识污染的一个实质，便是意识空间的规则律反过来影响到了现实世界的表征。比如昆山，屡屡在作战中幸存归来，于是越来越多的人开始相信他是所向披靡的龙将，带领将士们一次次行军、一次次摧枯拉朽。所以昆山受到的意识污染表现为，他的外貌变成了半龙半人、与盔甲融合的模样——意识污染将人们的期望变成了诅咒。以及圣莱山德医院的院长，被污染变成羊角的恶魔，也是来源于规则律的影响。温迪戈的诞生也是如此，食人恶魔温迪戈渐渐流行在阿尔冈昆语族传说中，而意识污染则会让温迪戈降临，随着传说范围扩大，接受信仰的温迪戈的力量也会不断增强，最终扩大成不可收拾的文化症候群，以及一头蜂巢级以上的大型意识生物。

**超现实认知管理条例**

由于意识污染会以规则律影响现实表征，所以一切封建迷信、宗教信仰、坊间传说、神秘学、超验认识、集体唯心主义、超越现实的理念、以及一切不切实际（字面意思）的幻想，都必须受到范围管控。**城市认知监察委员会**就是对此类条例负责的主要机关。一旦管理失责，再遇上意识污染的袭击，极容易造成重大公共安全事故。但是，城市认知监察委员会并不妨碍一般市民的民俗信仰，也没有权力胁迫所有市民刻下唯物认识论的思想钢印，那样，压抑的公众思想反而容易执念化，催生意识生物的诞生。他们做的，只是监视认知域模因和意识污染的大幅波动，并在危机未至时加以干预。而如果危机已要酿成，他们则会用更不可示人的那副面貌出手。

在认知管理条例中，明令禁止了修改、杜撰、扭曲公共认知的行为。但超氧公司钻了个空子，通过培养明星、偶像等大众符号来间接控制公共认知。音乐家的大型公共安全事故就是这样酿成的。超氧用某种意识工具屏蔽了音乐家的符号标识，自以为瞒过了城市认知监察的观测手段。不过，在事故发生时，**黑袍**并未缺席。

据传城市认知监察会向公众影响力大的组织、以及涉及意识科技的组织收取**认知税**。委员会对穹顶“一号”以及穹顶律法负责。

一号屏蔽意识污染的一种解释是，通过巨大的高权意识体，创造“穹顶律”并接受市民认同，使得穹顶律受到规则律赋能，从而在现实中生效。这些法则的力量来自于一号以及全体认识到穹顶律的人。每一片穹顶板，都会像巨人的肌肤一样，以不可动摇的律法，“拒绝”意识污染的侵蚀。也因此，一号的符号是“巨人”。

**回环书**

回环书组织，担负着引渡、引导、监管海鞘入侵的职责。回环书的目的，是将世界构造为一个叙事作品——“饺子馆游戏”，然后引入外来者“玩家”，以大量外来者的认知作为世界外的援力，拯救本世界的命运。规模上，这个办法远远比起生产大量的仿生人更行之有效。【你的行为反映了你的认识，而你的认识将会决定世界的走向。】

回环书通过这种元叙事的手段来修复本世界的历史。
