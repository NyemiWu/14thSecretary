# 识子论

识子理论：基于对意识污染研究而日趋成熟的尖端基础理论。该理论认为，任何能被观测和被描述的信息均可由映射于“意识空间”的基本粒子“识子”构成，“意识空间”是由识子作为基本粒子构成的另一维度空间，其中“识子”的纠缠、产生与湮灭直接对应现实世界中的任何变化，包括物理变化与思维活动。意识污染实质上是意识空间内出现异常波动，识子受无规则扰动而导致的现实世界异常状况，意识怪物实质上是识子异常波动所产生新的识子纠缠群而构成的构造体映射到现实世界产生的攻击性类生物。在此基础上，人类的意识在意识空间的投射为“较为开放的识子纠缠漩涡”，故容易受到意识污染侵害，没有对意识污染的抗性。而仿生人的意识空间投射为“封闭的识子纠缠漩涡”，具有意识污染抗性，但难以对环境变化、自身感受等在意识空间内体现为“方向”的变化做出感受和改变，故仿生人均需要一名人类作为“领航员”，防止其意识空间投射“迷失”，进而破损、异化，变成意识怪物。

听链：对识子结构进行定位、识别、解算的技战术动作，是系统化执行意识海作战的初步行动之一。

在针对高级别识子污染团、高级别识子结构时，听链动作的必要性会大幅提升。对此类目标实施打击时，务必提前进行听链，避免深潜过程中无法定位咬链位置或咬链能耗过大造成本体识子结构熔毁。

对于原生识子污染源的听链操作目前只能通过AVWG技术进行。对未被听链过的原生识子污染源无法进行咬链。

咬链：最初为识子应用技术中的一类专有名词，特指针对识子结构的解链技术。后在意识海作战中用以指代摧毁或抹除某一识子结构的战术动作。

有序识子堆积块：在意识空间内呈现为某种可对应物理世界基本相互作用力的识子结构，其开发和使用为识子技术的应用基础之一。最初被视为一类特殊识子，后来研究证明其实为一定数量识子按特定结构堆积而成的特殊组合，并以此为基础可批量生产。将其与虹元素相关的技术开发结合，可以在物理世界开发出远超常理的特殊材料，如反重力材料、三磁极金属、逆温变超导材料等等。此类材料的应用使得识子技术的应用效果几乎成为魔法。
