# 仿生人

为了反制意识污染而由AI主导设计的，人造智能意识人型体。具备和人类几乎完全一致的外貌，思想情感活动与人类也别无二致，连消化代谢系统也做到了高度仿生。

不同型号、迭代的仿生人有不同的功能。

仿生人生产依赖于最先进的意识科学、生物学与工程学技术，是后意识时代下不同于智械的更接近人类意识本质的人形智能造物

关于仿生人：在戍卫军团时代，人类为抵抗意识污染及其此生影响产生的意识怪物，制造了仿生人。仿生人依赖于“领航员体系”以构建完整的作战系统。领航员体系由一个正常人类和一个仿生人组成，正常人类负责保证仿生人躯体正常工作，为仿生人提供现实世界的“意识锚点”，而仿生人则依赖“意识锚点”进入“意识海”，在“意识海”维度中对意识污染和意识怪物进行根除。脱离领航员的仿生人单独进入意识海会导致其失去意识锚点，从而迷失，变异成新的意识怪物，相对的，仿生人深潜进入意识海后，留在物质世界的领航员在（具备物质躯体）意识怪物的袭击下相当脆弱，两者需要极为默契的配合才能顺利完成作战任务。失去领航员的仿生人往往不被批准执行作战任务，但也不乏为拯救被意识污染侵蚀的领航员铤而走险单独进入意识海的仿生人，其结果往往是悲剧。

*长岛狛鸣作为仿生人，其领航员已在穹顶城合围前战死，其本人之后一直无法找到合适的继任领航员，而流落至民间，在北岸区挣扎求生。但不熟悉人类社会生活的她差点死于见义勇为导致鸦巢对其的追杀，好在是奥博连斯基因为“某种召唤”而出手相救。或许奥博连斯基本可以成为她的继任领航员?但已经无从得知了。*

仿生人保密协议：戍卫军团时期的早期仿生人运用中，仿生人不稳定性极高，寿命极短。后在长期实践中，结合大量实验证明，仿生人身份信息暴露越多，其稳定性越低，即对仿生人的“认知”会影响其识子封闭结构的稳定性。故到了穹顶城时期，仿生人保密协议已经成为各大拥有仿生人势力之间的共识，即尽可能隐藏自身所拥有的仿生人身份信息，或杜撰完整的伪造户口信息，避免其仿生人本质暴露。（这一点可能有与信息通道学说有关，因为越是加入复杂的信息系统，越是容易受到污染，所以仿生人最好保持极其有限且受控的社会认知关系）

仿生人生产：

奇美拉意识嵌合手术：纽带-障壁技术，是生产仿生人所用的意识技术，仿生人的意识成型需要嵌合多种动物意识（含UMA等超自然生物意识），一并封装到仿生脑。嵌合的动物，往往具有人类不具备的感官、本能、技能等，是使得仿生人实现各种功能的绝佳意识材料。一些体量较小的动物意识，则需要事先叠加、培养复数样本，融合成有一定体量的个体，再加工成奇美拉素材。

奇美拉嵌合体：并非只有Lynn拥有奇美拉嵌合体意识器官，但只有Lynn的“奇美拉嵌合体”被称为“奇美拉嵌合体”，其余仿生人的“奇美拉嵌合体”意识器官被称为“泛用性奇美拉嵌合体”（待议）。该器官的制造和生产技术是仿生人作战能力大幅提升的核心，区分一名仿生人是否具有意识海战斗能力的核心。“奇美拉嵌合体”通过向仿生人的识子漩涡结构中嵌入某种人类认知中的“生物特性”，例如狼的凶狠，或者鸟的灵动，甚至神话造物如“独角兽”的正直优雅，以此改变仿生人的性格特征乃至于行为和作战风格、作战能力。拥有“奇美拉嵌合体”的仿生人较其余仿生人而言，抗污染稳定性和作战能力均有显著提升。Lynn的“奇美拉嵌合体”没有嵌入“任何人类认知”，即“只有奇美拉本身”，故拥有吸收意识污染并为其所用，甚至不受意识污染影响的能力（待议）。

格式塔校验：涵盖知觉校验、构造体校验、抗分裂校验等，确保意识体在感知、认知、精神体上具备完整不可分性。未通过格式塔校验的仿生人，可能出现偏执狂、精神分裂、躁郁、认知障碍、妄想症、人格分裂、意识免疫力低下等不良特质。

污染免疫力测试：测试仿生人在高压污染环境下的意识体稳定性以及修复成本。对于需要深潜的特种仿生人来说是必要的。

神经系统测试：确保仿生人神经系统正常运作，不会出现内感失调、肌紊乱、肌无力、神经募集力不足、反射弧断路、电信号过载熔断等症状

花蚀现象：脱离领航员后长期接触意识污染，或继续反复调用深潜模块，会导致大部分仿生人会遭到污染而异化为意识怪物。而极少部分仿生人会强烈抵触异化过程，从而触发花蚀现象。该现象表征为仿生人本身连同其主观认为的所有物，例如衣着、所持装备、住所和藏品等突变为与先前物理体积外观类似的灌木丛，表面附着大量品种不定的、颜色艳丽的花卉。已知花蚀现象一旦触发即不可逆，从花蚀开始蔓延至花蚀完成仅需一到两分钟。其伴生的鲜花与灌木丛会在数日后凋谢并枯死，并在之后几个小时内化为识子活性极高的虹元素稀土粉尘，一般称之为“花粉”，具有极高的科研和工业价值。
