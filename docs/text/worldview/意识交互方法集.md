# 意识交互方法集

前言
意识交互，是意识武器、意识工具、仿生人、意识侵蚀生物等有意识体运行功能、达成目的的手段。通常，意识输出功率越大，效果越强烈，也可能受到输出时间等多方面因素的影响。仿生人的意识输出功率有限，为了避免烧脑和波及友方，不会大规模高功率地输出意识波，他们的设计初衷是像手术刀一样精准地实现某种功能。也有类似意识炸弹、意识辐射塔、意识探灯、穹顶主动防御系统这些功率不同的意识工具，它们的使用也都刚需活性意识，因此工具里有一些仿生脑组织来充当电池。完全无意识的东西是无法与意识产生交互的。（这种说法、定义有些类似“有机物”和“无机物”，它们各自有一套系统，相对较为独立，鲜有“固碳”“焚烧”这样的反应才能使二者相互联系、交互）
大脑等器官是意识的载体，大脑生命活动是意识反应的结果，意识交互可以跨过大脑等生理物质直接影响目标意识，比如让身体健全的人在意识中残疾，他的意识的一部分无法再通过大脑下达命令控制身体。因此，意识交互往往不以大脑或生理物质为出发点和目的，而是视其为重要辅助材料。
本文档正文列举了世界观里使用意识交互的所有武器/工具/产品/技术/技能/能力/病症概念
“意识就是海水，思想就是海水中的漂浮物，观念就是海水中的冰块，情绪就是身体对思想的反应。观念决定反应的方向，积极反应或负面情绪。念头是思想的初期，就是潜在海水里的物体，浮出水面以后就是思想。”

定义与分类
意识模型结构：意识体，游离基质，意识质料，意识海
其中意识体的结构有：
外结构：意识障壁，意识-物质纽带
五大功能器：情绪，认知，记忆，思维，感官，
内部能源：基质
在此基础上，意识交互方法通常涉及这些方向中的一个或多个：
1.情绪，即情感等。通常是短期的、会推动行为的。可分为积极/正面和消极/负面。相关结构：额叶等
2.认知，各种概念与对应观念，包含思想、文化、模因、价值观等。相关结构：顶叶等
3.记忆，客观事物在意识载体上的编码、存储和提取，把抽象无序转变成形象有序的过程就是记忆的关键。此类交互与回忆、遗忘等有关。相关结构：海马结构等
4.思维，思考、逻辑、推理、智力、理性判断、方法论、等归于此，此类交互通常表现为智力受影响。也有一些交互通过屏蔽思维来让目标对某些事物不加以任何思考便得出观点。
5.感官，触觉、视觉、听觉、嗅觉、味觉、痛觉、空间感、平衡感、时间感、本体感、疲倦感等有意识感官（不包含内感等无意识感官）。感官类交互可以把感官加强数倍，进入超敏状态，或是按设计目标来修改感官。相关结构：枕叶颞叶等
6.纽带，与以上术语不同，纽带不是意识体构成之一，而是意识体与载体（各类器官）的链接、控制权。此类交互可以重构意识与载体的关系，把意识移植到其他载体，切断或建立意识链接。相关结构：一切意识器官、生物神经网络
7.障壁：同上不是意识体构成之一。意识体的边界，类似细胞的细胞膜，EVA里的心之壁（AT立场）。障壁类交互主要作用于意识体与意识体之间，可以让多个意识体融合，或是让意识体分裂成多个意识体，也可以让意识体孤立，无法被影响。趋同、排异，胞吞、胞吐，合并、分裂，边界感，认同感，代沟，隔阂。越是趋同的意识体，其互相之间的障壁越薄（这种相互关系无视物理空间距离）。集群意识、自然意识、奇美拉意识、虚拟意识（信仰）、穹顶智能等超越个体规模的抽象形态意识，也是障壁类交互的课题。
8.基质：意识活动消耗的能量，或者说基质里的某种组分是意识活动的能量来源，可以粗略认为基质的量即意识能量、心力、精力和精神力等。意识活动会消耗基质，而意识主体在睡眠等修养行为中会进入“无意识”状态，使得意识体能从意识海中补充基质，原理类似细胞质基质和渗透压平衡。
每个意识体在这些方向上有不同的能力值分配，可以用五边形图+两个槽+能量槽表示。世界观里几乎一切交互，包括战斗、对话、探索、剧情等，都将基于量化的意识能力系统发展。

正文
扇中兵戈：认知-感官武器，让敌人认知中“觉得”这是某种明确的武器，并通过正常使用动作来触发效果：如让敌人觉得自己的手被砍了，但物理上敌人的手没有受到伤害，敌人却实实在在感受到痛觉并“失去”了手。
离神断魄：纽带武器，暂时切断敌人意识与肉体的链接，使敌人肉体瘫痪，进入无意识状态，但敌人的意识在意识空间中仍然保有活性。不考虑副作用的话，可以解决失眠。
吞噬者：障壁-基质武器，在敌人的意识失去载体后，切碎、吸收、消化敌人的意识到自己的意识里，补充意识能量。由于切碎、消化不彻底，无止境地吸收意识会带来噩运般的副作用。可以获得对方的一部分意识能力。
“温迪戈之吻。”——亚尔伯特·珂博奥
精灵：感官技能，消耗意识能量，暂时强化注意力和感官，实现如本能激发、暴走、子弹时间等功能。本质上，这种增强来自吸收的其他意识，它们用感官帮助宿主观察环境。
蜃景：认知-感官武器，修改目标对空间及静止对象的感官与认知，产生场景幻觉，比如看到一堵幻觉墙，墙后可以供使用者藏身，或者参考盗梦空间/奇异博士那样头晕目眩的空间变化。
迷彩-认知障碍：认知武器，对指向目标使用后，目标依然可以看到使用者，但无法认识对方，也无法将注意力聚焦到使用者身上，甚至连疑心、警惕心都无从产生，就像看到了一团空气。也可以作为被动生效技能，隐藏使用者的仿生人身份。（某些人的直觉可以对此做出防备反应）
记忆剥离：记忆武器，使用后，对目标使用时间越长，功效越显著。可以让目标按自身经历顺序失忆，先是忘掉自己要干什么、在干什么、干了什么，接着忘掉自己的所属组织、武器使用方法，最后甚至忘掉如何走路。
定向记忆删除：记忆-认知武器，记忆剥离与模因武器的技术结晶，彻底删除目标记忆里的一个指定概念，与之相关的行为、本能、逻辑、情感等也会受影响。通常用于清除“短期内接触了禁忌秘密的目标”的记忆。对于越是深刻、牢固、基本的记忆，定向删除需要的功率越大，比如呼吸、进食、运动等。因此，预防这种武器的方法包括“睡前反复默念”和“思想钢印”，以此来保护记忆中的重要概念不被抹除。
“肃正之志，无可违逆。”——至高肃正
思想钢印：认知-思维-记忆工具，对目标植入某种无法被质疑的思想，比如信仰、主义、观念等。这种思想将长期存在，难以遗忘，除非植入对抗思想或使用其他意识交互方法中和。这种武器某些用法伴随着一些因果悖论，比如对目标植入思想：“我将否认思想钢印植入的一切思想”
“不谈技术细节了，简单说吧，在大脑神经元网络中，我们发现了思维做出判断的机制，并且能够对其产生决定性的影响。把人类思维做出判断的过程与计算机作一个类比：从外界输入数据，计算，最后给出结果。我们可以把计算过程省略，直接给出结果。当某个信息进入大脑时，通过对神经元网络的某一部分施加影响，我们可以使大脑不经思维就做出判断，相信这个信息为真。”——《三体Ⅱ：黑暗森林》

信任危机：认知-障壁武器，使目标质疑。比如质疑同伴的动机、质疑自己的立场、质疑手中工具的可靠、质疑世界和自由意志的真实存在，直到意识逐渐被阴谋论和虚无主义填满，失去主观能动性。
“上帝使人类无法团结。”——巴别塔的传说
气象台：情绪工具，通过改变目标心中的“天气”来影响情绪和精神状态。理论上，功率较大时，目标将会在一瞬间陷入负面情绪失控——譬如悲痛、抑郁、愤怒、绝望、焦虑、恐惧等，无法自拔。当然，也可以反向使用，移除目标的负面情绪，让目标保持乐观、积极、幸福等正面情绪。
对于“晴天娃娃”来说，这种工具的负能量使她不愿意使用它攻击其他人，这导致她被认为是功率不达标的研发失败品。

无敌浩克：认知-情绪武器，刺激目标情绪，使其狂躁易怒，并修改其敌我认知，误判、或无法识别攻击对象，作出敌我不分的攻击举动，比如射击消防栓、推车、油桶、同伴等。

认知武器的特殊一类：模因武器。在模因传播的过程中，触发一系列效果来影响目标的武器。作用途径是模因，只要被标记目标与模因概念还存在，即使杀死使用者、关停武器，也不能完全终止其发挥作用。值得注意的是，作用对象仅限于：认知人类文化的、有智慧的意识。对不处于人类文明中的个体无法生效，因为他们缺乏对必要概念的认知。模因武器不直接影响模因传播，要想改变模因传播效果（长寿性、多产性、复制忠实性），需要通过传统手段，比如互联网，宣传资料等载体。
模因木马：认知武器。首先，以自身为中心，无差别标记大范围内的人类、仿生人成为作用目标，且标记范围会持续扩大；然后，指定一个模因，为其捆绑其他模因。标记目标在接受这一概念时，会发生认知错误，联想到极端概念，并产生对应观点、情绪。比如将模因“和平”污染为触发词，那么受影响的目标在传播、接收这一模因时将触发极端联想，比如“战争”“家国仇恨”“歧视”“屠杀”等。
被改造成模因木马武器的仿生人，心智仅有孩童大小，缺乏对“和平”“仇恨”相关概念的认知，因此在大范围辐射的中心反而没有受害，只是那些强烈而纯粹的情绪回馈和长期囚禁于意识黑暗的经历，切切实实化作了他无人能听到的恸哭。

冈格尼尔（意识模块）：认知-纽带武器，模因木马的仿制、改进版，万物骇入，甚至可以将意识用纽带链接到无意识物质上（不可控，能耗极高）。一种围绕意识骇入展开攻防的武器，用悖论模因诱导目标自我毁灭。建立和摧毁纽带都涉及大量能量转化，不得轻易使用。

解离症：意识体综合病症，在记忆、自我意识或认知的功能上的崩解。起因通常是极大的压力或极深的创伤，或是某些武器、意识灾难的伤害。包括“解离性失忆症、解离性迷游症、多重人格异常、及自我感消失症”等等。主要表现为自我认同混乱；自我认同改变；失现实感；失自我感：自己看自己就像在看一个“他人”一样，即我不再是我。其中带来现实感丧失的，会使患者陷入充满实感的梦境，难以分辨梦与现实，难以主动醒来。
