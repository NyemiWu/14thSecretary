# 意识污染

**意识污染**：意识界与物质界的平衡打破导致的灾害，其规模呈滚雪球式地扩张。作用形式包括但不限于：各类精神性瘟疫（涵盖几乎所有已知的心理、精神疾病），生物基因突变，辐射，EMP，特定物质解体重构，出现超自然意志体，超自然意志现象（如意识结构紊乱，蜂巢意识现象，意识夺舍、寄生、剥离现象，伴随有物理性变化）。由于科技发展不成熟，该类灾害的防治手段相当局限，穹顶系统与仿生人是其中最有效的之二。

意识污染的一个实质，便是意识空间的规则律反过来影响到了现实世界的表征。

*比如昆山，屡屡在作战中幸存归来，于是越来越多的人开始相信他是所向披靡的龙将，带领将士们一次次行军、一次次摧枯拉朽。所以昆山受到的意识污染表现为，他的外貌变成了半龙半人、与盔甲融合的模样——意识污染将人们的期望变成了诅咒。以及圣莱山德医院的院长，被污染变成羊角的恶魔，也是来源于规则律的影响。温迪戈的诞生也是如此，食人恶魔温迪戈渐渐流行在阿尔冈昆语族传说中，而意识污染则会让温迪戈降临，随着传说范围扩大，接受信仰的温迪戈的力量也会不断增强，最终扩大成不可收拾的文化症候群，以及一头蜂巢级以上的大型意识生物。*

**意识污染影响：1.规则律现实化。2.传播性的心理/精神疾病。3.生物趋同化演变。**

**信息通道学说：**

认为一个物体（或者说信息系统），其内含的信息传递通道复杂度越大、越密集，受到意识污染的可能性则越高。

比如高等动物的大脑、神经网络，复杂的电子元件，中央处理器等。认为意识污染动力的本质与信息熵大小有关。智能生命以负熵为食，智能将局部熵降低的过程，与意识污染的动机高度相似，可以说“意识污染”是“降熵行为”的反噬，一个系统越是试图消除污染的不确定性，则越是会受到意识污染侵蚀（比如确定意识生物赐名的过程，也就是“测名”，实际上很有可能被意识污染反噬）。而污染的表现，则与信息通道有关——即便是没有智能的系统，也会受到意识污染；而有智能意识的人，则会因通路改写而呈现出心理或精神疾病。

**“肉虫”实验：**

通过大量克隆“养殖”人脑前额叶体，而广泛制造意识存在，“人工制造”出大量识子漩涡结构以供研究。该实验导致意识维度出现大量残缺甚至有害的识子漩涡结构，进而使得意识维度出现不平衡，最终意识维度与物理维度的边界因零点能反应炉的启动而局部破裂，导致意识污染侵蚀至现实世界，形成“意识污染”这一天灾。

**意识污染能源技术**

“燃烧”意识跨界纽带，可以获得大量能量，但也会造成全球意识污染加剧，这种行为无异于给天灾捅了个大窟窿。认识到这点后，纽带能技术被全球禁用、销毁，转而使用更无害（存疑）的肉虫族技术。譬如有些经过诱导变异的肉虫，可以通过代谢合成燃料。该技术打造的一种发动机会因废料中含有的【不充分燃烧后肉虫角质的局部放射性微粒】而射出高亮的光轨。

*有一种戏谑的说法是，科学家通过激怒一群虫子来让它们的怒火推动发动机。该说法并非空穴来风，研究表明肉虫的状态确实会受到意识体的情绪波动影响，而且非常显著。*

**意识生物与意识污染的关系：**

意识生物是意识污染的副产物。

意识生物加速意识污染的传播。此时意识生物可以看作携带病原体的传染源。

意识生物也是局部降熵的生命，其在执念催生下，遵守特定的认知行为模式，消除外界的不确定性，甚至超越人类。也就是说，意识生物可以反过来被人类利用，以特定形式管控意识污染——当然，这只是理论上。即便在这种理论情况下，意识生物依然会向系统外排放意识污染。存在一种假设：终极的意识生物，即是“局部降熵”能力达到终极的生物——【极限负熵生命】，其具备近乎完美预测未来的能力，对于祂来说几乎没有突如其来的未知事物，祂的记忆即是整个因果，遍历过去、现在与未来。（阿西莫夫小说的“茂的模”？）
