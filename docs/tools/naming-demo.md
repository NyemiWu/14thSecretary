# 测名台

把 [赐名流程](../canon/ritual.md) 完整跑一遍的可玩版本。

!!! info "怎么用"
    - 左侧是观测对象，右侧是测名台。
    - 四位秘语各选一个，按 **宣读测名**。正确答案会被锁死，进度 +25%。
    - 每次失误，对象**阶级 +1**，同时多暴露一条线索。阶级满了再失误就失败。
    - 四段全中 → 四句短句展开 → 从四个候选词里**锚定真名**。
    - 紫色的 `無相` 是万能符，能填任意一位，但不锁位、不涨进度。
