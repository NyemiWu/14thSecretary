# 静水教团

## 正文

### 概述

以「静水之下」为崇拜对象的地下教团。他们不召唤，只**等待**——
在河口设坛，把船推离岸边，然后记录船沉下去的方式，视之为神谕。

### 与沉钟的关系

> 本节为冲突点，待修订。

原稿写：教团掌握了驯养沉钟的方法，能够指定它出现的时辰。

这与 `002 静水之下` 的设定冲突 —— 图鉴中该对象的「多神 / 一神」判位是
**受控**，行动由更深处的存在牵引，教团不具备指令能力。

### 可选修订方向

1. 教团自认为在驯养，实际上是**被利用**（他们记录的"神谕"是牵引者的副产品）。
2. 教团只是**观测者**，不介入，纯粹记录。
3. 改成两个派系：一派主张驯养（错误认知），一派主张等待（正确认知）。
