# 秘语·显位的语义边界

## 正文

第四段（显位）的六个秘语中，`祝` 与 `牧` 最容易混淆，需要补一条边界规则。

拟加在「四 · 显（表现属性）」表下方：

!!! quote "拟增段落"
    **`祝` 与 `牧` 的分界**：`牧` 是**手段**（治愈、圣化作为能力类别），
    `祝` 是**形态**（神圣化作为力量的外显方式）。

    判定看**力从哪里来**：
    若对象的力量必须经由"照看、救济、修复"这类**关系性动作**才成立 → `牧`；
    若对象自身就持续散发某种正向场域，不需要动作介入 → `祝`。

    对照条：`004 巡礼者的残响` 用的是 `祝`（掌心自发浮出温白纹路），
    而 `001 灰烬中的某物` 用的是 `牧`（必须"把手按上去"才愈合）。
