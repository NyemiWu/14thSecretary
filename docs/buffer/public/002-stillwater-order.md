## 概述

以「静水之下」为崇拜对象的地下教团。他们不召唤，也不驯养 —— 他们**只是等**。

在河口设坛，把船推离岸边，然后记录船沉下去的方式，视之为神谕。
教团本身没有干预能力，他们把自己放在一个**观测者**的位置上。

## 与沉钟的关系

这是本条目最关键的一段。

教团相信自己是"被选中的记录者"，而事实上，他们对沉钟的出现时辰毫无影响 ——
按 [002 静水之下](../../text/bestiary/002-stillwater.md) 的判位，该对象是**受控**的，
行动由更深处的存在牵引。

教团记录的每一条"神谕"，都是那个牵引者的副产品。他们不承认这一点。

!!! quote "教团内部的分歧"
    - **静候派**（主流）：只记录，不介入。承认自己无能为力。
    - **推定派**（少数）：认为通过足够的记录可以反推出牵引者的规律，
      进而"预判"沉钟的时辰，实质上接近驯养。

    两派至今没有公开决裂，因为谁都拿不出证据。
