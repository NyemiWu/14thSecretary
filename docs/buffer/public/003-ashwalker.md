## 观察记录

一具总是在尸堆里翻找的躯壳，指节磨得只剩骨。

!!! abstract "形态摘要"
    - 只靠近已死之物，对活物绕行
    - 不确定地去向，像被什么牵着走
    - 触碰尸骸可令其短暂立起
    - 所过之处草木枯卷，土色发灰

## 四段秘语

| 段 | 秘语 | 判定依据 |
|---|---|---|
| 一 · 倾向 | `C` 混乱 | 只处理死者，对活物绕行；它带来的动静全是破坏性的 |
| 二 · 性 | `一神` 受控 | 不确定地转向，像被什么牵着走 |
| 三 · 途 | `牧` 牧师 | 触碰尸骸可令其短暂立起 —— 是「照看」的动作 |
| 四 · 显 | `咒` 秽 | 所过之处草木枯卷、土色发灰，负能量场 |

!!! note "为什么不是 `祝`"
    按 `祝 / 牧` 的边界规则（见 001 号在审稿件）——
    它的效果**必须**经由触碰这个关系性动作成立，自身不散发场域。
    所以是 `牧`（手段），不是 `祝`。

## 四段式真名

1. 它只朝死人走去。活人立在路当中，它绕开，连看都不看。
2. 它没有要去的地方。是有什么东西在拉它，它只是跟着。
3. 它把手指按下去，那具已经凉透的东西重新撑起了膝盖。
4. 它捡了一路的骨头，最后连自己那份也丢了 —— 人们后来叫它 **拾骨**。

!!! success "锚定结果"
    **赐名：拾骨**

    干扰候选：`绕开` · `跟着` · `撑起`

4. 它走过的地方，草会枯，土会发灰，可是它自己不散发任何东西。
5. 它不阻拦任何人。人死了它才过去。
